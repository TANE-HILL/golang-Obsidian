# Что такое SQL

**SQL — это язык, на котором мы “разговариваем” с [[2.0.0. Базы данных и их виды|базой данных]].**

Приложение не работает напрямую с файлами, а отправляет запросы в базу вроде:
```sql
SELECT * FROM users WHERE age > 18;
```
PostgreSQL понимает этот запрос, ищет нужные строки и возвращает результат в программу.

## Зачем нужен SQL

SQL решает четыре главные задачи — их называют **CRUD** (Create, Read, Update, Delete):

| <u>Действие</u> | <u>Команда</u> | <u>Что делает</u>            |
| --------------- | -------------- | ---------------------------- |
| **Create**      | `INSERT`       | Добавляет новые данные       |
| **Read**        | `SELECT`       | Получает данные              |
| **Update**      | `UPDATE`       | Изменяет существующие данные |
| **Delete**      | `DELETE`       | Удаляет данные               |

---
# Почему SQL универсален

SQL — это **единый язык** для большинства реляционных баз данных:
	PostgreSQL, MySQL, SQLite, Oracle и т.д.

Синтаксис может чуть отличаться, но логика и ключевые команды остаются одинаковыми. Это значит, что выучив SQL один раз, ты сможешь работать почти с любой реляционной базой.

## В чём сила SQL:
- Легко получать данные по любым условиям
- Можно объединять таблицы (**JOIN**)
- Безопасен при правильном использовании (через параметры)
- Работает десятилетиями — стандарт, не зависящий от языка программирования

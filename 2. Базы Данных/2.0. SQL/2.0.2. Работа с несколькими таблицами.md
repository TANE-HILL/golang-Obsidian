# Зачем нужен **` JOIN `**

[[2.0.1. Основы SQL - SELECT, FROM, GROUP BY, ORDER BY|Ранее]] мы работали только с одной таблицей — выбирали, фильтровали и сортировали данные.

Но в реальных проектах данные почти **всегда связаны между собой**.

**Например:**
- у пользователя есть несколько заказов,
- у заказа есть товары,
- у товара есть категория.

Все эти данные хранятся в **разных таблицах**, и чтобы собрать их в один результат, используется оператор **` JOIN `**.

Проще говоря, `JOIN` — это **способ “сшить” таблицы между собой.**

---
## Зачем это нужно в [[1.1.0. Go Basics|Go]]

Когда ты подключишь PostgreSQL в следующем модуле, все запросы к базе (например, “все заказы пользователя”) будут выполняться через SQL с `JOIN` — поэтому сейчас важно понять саму логику объединений и выборок.

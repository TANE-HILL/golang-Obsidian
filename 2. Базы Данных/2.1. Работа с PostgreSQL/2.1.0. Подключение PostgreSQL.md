# Зачем нужно подключение к <font color="#ff0000">PostgreSQL</font>

Когда программа хранит данные — их нужно **куда-то записывать**, чтобы они не пропадали после перезапуска.

Файлы или структуры в памяти для этого не подходят, если:
- данных становится много;
- нужно искать, фильтровать и сортировать;
- к ним обращаются **несколько пользователей одновременно**.

Для этого существует **база данных (БД)**.

А PostgreSQL — одна из самых популярных и надёжных [[2.0.0. Базы данных и их виды|СУБД]] для серверных приложений.

[[1.1.0. Go Basics|Go]] может напрямую подключаться к PostgreSQL через драйвер — так же, как браузер подключается к сайту: по сети, с авторизацией, запросами и ответами.

---
## Как работает подключение

1. Приложение на Go — это **клиент**.
2. PostgreSQL — **сервер**, который слушает порт (обычно `5432`).
3. Программа создаёт **соединение** (connection) с базой, передаёт логин, пароль, имя БД.
4. После этого можно выполнять SQL-запросы: `SELECT`, `INSERT`, `UPDATE` и т.д.

---
# Подготовка PostgreSQL

Прежде чем [[1.1.0. Go Basics|Go]] сможет работать с базой данных, нужно запустить сам сервер PostgreSQL.

Самый удобный способ — через **Docker**. 
Пока хватит этих знаний: это программа, которая позволяет запускать готовые сервисы *(например, PostgreSQL)* в виде **контейнеров** — изолированных мини-систем, не мешающих основной ОС.

---
## Файл `docker-compose.yml`

Чтобы быстро запустить базу, создадим рядом с проектом файл с таким содержимым:
```yaml
version: '3.8'
services:
  postgres:
    image: postgres:15
    container_name: gofinance-db
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: password
      POSTGRES_DB: gofinance
    ports:
      - "5432:5432"
    volumes:
      - ./pgdata:/var/lib/postgresql/data
```
### Что здесь происходит:
- **`services:`** — список контейнеров, которые нужно запустить.
    *У нас один — `postgres`, то есть **база данных**.*
- **`image: postgres:15`** — указываем, что хотим использовать готовый образ PostgreSQL версии 15.
    *Docker сам скачает его с официального сайта.*
- **`container_name: gofinance-db`** — имя контейнера, чтобы было удобно к нему обращаться.
- **`environment:`** — здесь задаются настройки для базы:
```yaml
POSTGRES_USER: postgres      # имя пользователя (логин)
POSTGRES_PASSWORD: password  # пароль
POSTGRES_DB: gofinance       # имя базы, которая создастся автоматически
```
- Эти данные ты сам придумываешь — это и есть логин, пароль и имя базы, которые потом указываются в строке подключения.
- **`ports: "5432:5432"`** — открывает порт 5432, через который PostgreSQL будет доступен на твоём компьютере.
    То есть ты сможешь подключиться к базе по адресу `localhost:5432`.
- **`volumes:`** — сохраняет данные базы на диск, чтобы они не пропадали при перезапуске контейнера.

## Запуск базы

После сохранения файла выполни команду:
```bash
docker compose up -d
```
- `up` — запустить контейнер;
- `d` — работать в фоновом режиме (чтобы не занимал терминал).

**Через пару секунд база будет готова.**

## Адрес подключения

Когда контейнер запущен, PostgreSQL доступен по адресу:
```
postgres://postgres:password@localhost:5432/gofinance
```

Разберём этот адрес:

| Часть         | Значение                                               |
| ------------- | ------------------------------------------------------ |
| `postgres://` | указывает тип базы данных                              |
| `postgres`    | логин (из `POSTGRES_USER`)                             |
| `password`    | пароль (из `POSTGRES_PASSWORD`)                        |
| `localhost`   | адрес сервера (контейнер работает на твоём компьютере) |
| `5432`        | порт PostgreSQL                                        |
| `gofinance`   | имя базы данных (из `POSTGRES_DB`)                     |

Если всё работает, ты увидишь консоль PostgreSQL с приглашением:


Результат покажет версию PostgreSQL — значит база запущена и готова к работе.

# Подключение к БД из Go

Теперь сделаем простую программу, которая подключается к базе и проверяет соединение:
```go
package main
import (
    "database/sql"
    "fmt"
    _ "github.com/lib/pq"
)

func main() {
    connStr := "postgres://postgres:password@localhost:5432/gofinance?sslmode=disable"

    db, err := sql.Open("postgres", connStr)
    if err != nil {
        panic(err)
    }
    defer db.Close()

    err = db.Ping()
    if err != nil {
        panic(err)
    }

    fmt.Println("✅ Подключение к PostgreSQL установлено!")
}
```

## Пошаговый разбор кода

### 1. Импортируем нужные пакеты

```go
import (
    "database/sql"
    _ "github.com/lib/pq"
)
```

- `database/sql` — это стандартная библиотека Go, которая умеет работать с разными базами данных (PostgreSQL, MySQL и другими). Она даёт общий интерфейс для работы с базой: подключение, запросы, закрытие и т.д.
- `_ "github.com/lib/pq"` — это **драйвер** PostgreSQL.
    Он нужен, чтобы Go *“понимал”*, как именно общаться с этой базой.
    Подчёркивание (**`_`**) значит: мы не используем этот пакет напрямую, но при импорте он **регистрирует себя** внутри `database/sql`, и теперь Go знает, как работать с PostgreSQL.

### 2. Задаём строку подключения

```go
connStr := "postgres://postgres:password@localhost:5432/gofinance?sslmode=disable"
```
Эта строка говорит программе, **куда и как подключаться** к базе данных.

Разберём по частям:

|Часть|Что значит|
|---|---|
|`postgres://`|указываем, что подключаемся к PostgreSQL|
|`postgres`|имя пользователя (логин)|
|`password`|пароль|
|`localhost`|адрес сервера (база работает на этом же компьютере)|
|`5432`|порт, на котором слушает PostgreSQL|
|`gofinance`|имя базы данных|
|`?sslmode=disable`|временно отключаем SSL, чтобы не мешало при разработке|

Эту строку можно записывать прямо в коде, но правильнее хранить её в `.env` файле, чтобы не светить пароль.
*(Это разберём позже)*

### 3. Создаём подключение

```go
db, err := sql.Open("postgres", connStr)
```

Эта команда **создаёт “объект подключения” к базе**.
Go теперь знает, что будет использовать драйвер `"postgres"` и параметры из `connStr`.

Важно:
> На этом шаге Go **ещё не подключается к базе**, а только **готовится** — проверка соединения произойдёт позже.

### 4. Закрываем соединение при выходе

```go
defer db.Close()
```

[[1.3.1. panic, recover, defer#Что делает ~ <font color=" ff0000">defer</font> ~|defer]] — значит “выполни в конце функции”.
Когда программа завершится, это закроет подключение к базе.
Так мы избегаем ошибок вроде “слишком много открытых подключений”.

### 5. Проверяем, что база доступна

```go
err = db.Ping()
```

`Ping()` отправляет тестовый запрос в базу.

Если база не запущена или логин/пароль неверные — Go сразу вернёт ошибку.
Если всё хорошо, ошибок не будет, и программа продолжит работу.

### 6. Выводим сообщение

```go
fmt.Println("✅ Подключение к PostgreSQL установлено!")
```

Если мы дошли до этой строчки — значит всё работает: Go успешно подключился к базе, и можно переходить дальше.

---
## Важно запомнить
- `sql.Open()` — **настраивает подключение**, но не проверяет его.
- `db.Ping()` — **проверяет**, что база реально доступна.
- `defer db.Close()` — **закрывает соединение**, когда программа завершится.

---
## Проверка результата

Запусти:
```bash
go run main.go
```

Если всё настроено правильно, в консоли появится:
```
✅ Подключение к PostgreSQL установлено!
```

Если появится ошибка вроде:
```
pq: password authentication failed for user "postgres"
```
- проверь логин, пароль и имя базы.

## Советы по хорошей практике

- Никогда не храни пароль в коде.
    Используй `.env` или переменные окружения:
```bash
export DATABASE_URL=postgres://postgres:password@localhost:5432/gofinance?sslmode=disable
```
и в коде:    
```go
connStr := os.Getenv("DATABASE_URL")
```
- Проверяй соединение при запуске приложения (через `db.Ping()`).
- Используй пул подключений — `sql.DB` сам управляет ими, поэтому не нужно открывать и закрывать соединение при каждом запросе.

# Шаг 5. Загружай `.env` в `main.go`

Минимальный рабочий пример *(читать легко и по делу)*:
```go
// cmd/api/main.go
package main

import (
	"database/sql"
	"fmt"
	"log"
	"os"

	_ "github.com/lib/pq"
	"github.com/joho/godotenv"
)

func mustGetenv(key string) string {
	v := os.Getenv(key)
	if v == "" {
		log.Fatalf("переменная окружения %s не задана", key)
	}
	return v
}

func main() {
	// 1) Подхватываем .env (только локально; на сервере можно не вызывать)
	if err := godotenv.Load(); err != nil {
		log.Println("⚠️  .env не найден или не загружен (это ок для продакшена)")
	}

	// 2) Читаем конфигурацию из окружения
	connStr := mustGetenv("DATABASE_URL")
	port := os.Getenv("PORT")
	if port == "" {
		port = "8080" // безопасный дефолт
	}

	// 3) Подключаемся к базе
	db, err := sql.Open("postgres", connStr)
	if err != nil {
		log.Fatalf("ошибка sql.Open: %v", err)
	}
	defer db.Close()

	if err := db.Ping(); err != nil {
		log.Fatalf("нет подключения к БД: %v", err)
	}

	fmt.Printf("✅ БД ок. Сервер поднимется на :%s\n", port)
	// тут запускаешь HTTP-сервер и передаёшь db дальше по слоям
}

```

Что здесь важно:
- `godotenv.Load()` — подгружает ключи из `.env` в переменные окружения процесса.
- `os.Getenv("DATABASE_URL")` — читает значение по ключу.
- `mustGetenv` — маленький хелпер: если переменная не задана — сразу понятная ошибка.

# Шаг 6. Вынеси подключение в отдельный пакет *(чистая архитектура)*

Чтобы код был аккуратным, сделаем отдельную функцию подключения:
```go
// internal/db/connect.go
package db

import (
	"database/sql"
	"fmt"
	_ "github.com/lib/pq"
)

func Connect(connStr string) (*sql.DB, error) {
	d, err := sql.Open("postgres", connStr)
	if err != nil {
		return nil, fmt.Errorf("sql.Open: %w", err)
	}
	if err := d.Ping(); err != nil {
		return nil, fmt.Errorf("db.Ping: %w", err)
	}
	return d, nil
}
```

И используем её в `main.go`:
```go
// cmd/api/main.go (фрагмент)
import goDB "gofinance/internal/db"

// ...
db, err := goDB.Connect(connStr)
if err != nil {
	log.Fatal(err)
}
defer db.Close()
```

## Как использовать `.env` в Go

**Чтобы Go мог прочитать данные** из `.env`, нужно установить **пакет**:
```bash
go get github.com/joho/godotenv
```

### Пример кода подключения с `.env`:
```go
// cmd/api/main.go
package main

import (
    "database/sql"
    "fmt"
    "log"
    "os"

    _ "github.com/lib/pq"
    "github.com/joho/godotenv"
)

func mustGetenv(key string) string {
    value := os.Getenv(key)
    if value == "" {
        log.Fatalf("переменная %s не найдена в окружении", key)
    }
    return value
}

func main() {
    // Загружаем .env в переменные окружения
    if err := godotenv.Load(); err != nil {
        log.Println("⚠️  Файл .env не найден (это нормально, если ты используешь export)")
    }

    // Читаем строку подключения и порт из окружения
    connStr := mustGetenv("DATABASE_URL")
    port := os.Getenv("PORT")
    if port == "" {
        port = "8080"
    }

    // Подключаемся к PostgreSQL
    db, err := sql.Open("postgres", connStr)
    if err != nil {
        log.Fatalf("ошибка подключения: %v", err)
    }
    defer db.Close()

    if err := db.Ping(); err != nil {
        log.Fatalf("база данных недоступна: %v", err)
    }

    fmt.Printf("✅ Подключение к PostgreSQL успешно! Сервер запустится на порту %s\n", port)
}
```
#### <u>Что делает этот код</u>:
1. `godotenv.Load()` — загружает все значения из файла `.env` и делает их доступными через `os.Getenv()`.
2. `os.Getenv("DATABASE_URL")` — получает значение переменной по имени.
3. `sql.Open()` и `db.Ping()` — подключаются к PostgreSQL и проверяют соединение.
4. `defer db.Close()` — закрывает соединение, когда программа завершится.

## Вынесем подключение в отдельный пакет (для чистоты кода)

Чтобы код не засорял `main.go`, создадим отдельный файл:
```go
// internal/db/connect.go
package db

import (
    "database/sql"
    "fmt"

    _ "github.com/lib/pq"
)

func Connect(connStr string) (*sql.DB, error) {
    d, err := sql.Open("postgres", connStr)
    if err != nil {
        return nil, fmt.Errorf("sql.Open: %w", err)
    }
    if err := d.Ping(); err != nil {
        return nil, fmt.Errorf("db.Ping: %w", err)
    }
    return d, nil
}
```

И используем его в `main.go`:
```go
import goDB "gofinance/internal/db"

// ...

db, err := goDB.Connect(connStr)
if err != nil {
    log.Fatal(err)
}
defer db.Close()
```

## Как запускать проект

Если `.env` лежит рядом — просто запускай:
```bash
go run ./cmd/api
```

Если не хочешь использовать `.env`, можно задать переменные вручную перед запуском:
### <u>macOS / Linux</u>
```bash
export DATABASE_URL=postgres://postgres:password@localhost:5432/gofinance?sslmode=disable
export PORT=8080
go run ./cmd/api
```
### <u>Windows PowerShell</u>
```powershell
$env:DATABASE_URL="postgres://postgres:password@localhost:5432/gofinance?sslmode=disable"
$env:PORT="8080"
go run ./cmd/api
```

# <font color="#ff0000">YAML</font> — памятка

- **YAML** — текстовый формат данных, в основном для **конфигураций**.
- Главный акцент — **читаемость человеком**.
- Вложенность задаётся **отступами**.
- Есть **комментарии** через `#`.
- В Go используется внешняя библиотека **`gopkg.in/yaml.v3`**.
- **`yaml.Marshal`** — Go → YAML.
- **`yaml.Unmarshal`** — YAML → Go.
- Используются теги структуры: **`yaml:"name"`**.
- Как и JSON, работает с **`[]byte`**.

# 1. <u>Как выглядит YAML</u>

```yaml
server: localhost
port: 8080
debug: true
```

Вложенность — отступами:
```yaml
server:
  host: localhost
  port: 8080
```

Списки:
```yaml
servers:
  - server1
  - server2
```

Комментарии:
```yaml
# Адрес сервера
server: localhost
```

# 2. <u>Go</u> → <u>YAML</u>

Сначала библиотека:
```bash
go get gopkg.in/yaml.v3
```

Структура:
```go
type Config struct {
    Server string `yaml:"server"`
    Port   int    `yaml:"port"`
}
```

Сериализация:
```go
data, err := yaml.Marshal(config)
```

Получаем `[]byte` с YAML.

# 3. <u>YAML</u> → <u>Go</u>

```go
var config Config

err := yaml.Unmarshal([]byte(yamlStr), &config)
```
После этого `config` заполнен значениями из YAML.

Как и с JSON, нужен **`&config`**, чтобы `Unmarshal` мог записать данные в структуру.

## 4. <u>Теги структуры</u>

```go
type Config struct {
    Server string `yaml:"server"`
    Port   int    `yaml:"port"`
    Debug  bool   `yaml:"debug"`
}
```
Теги определяют имена ключей YAML.

---
#### Главное отличие <font color="#ff0000">YAML</font> от <font color="#ff0000">JSON</font>
<u>YAML</u> ориентирован прежде всего на удобное написание конфигураций человеком, а <u>JSON</u> гораздо чаще встречается непосредственно в Web/API.

# <font color="#ff0000">JSON</font> — <u>памятка</u>

- **JSON** — текстовый формат данных, особенно часто используется в **Web/API**.
- Основные элементы: `{}` объект, `[]` массив, строки, числа, `true/false`, `null`.
- В Go: пакет **`encoding/json`**.
- **`Marshal`** — Go → JSON.
- **`Unmarshal`** — JSON → Go.
- **`Encoder/Decoder`** — удобнее для HTTP-потоков.
- **`json:"name"`** — тег, задающий имя поля в JSON.
- **`omitempty`** — не отправлять пустое поле.
- `Unmarshal(..., &obj)` — передаём **указатель**, чтобы заполнить структуру.
- JSON работает с **`[]byte`**.
# 1. <u>Go</u> **→** <u>JSON</u>

```go
data, err := json.Marshal(book)
```
Получаем `[]byte` с JSON:
```json
{"title":"Книга","pages":200}
```
Для красивого форматирования:
```go
json.MarshalIndent(book, "", "  ")
```

## 2. <u>JSON</u> **→** <u>Go</u>

```go
var book Book

err := json.Unmarshal([]byte(jsonStr), &book)
```
После этого `book` заполнен данными из JSON.

# 3. <u>Теги структуры</u>

```go
type Book struct {
    Title string `json:"title"`
    Pages int    `json:"pages,omitempty"`
}
```
`Title` → `"title"` в JSON.  
`omitempty` → поле не попадёт в JSON, если оно пустое.

## 4. <u>Для HTTP</u>

Go → HTTP response:
```go
json.NewEncoder(w).Encode(book)
```

HTTP request → Go:
```go
json.NewDecoder(r).Decode(&book)
```

Это основной вариант, который пригодится дальше при написании API.

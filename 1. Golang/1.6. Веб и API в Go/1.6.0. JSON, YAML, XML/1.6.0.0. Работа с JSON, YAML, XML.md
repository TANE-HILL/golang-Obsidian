# Что такое ~ <font color="#ff0000">JSON</font>, <font color="#ff0000">YAML</font>, <font color="#ff0000">XML</font> ~

Это **не языки программирования**. Это **текстовые форматы данных** — способы записать информацию так, чтобы её одинаково понимали разные программы и языки.

#### [[1.6.0.1. ~ JSON ~|JSON]](<font color="#ff0000">Java</font><font color="#ff0000">Script</font> <font color="#ff0000">Object</font> <font color="#ff0000">Notation</font>)

JSON - это текстовый формат вида “*объектов и массивов*”. Очень популярен в веб-API.

**Похоже на словари/массивы:**
```json
{ "title": "Книга", "pages": 200 }.
```    

#### [[1.6.0.2. ~ YAML ~|YAML]] (<font color="#ff0000">YAML Ain’t Markup Language</font>)

Формат для конфигураций. Главное — **читаемость** человеком.    
Опирается на отступы:
```yaml
title: Книга
pages: 200
```

#### [[1.6.0.3. ~ XML ~|XML]] (<font color="#ff0000">eXtensible Markup Language</font>)

Разметка с **тэгами**. Часто встречается в старых/корпоративных интеграциях:

```xml
<book><title>Книга</title><pages>200</pages></book>
```    

#### Кратко: **чем отличаются**

| Формат | Где часто используют         | Плюсы                                             | Минусы                                            |
| ------ | ---------------------------- | ------------------------------------------------- | ------------------------------------------------- |
| JSON   | REST/HTTP API, веб           | Встроен в [[1.1.0. Go Basics\|Go]], прост, лёгкий | Нет комментариев, иногда “жёсткий” к типам        |
| YAML   | Конфиги (Docker, K8s, CI/CD) | Очень читаем, поддерживает комментарии            | Чувствителен к отступам, нужна внешняя библиотека |
| XML    | Старые API, SOAP, документы  | Строгий, расширяемый                              | Многословный, тяжёлый синтаксис                   |
#### Из чего состоят:
- **<u>JSON</u>**: объекты `{}`, массивы `[]`, строки, числа, `true/false`, `null`.
- **<u>YAML</u>**: ключ: значение, списки с , вложенность отступами, комментарии с `#`.
- **<u>XML</u>**: теги `<tag>...</tag>`, атрибуты `<tag attr="...">`, строгая иерархия.

Все три — обычно **UTF-8** текст. JSON не любит “висячие запятые” и **не поддерживает комментарии**; YAML — позволяет комментарии; XML — поддерживает пространства имён, атрибуты, схемы.

---
# Общая идея в [[1.1.0. Go Basics|Go]]

- **<u>Сериализация</u>** (_marshal_) — структура Go → текст (JSON/YAML/XML).

- **<u>Десериализация</u>** (_unmarshal_) — текст → структура Go.

- В Go для JSON и XML — **встроенные пакеты** `encoding/json`, `encoding/xml`. Для YAML — ставим `gopkg.in/yaml.v3`.

---
# **Общая модель** для примеров

**Во всех примерах используем простую структуру:**
```go
type Book struct {
    Title  string `json:"title" yaml:"title" xml:"title"`
    Author string `json:"author" yaml:"author" xml:"author"`
    Pages  int    `json:"pages"  yaml:"pages"  xml:"pages"`
}
```

Теги справа говорят кодерам/декодерам **какие имена полей** использовать в файле.

(Для XML мы ниже добавим `XMLName`, чтобы задать корневой тег.)

# <u>JSON</u> в [[1.1.0. Go Basics|Go]] ~ <font color="#ff0000">encoding / json</font> ~

#### <u>Сериализация</u> (<u>Go</u> → <u>JSON</u>):
```go
package main

import (
    "encoding/json"
    "fmt"
)

type Book struct {
    Title  string `json:"title"`
    Author string `json:"author"`
    Pages  int    `json:"pages"`
}

func main() {
    b := Book{Title: "Мастер и Маргарита", Author: "Булгаков", Pages: 400}

    data, err := json.Marshal(b)
    if err != nil {
        panic(err)
    }

    fmt.Println(string(data))
}
```
#### <u>Построчно</u>:
- `type Book ...` — описали модель.
- `b := Book{...}` — создали экземпляр.
- `json.Marshal(b)` — преобразовали структуру **в `[]byte`** (массив байт).
    Почему `[]byte`? Любой текст в Go — это **набор байт**. Так удобнее писать/читать в файлы/сокеты.
- `string(data)` — превратили байты в строку, чтобы **красиво показать** в консоли.

#### <u>Вывод</u>:
```json
{"title":"Мастер и Маргарита","author":"Булгаков","pages":400}
```
> Хотите красивее? Используйте `json.MarshalIndent(b, "", " ")`.

#### <u>Десериализация</u> (<u>JSON</u> → [[1.1.0. Go Basics|Go]]):
```go
package main

import (
    "encoding/json"
    "fmt"
)

type Book struct {
    Title  string `json:"title"`
    Author string `json:"author"`
    Pages  int    `json:"pages"`
}

func main() {
    jsonStr := `{"title":"Гарри Поттер","author":"Джоан Роулинг","pages":350}`

    var b Book
    err := json.Unmarshal([]byte(jsonStr), &b)
    if err != nil {
        panic(err)
    }

    fmt.Println(b.Title, "-", b.Author, "(", b.Pages, ")")
}

```
#### <u>Построчно</u>:
- `jsonStr := "...json..."` — у нас **строка**.
- `[]byte(jsonStr)` — переводим строку в **массив байт**, т.к. `Unmarshal` ждёт `[]byte`.
- `var b Book` — создаём **пустую** переменную, куда будем писать результат.
- `&b` — передаём **адрес** (`Book`), чтобы функция могла **заполнить** переменную.
    Если бы передали просто `b`, это была бы копия — записывать было бы некуда.
- После `Unmarshal` структура `b` заполнена данными из JSON.
#### <u>Вывод</u>:
```Run
Гарри Поттер - Джоан Роулинг ( 350 )
```

# <u>YAML</u> в [[1.1.0. Go Basics|Go]] ~ <font color="#ff0000">gopkg.in / yaml.v3</font> ~

#### <u>Установка:</u>
```bash
go get gopkg.in/yaml.v3
```

#### <u>Сериализация</u> (<u>Go</u> → <u>YAML</u>):
```go
package main

import (
    "fmt"
    "gopkg.in/yaml.v3"
)

type Config struct {
    Server string `yaml:"server"`
    Port   int    `yaml:"port"`
    Debug  bool   `yaml:"debug"`
}

func main() {
    c := Config{Server: "localhost", Port: 8080, Debug: true}

    data, err := yaml.Marshal(c)
    if err != nil {
        panic(err)
    }

    fmt.Println(string(data))
}
```
#### <u>Построчно</u>:
- Теги `yaml:"..."` — имена ключей в YAML.
- `yaml.Marshal(c)` — структура → **`[]byte`** (текст YAML).
- `string(data)` — печатаем как строку.
#### <u>Вывод</u>:
```yaml
server: localhost
port: 8080
debug: true
```

#### <u>Десериализация</u> (<u>YAML</u> → <u>Go</u>):
```go
package main

import (
    "fmt"
    "gopkg.in/yaml.v3"
)

type Config struct {
    Server string `yaml:"server"`
    Port   int    `yaml:"port"`
    Debug  bool   `yaml:"debug"`
}

func main() {
    yamlStr := `
server: prod-server
port: 9090
debug: false
`

    var c Config
    if err := yaml.Unmarshal([]byte(yamlStr), &c); err != nil {
        panic(err)
    }

    fmt.Println("Подключаемся к:", c.Server, "на порту", c.Port, "Debug?", c.Debug)
}
```
#### <u>Построчно</u>:
- Многострочная **строка** `yamlStr` с YAML.
- `[]byte(yamlStr)` — переводим строку в байты, т.к. `Unmarshal` принимает `[]byte`.
- `var c Config` — пустая структура-приёмник.
- `&c` (неявно в параметре) — даём функции **куда писать** результат.
#### <u>Вывод</u>:
```Run
Подключаемся к: prod-server на порту 9090 Debug? false
```

# <u>XML</u> в [[1.1.0. Go Basics|Go]] ~ <font color="#ff0000">encoding / xml</font> ~
*XML работает похоже, но есть свои нюансы: корневой тег и имена тегов.*
#### <u>Сериализация</u> (<u>Go</u> → <u>XML</u>):
```go
package main

import (
    "encoding/xml"
    "fmt"
)

type Book struct {
    XMLName xml.Name `xml:"book"` // задаём имя корневого тега
    Title   string   `xml:"title"`
    Author  string   `xml:"author"`
    Pages   int      `xml:"pages"`
}

func main() {
    b := Book{Title: "Собачье сердце", Author: "Булгаков", Pages: 200}

    data, err := xml.MarshalIndent(b, "", "  ")
    if err != nil {
        panic(err)
    }

    fmt.Println(string(data))
}
```
#### <u>Построчно</u>:
- `XMLName xml.Name "xml:\\"book\\""` — говорит кодеру, что корневой тег должен быть `<book>...</book>`.
- Остальные теги задаются через `xml:"..."`.
- `xml.MarshalIndent` — красиво форматирует с отступами.
- Результат — **`[]byte`** (XML), печатаем как строку.

#### <u>Вывод</u>:
```xml
<book>
  <title>Собачье сердце</title>
  <author>Булгаков</author>
  <pages>200</pages>
</book>
```
#### <u>Десериализация</u> (<u>XML</u> → <u>Go</u>):
```go
package main

import (
    "encoding/xml"
    "fmt"
)

type Book struct {
    Title  string `xml:"title"`
    Author string `xml:"author"`
    Pages  int    `xml:"pages"`
}

func main() {
    xmlData := `
<book>
  <title>12 стульев</title>
  <author>Ильф и Петров</author>
  <pages>320</pages>
</book>`

    var b Book
    if err := xml.Unmarshal([]byte(xmlData), &b); err != nil {
        panic(err)
    }

    fmt.Println(b.Title, "-", b.Author, "(", b.Pages, ")")
}
```
#### <u>Построчно</u>:
- `xmlData` — строка с XML.
- `[]byte(xmlData)` — XML в байтах.
- `var b Book` — создаём приёмник.
- `&b` — передаём адрес, чтобы `Unmarshal` мог **заполнить** поля.
#### <u>Вывод</u>:
```Run
12 стульев - Ильф и Петров ( 320 )
```

# Почему “везде байты” и “почему ссылка”

- **Почему `[]byte`?**
    Любой текст в Go под капотом — **байты**.
    (Дешево писать/читать из файлов, сетевых соединений, HTTP-тел и т.д.). `Marshal/Unmarshal` работают с **сырыми байтами**, поэтому мы часто делаем `[]byte(str)`.

- **Почему `&obj` (ссылка)?**
    Функция `Unmarshal` должна **записать** распарсенные данные **в переменную**. Чтобы она могла это сделать, ей нужен **адрес** (указатель). Без `&` она получит копию и попросту “некуда будет писать”.

---
# Ещё несколько полезных приёмов

- **Потоковая работа** (без промежуточных `[]byte`):
    - JSON: `json.NewEncoder(w).Encode(v)` / `json.NewDecoder(r).Decode(&v)` — сразу пишем/читаем в `io.Writer`/`io.Reader`(например, HTTP).
- **Переименование полей** через теги: `json:"title,omitempty"` — поле не попадёт в JSON, если “пустое”.
- **Ошибки типов**: если в JSON строка, а в структуре `int`, будет ошибка. Следите за типами.

# <font color="#ff0000">XML</font> — памятка

- **XML** — текстовый формат данных с **тегами**.
- Часто встречается в **старых API, SOAP и корпоративных интеграциях**.
- Данные организованы в строгую **иерархию**.
- Используются **теги** `<tag>...</tag>` и **атрибуты** `<tag attr="...">`.
- В Go — встроенный пакет **`encoding/xml`**.
- **`xml.Marshal`** — Go → XML.
- **`xml.Unmarshal`** — XML → Go.
- Для корневого тега используется **`XMLName`**.
- Как JSON/YAML, работает с **`[]byte`**.

## 1. <u>Как выглядит XML</u>

```xml
<book>
  <title>Книга</title>
  <pages>200</pages>
</book>
```

Атрибут:
```xml
<book id="123">
```

Главная особенность — данные находятся внутри тегов.

# 2. <u>Go</u> → <u>XML</u>

```go
type Book struct {
    XMLName xml.Name `xml:"book"`
    Title   string   `xml:"title"`
    Pages   int      `xml:"pages"`
}
```

Сериализация:
```go
data, err := xml.MarshalIndent(book, "", "  ")
```

Получаем:
```xml
<book>
  <title>Книга</title>
  <pages>200</pages>
</book>
```
`XMLName` задаёт **корневой тег**.

# 3. <u>XML</u> → <u>Go</u>

```go
var book Book

err := xml.Unmarshal([]byte(xmlData), &book)
```
После этого `book` заполнен данными из XML.

Как и с JSON/YAML, передаём **`&book`**, чтобы `Unmarshal` мог записать результат в структуру.

# 4. <u>Теги структуры</u>

```go
type Book struct {
    Title string `xml:"title"`
    Pages int    `xml:"pages"`
}
```
`xml:"title"` говорит Go, из какого XML-тега брать значение.

---
#### Главное отличие <font color="#ff0000">XML</font>
<u>XML</u> более многословный и структурированный за счёт тегов.
В современном Web/API чаще используется <u>JSON</u>.

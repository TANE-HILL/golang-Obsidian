# Что такое <font color="#ff0000">HTTP</font> и зачем ~ <font color="#ff0000">net / http</font> ~

Интернет можно представить как огромную почтовую систему.
Когда открывается сайт, браузер отправляет запрос серверу с просьбой:
> «Привет, сервер! Дай, пожалуйста, страницу /users.»

Сервер принимает письмо, обрабатывает его и отвечает:
> «Вот страница, держи!»

Эти письма называются **HTTP-запросами** и **HTTP-ответами**.

<font color="#ff0000">HTTP</font> — это **язык**, на котором клиент *(браузер, приложение)* и сервер **общаются друг с другом**.

[[1.1.0. Go Basics|Go]] умеет работать с <u>HTTP</u> “**из коробки**” — с помощью стандартной библиотеки: `net/http`.

**Она позволяет без сторонних инструментов:**
- запускать HTTP-сервер;
- обрабатывать маршруты (пути, по которым приходят запросы);
- читать метод, заголовки, параметры и тело запроса;
- отправлять ответы, включая JSON, с нужными заголовками и статусами.

# Минимальный **HTTP-сервер**

Когда ты запускаешь HTTP-сервер, ты буквально создаёшь “маленький сервер” на своём компьютере. Он слушает входящие запросы на определённом порту (например, `8080`).

Если кто-то (например, браузер) обращается по адресу `http://localhost:8080/hello`, сервер вызывает нужную функцию и возвращает ответ.

- `localhost` — это имя твоего компьютера.
- `:8080` — номер “двери”, через которую приходят запросы.

<u>Пример самого простого сервера:</u>
```go
package main

import (
    "fmt"
    "net/http"
)

func helloHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Привет, мир!")
}

func main() {
    http.HandleFunc("/hello", helloHandler)

    fmt.Println("Сервер запущен на <http://localhost:8080>")
    err := http.ListenAndServe(":8080", nil)
    if err != nil {
        panic(err)
    }
}
```
- `http.HandleFunc("/hello", helloHandler)` — регистрирует путь `/hello` и указывает функцию-обработчик.
- `helloHandler` — это обработчик (handler), который отвечает на запрос.
- `http.ListenAndServe(":8080", nil)` — запускает сервер на порту `8080`.

Если открыть в браузере [http://localhost:8080/hello](http://localhost:8080/hello) — ты увидишь надпись **Привет, мир!**.

# <u>Обработчики</u> ~ <font color="#ff0000">handlers</font> ~ и <u>маршруты</u>

Каждый <u>обработчик</u> в [[1.1.0. Go Basics|Go]] отвечает за **определённый путь** (<font color="#ff0000">route</font>) — адрес, по которому клиент обращается к серверу. Когда запрос приходит, [[1.1.0. Go Basics|Go]] проверяет: “какой путь указан в URL?” — и вызывает соответствующую функцию.

Например, если пользователь открывает
```
<http://localhost:8080/about>
```
то сервер ищет, есть ли зарегистрированный путь `/about`.
Если есть — вызывает связанную с ним функцию (обработчик).

---
# <u>Регистрация маршрутов</u>

Для регистрации маршрутов функция ~ <font color="#ff0000">http.HandleFunc()</font> ~

Она связывает путь и обработчик:
```go
http.HandleFunc("/", homeHandler)
http.HandleFunc("/about", aboutHandler)
```

Пошагово:
- `"/"` — путь (route). Это “главная страница”.
- `"about"` — ещё один путь. Например, страница “О проекте”.
- `homeHandler` и `aboutHandler` — функции, которые Go вызовет, когда придёт запрос на эти адреса.

**Например:**
```go
func homeHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Главная страница")
}

func aboutHandler(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "О проекте")
}
```

Теперь:
- запрос на `http://localhost:8080/` вернёт “Главная страница”
- запрос на `http://localhost:8080/about` вернёт “О проекте”

# <u>Что такое маршрутизатор</u> ~ <font color="#ff0000">ServeMux</font> ~

**Когда маршрутов становится много**, удобно использовать **маршрутизатор** (<font color="#ff0000">router</font> или <font color="#ff0000">mux</font>).
#### <u>mux</u> — сокращение от “**multiplexer**”, то есть “переключатель маршрутов”.

<u>Он работает как “секретарь на ресепшене”</u>:
	принимает все входящие запросы и направляет каждый к нужной функции, в зависимости от пути (`/users`, `/posts`, `/login` и т.д.).

#### <u>Пример с маршрутизатором</u>:
```go
mux := http.NewServeMux()            // создаём новый маршрутизатор
mux.HandleFunc("/users", usersHandler) // регистрируем обработчик для /users

http.ListenAndServe(":8080", mux)    // запускаем сервер и говорим: используй этот mux
```
#### <u>Пошагово</u>:
1. `http.NewServeMux()` — создаёт новый объект маршрутизатора.
    Он будет сам разруливать, какой обработчик вызывать при каждом запросе.
2. `mux.HandleFunc("/users", usersHandler)` — регистрирует путь `/users` и связывает его с функцией `usersHandler`.
3. `http.ListenAndServe(":8080", mux)` — запускает сервер и передаёт ему маршрутизатор, чтобы все запросы проходили через него.

---
# <u>Почему удобен</u> ~ <font color="#ff0000">mux</font> ~

- Можно легко **разделить код** по файлам (например, `users.go`, `auth.go`, `posts.go`).
- Можно зарегистрировать маршруты с одинаковыми началами (`/api/v1/users`, `/api/v1/posts`).
- Позже можно заменить стандартный `ServeMux` на более продвинутый роутер (например, `chi` или `gorilla/mux`) без переписывания логики.

# <font color="#ff0000">HTTP</font> <u>методы</u>

<u>Методы определяют</u>, **что хочет сделать клиент**.
Можно представить их как глаголы действий:

| <u>Метод</u>                            | <u>Значение</u>               | <u>Пример</u>             |
| --------------------------------------- | ----------------------------- | ------------------------- |
| **<font color="#ff0000">GET</font>**    | **Получить данные**           | “*Дай посмотреть*”        |
| **<font color="#ff0000">POST</font>**   | **Создать данные**            | “*Добавь запись*”         |
| **<font color="#ff0000">PUT</font>**    | **Полностью обновить данные** | “*Замени объект целиком*” |
| **<font color="#ff0000">PATCH</font>**  | **Частично обновить**         | “*Измени одно поле*”      |
| **<font color="#ff0000">DELETE</font>** | **Удалить**                   | “*Удали запись*”          |
Некоторые методы можно безопасно повторять — это называется **идемпотентность**:
- `GET`, `PUT`, `DELETE` — повтор одного и того же запроса не изменит результат.
- `POST` — не идемпотентен: может создавать дубликаты.

<u>Пример проверки метода в коде:</u>
```go
func usersHandler(w http.ResponseWriter, r *http.Request) {
    switch r.Method {
    case http.MethodGet:
        // получить данные
    case http.MethodPost:
        // создать новые данные
    default:
        http.Error(w, "Метод не поддерживается", http.StatusMethodNotAllowed)
    }
}
```

# Из чего состоит <font color="#ff0000">URL</font> (*и как это полезно в коде*)

Когда ты открываешь страницу или делаешь запрос, ты всегда используешь **URL** — это адрес ресурса в интернете.

Можно думать о нём как о “почтовом адресе”, по которому твоё *письмо* (<u>HTTP-запрос</u>) должно дойти до нужного получателя (сервера).

<u>Пример адреса</u>:
```
<http://localhost:8080/users?id=42&active=true>
```

<u>Разберём этот адрес по частям</u>:

| Часть                    | Название                  | Что значит                                          | Пример                                       |
| ------------------------ | ------------------------- | --------------------------------------------------- | -------------------------------------------- |
| **`http://`**            | Схема (протокол)          | Способ общения — “на каком языке говорить”          | `http` или `https`                           |
| **`localhost`**          | Хост (host)               | Куда идёт запрос — имя сервера или домен            | `localhost`, `google.com`, `api.example.com` |
| **`:8080`**              | Порт                      | Номер “двери”, через которую сервер слушает запросы | `:8080` или `:80`                            |
| **`/users`**             | Путь (path)               | Какой именно ресурс запрашиваем                     | `/users`, `/products/5`, `/search`           |
| **`?id=42&active=true`** | Параметры запроса (query) | Дополнительные данные для уточнения запроса         | `?ключ=значение` (можно несколько)           |

---
# **Как сервер использует <font color="#ff0000">URL</font>**

Когда клиент делает запрос, сервер получает весь URL и может прочитать любую его часть:
```go
func handler(w http.ResponseWriter, r *http.Request) {
    fmt.Println("Полный адрес:", r.URL.String())   // весь URL
    fmt.Println("Путь:", r.URL.Path)               // например: /users
    fmt.Println("Параметры:", r.URL.RawQuery)      // например: id=42&active=true
}
```

---
# **Как достать <u>query-параметры</u>**

#### **<u>Query</u> — часть после знака ~ <font color="#ff0000">?</font> ~**
Они нужны, чтобы передавать серверу дополнительные данные, не изменяя сам путь.

<u>Например, если пользователь открывает</u>:
```
<http://localhost:8080/search?term=go&limit=5>
```
сервер может извлечь параметры `term` и `limit` вот так:
```go
func searchHandler(w http.ResponseWriter, r *http.Request) {
    term := r.URL.Query().Get("term")   // значение параметра term
    limit := r.URL.Query().Get("limit") // значение параметра limit

    fmt.Fprintf(w, "Ищем по запросу '%s', максимум %s результатов.", term, limit)
}
```
Результат в браузере:
```
Ищем по запросу 'go', максимум 5 результатов.
```

---
# **Как это работает вместе**

<u>Когда приходит запрос</u>:
```
<http://localhost:8080/users?id=42>
```

<u>Go разбивает его на части</u>:
- `r.URL.Path` → `/users`
- `r.URL.Query().Get("id")` → `42`

Таким образом, ты можешь реагировать на разные пути:
`/users`, `/products`, `/posts`
и **извлекать конкретные значения параметров из строки запроса**.

# **<u>Статус-коды</u>: что ставить и когда**

Когда сервер **отвечает**, он сообщает не только данные, но и **код состояния** — короткое числовое сообщение о результате операции.

| <u>Код</u>                                                 | <u>Значение</u>             | <u>Описание</u>                                    |
| ---------------------------------------------------------- | --------------------------- | -------------------------------------------------- |
| **<font color="#ff0000">200 OK</font>**                    | **Всё хорошо**              | *Запрос выполнен успешно*                          |
| **<font color="#ff0000">201 Created</font>**               | **Создано**                 | *Создан новый ресурс*                              |
| **<font color="#ff0000">204 No Content</font>**            | **Нет содержимого**         | *Всё прошло успешно, но тело не нужно*             |
| **<font color="#ff0000">400 Bad Request</font>**           | **Ошибка запроса**          | *Клиент прислал неверные данные*                   |
| **<font color="#ff0000">401 Unauthorized</font>**          | **Не авторизован**          | *Требуется вход или токен*                         |
| **<font color="#ff0000">403 Forbidden</font>**             | **Запрещено**               | *Нет прав на операцию*                             |
| **<font color="#ff0000">404 Not Found</font>**             | **Не найдено**              | *Ресурс отсутствует*                               |
| **<font color="#ff0000">405 Method Not Allowed</font>**    | **Метод не поддерживается** | *Например, `POST` туда, где разрешён только `GET`* |
| **<font color="#ff0000">500 Internal Server Error</font>** | **Ошибка сервера**          | *Неожиданная ошибка на стороне сервера*            |

#### <u>Пример 1</u>: **успешный** и **неуспешный** сценарий:

Допустим, у нас есть обработчик, который принимает имя пользователя из формы. 
- Если имя не передано — это ошибка клиента (код 400).
- Если всё хорошо — сервер возвращает успешный ответ (код 200).
```go
func helloHandler(w http.ResponseWriter, r *http.Request) {
    name := r.URL.Query().Get("name") // читаем параметр ?name=...
    if name == "" {
        // клиент ничего не передал — его ошибка
        http.Error(w, "нужно указать имя", http.StatusBadRequest) // 400
        return
    }

    // всё хорошо — возвращаем приветствие
    w.WriteHeader(http.StatusOK) // 200 OK
    fmt.Fprintf(w, "Привет, %s!", name)
}
```
#### <u>Ответ</u> `http://localhost:8080/hello?name=Катя`:
```
Привет, Катя!
```
    (код 200 OK)
#### <u>Ответ</u> `http://localhost:8080/hello`:
```
нужно указать имя
```
    (код 400 Bad Request)

#### <u>Пример 2</u>: когда ничего возвращать не нужно

Иногда запрос успешно выполнен, но тело ответа не нужно — например, при удалении. В таком случае принято использовать <font color="#ff0000">204 No Content</font>:
```go
func deleteUserHandler(w http.ResponseWriter, r *http.Request) {
    id := r.URL.Query().Get("id")

    if id == "" {
        http.Error(w, "укажите id", http.StatusBadRequest)
        return
    }

    // допустим, пользователь удалён
    w.WriteHeader(http.StatusNoContent) // 204
}
```
Браузер не увидит текст, но получит “тихий успех”:
	сервер говорит “всё удалено, тело не требуется”.

#### <u>Таким образом</u>:
- <font color="#ff0000">400</font>, <font color="#ff0000">401</font>, <font color="#ff0000">403</font>, <font color="#ff0000">404</font>, <font color="#ff0000">405</font> — <u>ошибки по вине клиента</u> (*что-то не так в запросе*);
- <font color="#ff0000">500</font> — <u>ошибка на стороне сервера</u>;
- <font color="#ff0000">200</font>, <font color="#ff0000">201</font>, <font color="#ff0000">204</font> — <u>успешные сценарии</u>.

	<u>Код статуса помогает</u> любому клиенту *(браузеру, приложению, Postman)* <u>понимать контекст</u>: **всё ли в порядке или нужно что-то исправить.**

# <u>Заголовки</u> ~ <font color="#ff0000">Headers</font> ~

Когда клиент и сервер общаются через <font color="#ff0000">HTTP</font>, они передают не только сами данные, но и **дополнительную информацию о запросе и ответе**.

Эта дополнительная часть называется <u>заголовками</u>.

Можно думать о заголовках как о “конверте” письма — на нём написано: *кто отправил письмо, что внутри и как его нужно прочитать*.

#### <u>Пример реального запроса</u>:

Вот как выглядит HTTP-запрос, если заглянуть внутрь:
```
GET /users HTTP/1.1
Host: localhost:8080
Accept: application/json
User-Agent: Mozilla/5.0
```
- `GET /users` — это **строка запроса** *(что хотим получить)*.
- Строки ниже — это **заголовки**:
    - `Host` — куда идёт запрос;
    - `Accept` — что клиент хочет получить;
    - `User-Agent` — кто делает запрос (браузер, программа и т.д.).

#### <u>Пример ответа сервера</u>:

```
HTTP/1.1 200 OK
Content-Type: application/json
Content-Length: 32

{"name": "Катя", "age": 30}

```
- Всё, что до пустой строки — это **заголовки ответа**.
- После пустой строки идёт **тело ответа** — сами данные.

# <u>Основные заголовки</u>, которые нужно знать

| <u>Заголовок</u>                            | <u>Что означает</u>                          | <u>Пример</u>                          |
| ------------------------------------------- | -------------------------------------------- | -------------------------------------- |
| <font color="#ff0000">Content-Type</font>   | **Тип данных в теле запроса или ответа**     | `application/json`, `text/html`        |
| <font color="#ff0000">Content-Length</font> | **Размер тела в байтах**                     | *Обычно выставляется автоматически*    |
| <font color="#ff0000">Accept</font>         | **Какой формат данных клиент готов принять** | `application/json`                     |
| <font color="#ff0000">User-Agent</font>     | **Кто делает запрос**                        | `Mozilla/5.0` или `Go-http-client/1.1` |
| <font color="#ff0000">Authorization</font>  | **Токен или логин для доступа**              | `Bearer 123abc`                        |
#### **Этих заголовков достаточно, чтобы начать работать с API.**

---
# <u>Как работать с заголовками</u> в [[1.1.0. Go Basics|Go]]
#### <u>Читать заголовки из запроса</u>:
```go
func handler(w http.ResponseWriter, r *http.Request) {
    fmt.Println("Тип содержимого:", r.Header.Get("Content-Type"))
    fmt.Println("Кто сделал запрос:", r.Header.Get("User-Agent"))
}
```
#### <u>Устанавливать заголовки в ответе</u>:
```go
w.Header().Set("Content-Type", "application/json")
w.WriteHeader(http.StatusOK)
fmt.Fprintln(w, `{"message":"ok"}`)
```

> Важно: заголовки нужно установить до того, как ты начал писать тело ответа.

> Как только сервер начал отправлять данные (`w.Write(...)`), заголовки **“зафиксированы”** и изменить их уже нельзя.

# <u>Тело запроса и ответа</u> ~ <font color="#ff0000">Body</font> ~

**Тело (body)** — это “*вложение*” в письме.
Если заголовки говорят _что внутри_ и _как это читать_, то **тело** содержит **сами данные** — текст, JSON, файл и т.д.

#### <u>Когда тело есть, а когда нет</u>:

| <u>Метод</u>                                                          | <u>Есть тело?</u>                 | <u>Пример</u>          |
| --------------------------------------------------------------------- | --------------------------------- | ---------------------- |
| <font color="#ff0000">GET</font>                                      | **Обычно нет (<u>всё в URL</u>)** | `/search?term=go`      |
| <font color="#ff0000">POST</font>                                     | **Да, почти всегда**              | *создаём новую запись* |
| <font color="#ff0000">PUT</font> / <font color="#ff0000">PATCH</font> | **Да**                            | *обновляем запись*     |
| <font color="#ff0000">DELETE</font>                                   | **Иногда нет**                    | *удаляем ресурс*       |

#### <u>Пример</u>: тело в запросе

Если клиент отправляет **JSON**, запрос может выглядеть так:
```
POST /users HTTP/1.1
Host: localhost:8080
Content-Type: application/json

{"name": "Катя", "age": 30}
```

#### <u>Как читать тело запроса</u> в [[1.1.0. Go Basics|Go]]:

В **Go** тело запроса доступно через `r.Body`.
Обычно его читают, если запрос содержит JSON или текст.
```go
func createUser(w http.ResponseWriter, r *http.Request) {
    // Ограничиваем размер тела (например, максимум 1 МБ)
    r.Body = http.MaxBytesReader(w, r.Body, 1<<20)
    defer r.Body.Close()

    // Читаем тело запроса
    data, err := io.ReadAll(r.Body)
    if err != nil {
        http.Error(w, "Ошибка при чтении тела", http.StatusBadRequest)
        return
    }

    fmt.Println("Получены данные:", string(data))
}
```

#### <u>Пример</u>: тело в ответе

Сервер может вернуть тело в любом формате — чаще всего **JSON**:
```go
func helloHandler(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusOK)

    // тело — это то, что отправляем клиенту
    fmt.Fprintln(w, `{"message": "Привет, мир!"}`)
}
```

#### <u>Когда тела нет совсем</u>

Иногда серверу не нужно отправлять данные — только сказать: “*всё хорошо*”.
В таких случаях тело просто опускается, а статус-код всё объясняет:
```go
w.WriteHeader(http.StatusNoContent) // 204 No Content
```

# Главное про ~ <font color="#ff0000">body</font> ~

- <u>Тело</u> — это **основное содержимое** запроса или ответа.
- **<u>Заголовки</u>** описывают: <u>что в теле</u> и <u>в каком формате</u>.
- У тела **может не быть содержимого**, например, при `204 No Content`.
- В [[1.1.0. Go Basics|Go]] <u>тело запроса читается через</u> `r.Body`, а <u>тело ответа пишется через</u> `w.Write()` или `fmt.Fprintln(w, ...)`.

# ~ <font color="#ff0000">encoding / json</font> ~ **и** ~ <font color="#ff0000">struct-теги</font> ~

#### <u>JSON</u> **→** <u>структура</u> *(из тела запроса)*:
```go
type User struct {
    Name string `json:"name"`
    Age  int    `json:"age"`
}

func createUserHandler(w http.ResponseWriter, r *http.Request) {
    if r.Method != http.MethodPost {
        http.Error(w, "Метод не поддерживается", http.StatusMethodNotAllowed)
        return
    }

    r.Body = http.MaxBytesReader(w, r.Body, 1<<20) // 1 МБ
    defer r.Body.Close()

    var u User
    if err := json.NewDecoder(r.Body).Decode(&u); err != nil {
        http.Error(w, "Невалидный JSON", http.StatusBadRequest) // 400
        return
    }

    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(http.StatusCreated) // 201
    json.NewEncoder(w).Encode(u)      // эхо созданного пользователя
}
```
#### <u>Структура</u> **→** <u>JSON</u> *(в тело ответа)*:
```go
type Info struct {
    Message string `json:"message"`
    Time    int64  `json:"time"`
}

func jsonHandler(w http.ResponseWriter, r *http.Request) {
    resp := Info{Message: "hello", Time: time.Now().Unix()}
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(resp) // по умолчанию 200 OK
}
```
#### <u>Полезные теги</u>:
```go
type User struct {
    Name  string `json:"name"`
    Age   int    `json:"age,omitempty"` // пустые значения не попадут в JSON
    Token string `json:"-"`             // никогда не включать в JSON
}
```

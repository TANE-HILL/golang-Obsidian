# Зачем нужен пакет ~ <font color="#ff0000">sync</font> ~

Когда программа работает с несколькими [[1.14. Goroutines|горутинами]], они часто **делят общие данные** — например, общий счётчик, [[1.6. Массивы и слайсы, работа под капотом|слайс]] или [[1.7. Map в Go - устройство и особенности|карту]].

Без синхронизации всё может пойти не так:

- данные обновляются **одновременно** из разных горутин;
- часть изменений теряется;
- программа ведёт себя **непредсказуемо**.

Такое поведение называется **гонкой данных (data race)**.

Чтобы избежать этого, Go предлагает **пакет `sync`**, который содержит набор инструментов для безопасной работы с горутинами:

|Инструмент|Что делает|
|---|---|
|`WaitGroup`|Ждёт завершения всех горутин|
|`Mutex`|Защищает общий ресурс от одновременного доступа|
|`RWMutex`|Разделяет доступ — одни читают, другие пишут|
|`Atomic`|Выполняет простые операции без блокировок|
|`Pool`|Позволяет переиспользовать объекты и экономить память|

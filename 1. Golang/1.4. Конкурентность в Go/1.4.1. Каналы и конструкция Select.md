На прошлом уроке были изучены [[1.4.0. Goroutines|горутины]].
Они позволяют выполнять несколько задач одновременно.

Но если горутины работают независимо — как им **обмениваться данными**?
*Например, одна горутина что-то считает, а другая должна вывести результат.* - Как передать это значение из одной в другую?

Для этого в [[1.1.0. Go Basics|Go]] есть встроенный механизм — **<u>каналы</u> (<font color="#ff0000">channels</font>)**.

Каналы позволяют горутинам **безопасно обмениваться данными**, не используя общие переменные.

---
# Что такое канал ~ <font color="#ff0000">chan</font> ~

**Каналы** (channels) представляют инструменты коммуникации между горутинами (это “трубка”, по которой данные передаются между горутинами).
В языке Go канал имеет определенный [[1.1.2. Типы данных|тип]], то есть тип значений, которые он может передавать из одной горутины в другую.

Для определения канала применяется ключевое слово **chan**:
```go
chan тип_элемента
```

После слова `chan` указывается тип данных, который будет передаваться с помощью канала, например:
```go
var intCh chan int
```
Здесь [[1.1.1. Переменные|переменная]] intCh представляет канал, который передает данные [[1.1.2. Типы данных|типа]] int.

При простом определении переменной канала она имеет значение **nil**, то есть по сути канал неинициализирован.

Можно это увидеть по консольному выводу:
```go
package main
import "fmt"
     
func main() { 
    var intCh chan int
    fmt.Println(intCh) // <nil>
}
```

Для инициализации канала применяется функция <font color="#ff0000">make()</font>. 

Объявление канала с помощью **make()** <u>резервирует место</u> в хранилище, <u>инициализирует память</u> и <u>создает базовый заголовок определенного типа</u>:
```go
package main
import "fmt"
     
func main() { 
    var intCh chan int = make(chan int) // канал для данных типа int
    // или так 
    //intCh := make(chan int) // канал для данных типа int
 
    fmt.Println(intCh) // 0xc000100070
}
```

---
# Отправка и получение данных

Для работы с каналом используется оператор `<-`:

- Отправить данные в канал:    
```go
intCh <- 5
```

- Получить данные из канала:
```go
val := <-intCh
```

Важно: тип данных должен совпадать с типом канала.

---
# Простая передача данных через канал

```go
package main
import "fmt"

func main() {
    intCh := make(chan int)

    go func() {
        fmt.Println("Горутина запущена")
        intCh <- 5 // отправляем число в канал
    }()

    fmt.Println(<-intCh) // получаем данные из канала
    fmt.Println("The End")
}
```

**Как это работает:**
1. `main` запускает горутину, которая отправляет число 5 в канал.
2. `main` блокируется на строке `<-intCh`, пока не получит данные.
3. Когда горутина отправляет 5, обе разблокируются и продолжают работу.

**Вывод:**
Каналы позволяют горутинам безопасно обмениваться данными — без общих переменных.

# Небуферизированные каналы

Если канал создаётся без указания размера, он **небуферизированный**:
```go
intCh := make(chan int)
```

В таком канале:
- Отправитель ждёт, пока кто-то **прочитает** данные.
- Получатель ждёт, пока кто-то **отправит** данные.

Это создаёт **синхронизацию** между горутинами — они “встречаются” в канале.

---
#### Передача числа между функциями:
```go
package main
import "fmt"

func main() {
    intCh := make(chan int)
    go square(5, intCh)
    fmt.Println(<-intCh)
    fmt.Println("The End")
}

func square(n int, ch chan int) {
    ch <- n * n // отправляем квадрат числа
}

```

**Как работает:**
- `main` создаёт канал и запускает горутину `square`.
- `square` считает `n * n` и отправляет результат в канал.
- `main` ждёт результат и печатает его.

**Вывод:**
Небуферизированный канал заставляет горутины работать синхронно — они ждут друг друга.

---
# Взаимная передача данных

Канал может использоваться и в обе стороны — горутины могут по очереди **отправлять и получать** данные:
```go
package main
import "fmt"

func main() {
    intCh := make(chan int)
    go square(intCh)
    intCh <- 4
    fmt.Println("result:", <-intCh)
}

func square(ch chan int) {
    num := <-ch
    fmt.Println("num:", num)
    ch <- num * num
}
```

**Что происходит:**
1. `main` создаёт канал и запускает горутину.
2. `square` ждёт число, `main` его отправляет.
3. После вычисления `square` отправляет результат обратно.

**Вывод:**
Канал — это двусторонний мост: горутины могут обмениваться данными в обе стороны.

---
# Буферизированные каналы

Каналы могут иметь **буфер** — то есть хранить несколько значений, пока их не прочитают.
```go
intCh := make(chan int, 3)
```

Теперь можно отправить до 3 значений, прежде чем канал заблокируется:
```go
intCh <- 10
intCh <- 20
intCh <- 30
fmt.Println(<-intCh) // 10
```

**Вывод:**
Буферизированные каналы позволяют временно хранить данные — удобно, когда горутина-получатель не всегда готова их сразу обрабатывать.
Работают каналы по принципу очереди: *"первым зашёл - первым вышел"*.

---
# Закрытие канала

Когда данные больше не будут отправляться, канал можно **закрыть**:
```go
close(intCh)
```

После закрытия:
- В канал **нельзя отправлять данные**.
- Но можно читать те, что уже там есть.

#### Пример 3. Проверка закрытия канала:
```go
package main
import "fmt"

func main() {
    intCh := make(chan int)
    go func() {
        intCh <- 10
        close(intCh)
    }()

    for {
        val, ok := <-intCh
        if !ok {
            fmt.Println("Канал закрыт")
            break
        }
        fmt.Println("Получено:", val)
    }
}
```

**Вывод:**
Закрытие канала сигнализирует другим горутинам, что данные закончились.

---
# Однонаправленные каналы

По умолчанию канал **двунаправленный** — можно и читать, и писать.
Но иногда удобно ограничить доступ, чтобы избежать ошибок.
```go
func send(ch chan<- int) { ch <- 42 }    // отправка
func receive(ch <-chan int) { fmt.Println(<-ch) } // чтение
```

**Вывод:**
Однонаправленные каналы помогают явно указать, кто отправляет, а кто получает.

---
# Синхронизация с помощью каналов

Иногда канал используется не для передачи данных, а для **сигналов** — например, чтобы сообщить о завершении работы.
```go
package main
import "fmt"

func sum(n int, done chan bool) {
    result := 0
    for i := 1; i <= n; i++ {
        result += i
    }
    fmt.Println("Сумма первых", n, "чисел =", result)
    done <- true // сигнал, что работа завершена
}

func main() {
    done := make(chan bool)
    for i := 1; i <= 3; i++ {
        go sum(i+3, done)
    }

    for i := 1; i <= 3; i++ {
        <-done // ждём завершения каждой горутины
    }
    fmt.Println("The End")
}
```

**Вывод:**
Каналы можно использовать как способ синхронизации — дождаться завершения всех горутин.

# Работа с несколькими каналами: оператор ~ <font color="#ff0000">select</font> ~

Когда программа использует несколько горутин, часто нужно **ждать данные сразу из нескольких каналов**.

Например, одна горутина считает квадрат числа, другая — куб, а третья возвращает удвоенное значение.

Как узнать, **какая из них первой вернёт результат**?

Для этого в Go есть оператор **`select`**.
Он похож на `switch`, но работает с операциями каналов.

---
# Принцип работы ~ <font color="#ff0000">select</font> ~

`select` ждёт выполнения одной из операций приёма или отправки данных через канал.
```go
select {
case val := <-ch1:
    fmt.Println("Получили из первого канала:", val)
case val := <-ch2:
    fmt.Println("Получили из второго канала:", val)
default:
    fmt.Println("Нет данных — выполняем что-то другое")
}
```
- если из какого-то канала пришли данные — выполняется соответствующий `case`;
- если готовых данных нет, а есть `default` — выполняется он;
- если `default` нет — программа **ждёт**, пока хотя бы один канал не станет готов.

#### Несколько горутин с разным временем выполнения:
```go
package main
import (
    "fmt"
    "time"
)

func square(ch chan int) {
    time.Sleep(200 * time.Millisecond)
    ch <- 9
}

func cube(ch chan int) {
    time.Sleep(500 * time.Millisecond)
    ch <- 27
}

func main() {
    sqrCh := make(chan int)
    cubeCh := make(chan int)

    go square(sqrCh)
    go cube(cubeCh)

    select {
    case val := <-sqrCh:
        fmt.Println("Square:", val)
    case val := <-cubeCh:
        fmt.Println("Cube:", val)
    }
}
```

**Что происходит:**
- обе горутины запускаются параллельно;
- `square` успевает завершиться первой, так как спит меньше;
- `select` выбирает тот `case`, где канал готов.

**Вывод:**
`select` ждёт первый готовый канал и обрабатывает только его.

---
# Использование `default`

Иногда не нужно ждать бесконечно — можно добавить блок `default`, чтобы выполнить альтернативное действие, если канал пока не готов.
```go
package main
import (
    "fmt"
    "time"
)

func main() {
    ch := make(chan int)

    go func() {
        time.Sleep(300 * time.Millisecond)
        ch <- 42
    }()

    select {
    case val := <-ch:
        fmt.Println("Получено:", val)
    default:
        fmt.Println("Нет данных, продолжаем работу")
    }
}
```

**Результат:**
```
Нет данных, продолжаем работу
```

**Вывод:**
`default` делает `select` **неблокирующим** — программа не ждёт канал, если данных пока нет.

# Обработка всех результатов

Обычно в `select` попадает только **один** `case`.

Но если нужно обработать все каналы, можно просто повторить `select` в цикле.
```go
package main
import "fmt"

func main() {
    ch1 := make(chan int)
    ch2 := make(chan int)
    ch3 := make(chan int)

    go func() { ch1 <- 2 }()
    go func() { ch2 <- 4 }()
    go func() { ch3 <- 6 }()

    for i := 0; i < 3; i++ {
        select {
        case val := <-ch1:
            fmt.Println("ch1:", val)
        case val := <-ch2:
            fmt.Println("ch2:", val)
        case val := <-ch3:
            fmt.Println("ch3:", val)
        }
    }
}
```

**Вывод:**
`select` в цикле позволяет обрабатывать данные **по мере их поступления** из разных каналов.

# Перебор канала с помощью ~ <font color="#ff0000">range</font> ~

Когда канал закрывается, часто нужно **прочитать все оставшиеся данные**. Для этого Go предоставляет конструкцию `for ... range`.
#### С ~ <font color="#ff0000">range</font> ~ просто и безопасно
```go
package main
import "fmt"

func main() {
    ch := make(chan int)

    go func() {
        for i := 1; i <= 5; i++ {
            ch <- i
        }
        close(ch) // закрываем канал
    }()

    // читаем все значения из канала
    for val := range ch {
        fmt.Println("Получено:", val)
    }

    fmt.Println("Канал закрыт")
}
```

**Как это работает:**
- пока канал открыт — `range` получает значения одно за другим;
- когда канал закрывается — цикл завершается автоматически.

**Вывод:**
`range` — это удобный и безопасный способ перебора всех данных из канала.

#### Как это выглядело бы без <font color="#ff0000">range</font>:
```go
package main
import "fmt"

func main() {
    ch := make(chan int)

    go func() {
        for i := 1; i <= 5; i++ {
            ch <- i
        }
        close(ch)
    }()

    for {
        val, ok := <-ch
        if !ok {
            // если канал закрыт — выходим из цикла
            break
        }
        fmt.Println("Получено:", val)
    }

    fmt.Println("Канал закрыт")
}
```

**Что здесь происходит:**
- мы вручную читаем из канала;
- переменная `ok` показывает, открыт канал (`true`) или уже закрыт (`false`);
- как только канал закрыт — выходим из цикла.

**Вывод:**
Без `range` нужно вручную проверять, не закрыт ли канал.

С `range` Go делает это автоматически, код получается чище и безопаснее.

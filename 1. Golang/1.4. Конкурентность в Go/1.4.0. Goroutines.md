# Что такое <font color="#ff0000">конкурентность</font> и зачем она нужна

**Одна из ключевых фишек [[1.1.0. Go Basics|Go]]** — подход к конкурентному программированию.

> Конкурентность (concurrency) — это умение программы выполнять несколько задач “одновременно”, не мешая друг другу.

> Это не обязательно параллелизм (одновременное выполнение на разных ядрах процессора), но возможность запускать несколько независимых процессов, которые делят время выполнения между собой.

#### Примеры из жизни:
- сервер Go обрабатывает десятки HTTP-запросов сразу;
- приложение скачивает несколько файлов одновременно;
- фоновые задачи выполняются, не мешая основной логике.

Во многих языках реализация конкурентности — это боль: сложные потоки, синхронизация, блокировки.

В Go же всё встроено прямо в язык. Чтобы запустить код конкурентно, достаточно написать **одно слово:** ~ <font color="#ff0000">go</font> ~

---
# Зачем нужны <font color="#ff0000">горутины</font>

Горутины — это **механизм конкурентности в Go**.

Они позволяют программе выполнять несколько задач **независимо друг от друга**, не блокируя основной поток.

Представь, что у тебя есть программа, которая должна делать сразу несколько дел: *скачивать файлы, считать данные и обновлять интерфейс*.
Если выполнять их **по очереди**, всё будет “замирать” во время каждой операции.

С горутинами — каждая из этих задач может работать **параллельно** с другими, а Go сам решает, как распределить их между процессорными ядрами.

---
## Что такое <font color="#ff0000">горутина</font>

**Горутина** — это лёгкий поток выполнения.

Её можно представить как “мини-программу внутри программы”, которая выполняется **параллельно** с другими.
Когда мы запускаем программу, в ней уже есть **одна** <font color="#ff0000">горутина</font> — это [[1.1.5. Функции и передача данных|функция]] <font color="#ff0000">main</font>.

Если в коде создать ещё несколько горутин, то Go распределит их между процессорными ядрами и выполнит их **одновременно** (если ядер несколько) или **по очереди**, но очень быстро переключаясь между ними.

---
# Как запустить <font color="#ff0000">горутину</font>

Чтобы запустить горутину, нужно перед вызовом функции поставить ключевое слово `go`:
```go
go имяФункции()
```
Это значит: **“запусти эту функцию в отдельной горутине и не жди её завершения”**.

---
#### Пример 1. Запуск нескольких горутин:
```go
package main
import "fmt"

func main() {
    for i := 1; i < 7; i++ {
        go sum(i)
    }
    fmt.Println("The End")
}

func sum(n int) {
    result := 0
    for i := 1; i <= n; i++ {
        result += i
    }
    fmt.Println(n, "-", result)
}

```
**Что делает программа:**
- В цикле запускается 6 горутин, каждая вызывает `sum(i)`.
- Каждая горутина считает сумму чисел от 1 до `i` и выводит результат.
- Функция `main` не ждёт, пока они закончат — сразу печатает `"The End"` и завершает программу.

**Результат может быть разным:**
```Run
The End
```
или
```Run
2 - 3
1 - 1
4 - 10
The End
5 - 15

```
#### Почему так происходит:

Главная горутина — это `main`.
Когда она завершается, **вся программа останавливается**, даже если другие горутины не успели завершиться. <u>Go не ждёт их по умолчанию</u>.

---
# Как дождаться выполнения <font color="#ff0000">горутин</font> *(первый способ)*

Чтобы “<u>заморозить</u>” выполнение программы до завершения горутин, можно временно использовать приём с `fmt.Scanln()`.

Эта функция ждёт ввода с клавиатуры, и программа не завершится, пока пользователь не нажмёт Enter:
```go
package main
import "fmt"

func main() {
    for i := 1; i < 7; i++ {
        go sum(i)
    }

    fmt.Scanln() // ждём ввода
    fmt.Println("The End")
}

```
**Теперь результат стабилен:**
```
3 - 6
4 - 10
1 - 1
2 - 3
5 - 15
6 - 21
The End

```

# Порядок выполнения горутин

Важно понимать: <u>Go не гарантирует порядок выполнения горутин</u>.
Кто закончит первой — зависит от планировщика Go и нагрузки на процессор.

Даже если запустить их в порядке 1,2,3,4,5,6 — на экране они могут вывестись как угодно.

---
# Анонимные <font color="#ff0000">горутины</font>

Горутины можно запускать не только с обычными функциями, но и с **анонимными** — то есть функциями без имени, прямо “на месте”.

#### Пример 2. Анонимная горутина:
```go
package main
import "fmt"

func main() {
    for i := 1; i < 7; i++ {
        go func(n int) {
            result := 0
            for j := 1; j <= n; j++ {
                result += j
            }
            fmt.Println(n, "-", result)
        }(i)
    }
    fmt.Scanln()
    fmt.Println("The End")
}

```
**Что здесь происходит:**
- В цикле создаётся анонимная функция.
- Ей сразу передаётся аргумент `i`.
- Она выполняется в отдельной горутине.

# Работа с пакетом <font color="#ff0000">time</font> *(второй способ)*

Иногда удобнее **приостановить** выполнение программы на короткое время.
Для этого используется пакет `time` и функция `Sleep()`.

#### Пример 3. Ожидание с <font color="#ff0000">time.Sleep</font>:
```go
package main
import (
    "fmt"
    "time"
)

func main() {
    for i := 1; i < 7; i++ {
        go sum(i)
    }
    time.Sleep(200 * time.Millisecond) // ждём 0.2 секунды
    fmt.Println("The End")
}

func sum(n int) {
    result := 0
    for i := 1; i <= n; i++ {
        result += i
    }
    fmt.Println(n, "-", result)
}

```
**Как работает:**
- После запуска всех горутин `main` ждёт 200 миллисекунд.
- За это время горутины успевают завершиться.
- Потом программа продолжает выполнение.

# <font color="#ff0000">Горутины</font> и ядра процессора

<u>Go умеет распределять горутины между разными ядрами процессора</u>.

Переменная окружения `GOMAXPROCS` управляет количеством ядер, доступных для выполнения программы.
По умолчанию Go использует **все доступные ядра**.

Это значит, что если у тебя процессор с 8 ядрами — <u>горутины могут реально выполняться параллельно</u>.

---
# Термины

#### **Гонка данных (data race)**
Это ситуация, когда **две или более горутины одновременно работают с одной и той же переменной**, и хотя бы одна из них её изменяет. Поскольку порядок выполнения горутин заранее неизвестен, результат может оказаться неправильным.

**Например:**
```Go
for i := 0; i < 5; i++ {
	go func() {
		counter++
	}()
}
```

#### **Атомарная операция**
Это операция, которую нельзя "прервать" посередине. Пока она выполняется, никакая другая горутина не может увидеть её незавершённое состояние.

Например, операция `counter++` *(из примера выше)* **не атомарна**. Она на самом деле состоит из трёх шагов:
1. прочитать значение `counter`;
2. прибавить `1`;
3. записать новое значение обратно.

Если в этот момент другая горутина тоже начнёт выполнять эти три шага, они могут пересечься, и одно из увеличений потеряется.

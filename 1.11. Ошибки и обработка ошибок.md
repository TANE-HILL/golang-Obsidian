# Зачем нужны ошибки и какую проблему они решают

#### Жизненная картина №1: «Файл отчёта»

Ты запускаешь программу: *«прочитай файл `report.csv` и посчитай сумму»*.

Проблемы в реальности: файл могут переименовать, путь окажется неправильным, прав нет, файл пустой.

**Без ошибок**: программа «молча» вернёт нули или упадёт.

**С ошибками**: функция чтения вернёт конкретную причину (файл не найден, нет прав, повреждён), а вызывающий код решит — попросить другой путь, создать файл, сообщить пользователю.

**Мини-пример**

```go
data, err := os.ReadFile("report.csv")
if err != nil {
    // сообщаем причину и выходим
    fmt.Println("не удалось прочитать отчёт:", err)
    return
}
fmt.Println("длина файла:", len(data))

```

**Зачем**: пользователь получает понятную причину, а программа остаётся под контролем, не падает.

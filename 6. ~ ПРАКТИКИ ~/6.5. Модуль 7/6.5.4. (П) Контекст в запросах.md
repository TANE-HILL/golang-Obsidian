# <u>Задание</u>

#### План реализации:
1. **Создать новый файл `handlers/slow.go`**
	Здесь будет хендлер `HandleSlowBook`, который имитирует долгую работу с таймаутом.
2. **Добавить маршрут в `main.go`**
	Добавить `mux.HandleFunc("/slow", handlers.HandleSlowBook)`.
3. **Используй контекст внутри обработчика**
	Создай контекст с таймаутом `context.WithTimeout(r.Context(), 3*time.Second)` и реагируй на сигналы `ctx.Done()`.
4. **Вывести сообщения в консоль**
	Чтобы видеть, что сервер правильно реагирует на отмену запроса и таймаут.
5. **Проверить через `curl`**
	Сделать запрос и прервать его вручную, а затем дождаться таймаута.

# <u>Решение</u>

**`slow.go`:**
```Go
package handlers  
  
import (  
    "context"  
    "fmt"    "net/http"    "time")  
  
func HandleSlowBook(w http.ResponseWriter, r *http.Request) {  
    ctx, cancel := context.WithTimeout(r.Context(), 3*time.Second)  
    defer cancel()  
    fmt.Println("Начали обработку запроса...")  
    select {  
    case <-time.After(5 * time.Second):  
       w.WriteHeader(http.StatusOK)  
       _, err := w.Write([]byte("Обработка выполнена"))  
       if err != nil {  
          return  
       }  
    case <-ctx.Done():  
       if ctx.Err() == context.Canceled {  
          fmt.Println("Клиент отменил операцию:", ctx.Err())  
       } else if ctx.Err() == context.DeadlineExceeded {  
          fmt.Println("Операция заняла слишком много времени:", ctx.Err())  
       }  
       return  
    }  
}
```

**Изменения в `main.go`:**
```Go
mux.HandleFunc("/slow", handlers.HandleSlowBook)
```

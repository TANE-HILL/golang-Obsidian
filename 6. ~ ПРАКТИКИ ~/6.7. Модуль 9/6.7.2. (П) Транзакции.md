# Что будет в практике

Ты уже умеешь добавлять данные в базу и получать их через `sqlx`.
Теперь ты научишься объединять **несколько SQL-запросов в одну транзакцию**, чтобы они выполнялись **целиком или не выполнялись вовсе**.
В этой практике ты расширишь свой проект **GoFinance**, добавив новую логику:
> При создании транзакции нужно одновременно обновлять баланс счёта.

Если хотя бы один из шагов не сработает — все изменения должны **откатиться**.

---
# Цель

Реализовать безопасную финансовую операцию, состоящую из двух SQL-запросов:
- добавить новую транзакцию в таблицу `transactions`;
- обновить баланс счёта в таблице `accounts`;

Оба действия должны выполняться **в рамках одной транзакции** (`BEGIN → COMMIT → ROLLBACK`).

---
## Техническое задание

### Описание

Добавить в проект **GoFinance** новую таблицу `accounts` и реализовать ручку `POST /transactions/with-account`, которая создаёт транзакцию и одновременно обновляет баланс выбранного счёта.

Если при обновлении баланса произойдёт ошибка — всё должно **откатиться** через `Rollback()`.

## Что нужно реализовать

### 1. Создай таблицу `accounts`
📄 `migrations/003_create_accounts.sql`

Создай таблицу для хранения счетов и их балансов.
Каждый счёт будет связан с транзакциями через `account_id`.

---
### 2. Добавь модель счёта
📄 `internal/models/account.go`

Опиши структуру `Account`, которая маппится на таблицу `accounts`.
Добавь поля: `ID`, `Name`, `Balance`.

---
### 3. Обнови репозиторий транзакций
📄 `internal/db/transaction_repo.go`

Добавь новый метод `CreateWithAccountUpdate(ctx, t, accountID)`:
- начинает SQL-транзакцию (`Beginx`);
- выполняет вставку в таблицу `transactions`;
- обновляет баланс в таблице `accounts`;
- делает `Commit()` при успехе;
- выполняет `Rollback()` при ошибке.

---
### 4. Добавь новый HTTP-хендлер
📄 `internal/handlers/transactions.go`

Создай обработчик `POST /transactions/with-account`, который принимает JSON:
```json
{
  "category_id": 1,
  "account_id": 1,
  "amount": 2000,
  "note": "Пополнение счета"
}
```
и вызывает метод `CreateWithAccountUpdate`.

Ответ должен возвращать JSON с созданной транзакцией.

---
### 5. Зарегистрируй новый маршрут
📄 `cmd/api/main.go`

Добавь маршрут `/transactions/with-account` и подключи новый хендлер.

## Проверка работы

### 1. Применить миграции
```bash
go run ./cmd/migrate up
```

### 2. Добавить тестовый счёт
*В PostgreSQL:*
```sql
INSERT INTO accounts (name, balance) VALUES ('Основной счёт', 5000);
```

### 3. Отправить транзакцию
```bash
curl -X POST <http://localhost:8080/transactions/with-account> \
  -H "Content-Type: application/json" \
  -d '{"category_id":1,"account_id":1,"amount":2000,"note":"Пополнение счета"}'
```
- В ответ ты получишь JSON с транзакцией, а баланс счёта в таблице `accounts` увеличится на 2000.

### 4. Проверить Rollback
*Отправь запрос с несуществующим `account_id`:*
```bash
curl -X POST <http://localhost:8080/transactions/with-account> \
  -H "Content-Type: application/json" \
  -d '{"category_id":1,"account_id":999,"amount":1000,"note":"Ошибка"}'
```
Результат:
```
Database error: account not found
```

Баланс счёта при этом **не изменится**, так как транзакция **откачена**.

## 3. `.../db/transaction_repo.go` *(новый метод)*:
```Go
//...
func (r *TransactionRepo) CreateWithAccountUpdate(ctx context.Context, t models.Transaction, accountID int) (models.Transaction, error) {  
    tx, err := r.db.Beginx()  
    if err != nil {  
       return models.Transaction{}, err  
    }  
    query := `  
    INSERT INTO transactions (category_id, amount, note)
    VALUES ($1, $2, $3)
    RETURNING id, category_id, amount, note, created_at`  
    var tr models.Transaction  
    err = tx.GetContext(  
       ctx,  
       &tr,  
       query,  
       t.CategoryID,  
       t.Amount,  
       t.Note,  
    )  
    if err != nil {  
       tx.Rollback()  
       return models.Transaction{}, err  
    }  
    query = `  
        UPDATE accounts
        SET balance = balance + $1
        WHERE id = $2`  
  
    result, err := tx.ExecContext(  
       ctx,  
       query,  
       t.Amount,  
       accountID,  
    )  
    if err != nil {  
       tx.Rollback()  
       return models.Transaction{}, err  
    }  
  
    rows, err := result.RowsAffected()  
    if err != nil {  
       tx.Rollback()  
       return models.Transaction{}, err  
    }  
  
    if rows == 0 {  
       tx.Rollback()  
       return models.Transaction{}, errors.New("account not found")  
    }  
    err = tx.Commit()  
    if err != nil {  
       return models.Transaction{}, err  
    }  
    return tr, nil  
}
```

## 4. `.../handlers/transactions.go` *(новый `handler`)*:
```Go
//...
func (h *TransactionHandlers) CreateTransactionWithAccount(w http.ResponseWriter, r *http.Request) {  
    if r.Method != http.MethodPost {  
       http.Error(w, "Method Not Allowed", http.StatusMethodNotAllowed)  
       return  
    }  
  
    var in struct {  
       CategoryID int     `json:"category_id"`  
       AccountID  int     `json:"account_id"`  
       Amount     float64 `json:"amount"`  
       Note       string  `json:"note"`  
    }  
  
    if err := json.NewDecoder(r.Body).Decode(&in); err != nil {  
       http.Error(w, "Invalid JSON", http.StatusBadRequest)  
       return  
    }  
  
    tr, err := h.repo.CreateWithAccountUpdate(  
       r.Context(),  
       models.Transaction{  
          CategoryID: in.CategoryID,  
          Amount:     in.Amount,  
          Note:       in.Note,  
       },  
       in.AccountID,  
    )  
    if err != nil {  
       http.Error(w, "Database error: "+err.Error(), http.StatusInternalServerError)  
       return  
    }  
  
    w.Header().Set("Content-Type", "application/json")  
    w.WriteHeader(http.StatusCreated)  
    json.NewEncoder(w).Encode(tr)  
}
```

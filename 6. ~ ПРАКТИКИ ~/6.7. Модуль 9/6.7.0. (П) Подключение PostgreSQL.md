# Проект GoFinance в модуле 9

Весь 9-й модуль посвящён **реальной работе с базой данных PostgreSQL**.
Чтобы учить это на практике, создадим **новый мини-проект** — финансовый сервис **GoFinance**.

## Идея проекта

GoFinance — это простой REST-сервис для **учёта личных финансов**.

Пользователь сможет:
- добавлять категории (например, “Еда”, “Транспорт”, “Фриланс”);
- создавать транзакции (доходы и расходы);
- просматривать список операций и баланс.


Пошагово, в течение модуля:

|Раздел|Что изучаем|На чём тренируемся|
|---|---|---|
|Подключение к PostgreSQL|создание соединения, .env, docker|создаём подключение к БД|
|CRUD-операции с SQL|SELECT, INSERT, UPDATE, DELETE|добавляем категории и транзакции|
|Транзакции|атомарность, `BEGIN/COMMIT/ROLLBACK`|делаем перевод между счетами|
|ORM и Query Builders|`sqlx`, `GORM`|упрощаем работу с БД|
|Миграции|структура и обновление схемы|применяем при запуске сервиса|
|REST API|`net/http` + база|создаём полноценные ручки|

# Задание к уроку

> Цель — подготовить основу будущего REST-сервиса GoFinance.

## 1. Создать проект и структуру папок

```bash
mkdir gofinance
cd gofinance
go mod init gofinance
mkdir -p cmd/api internal/db internal/handlers internal/models migrations
```

## 2. Настроить PostgreSQL

Создать `docker-compose.yml` и запустить контейнер:
```yaml
version: '3.8'
services:
  postgres:
    image: postgres:15
    container_name: gofinance-db
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: password
      POSTGRES_DB: gofinance
    ports:
      - "5432:5432"
    volumes:
      - ./pgdata:/var/lib/postgresql/data
```

```bash
docker compose up -d
```

## 3. Добавить `.env` с настройками

```
DATABASE_URL=postgres://postgres:password@localhost:5432/gofinance?sslmode=disable
PORT=8080
APP_ENV=local
```

и `.gitignore`:

```
.env
pgdata/
```

## 4. Подключиться к базе

**`cmd/api/main.go`:**
```go
package main

import (
    "database/sql"
    "fmt"
    "log"
    "os"

    _ "github.com/lib/pq"
    "github.com/joho/godotenv"
)

func main() {
    if err := godotenv.Load(); err != nil {
        log.Println("⚠️  Файл .env не найден")
    }

    connStr := os.Getenv("DATABASE_URL")

    db, err := sql.Open("postgres", connStr)
    if err != nil {
        log.Fatalf("Ошибка подключения: %v", err)
    }
    defer db.Close()

    if err := db.Ping(); err != nil {
        log.Fatalf("База недоступна: %v", err)
    }

    fmt.Println("✅ Подключение к PostgreSQL установлено!")
}
```

## 5. Проверить запуск

```bash
go run ./cmd/api
```
Результат:
```
✅ Подключение к PostgreSQL установлено!
```

# Решение

## **`main.go`**:
```Go
package main  
import (  
    "database/sql"  
    "fmt"
    "log"
    "os"
    
    "github.com/joho/godotenv"
    _ "github.com/lib/pq"  
)  
  
func main() {  
    if err := godotenv.Load(); err != nil {  
       log.Println(".env не найден")  
    }  
    connStr := os.Getenv("DATABASE_URL")  
    db, err := sql.Open("postgres", connStr)  
    if err != nil {  
       log.Fatalf("Ошибка подключения: %v", err)  
    }  
    defer db.Close()  
    if err := db.Ping(); err != nil {  
       log.Fatalf("База недоступна: %v", err)  
    }  
    fmt.Println("✅ Подключение к PostgreSQL установлено!")  
}
```

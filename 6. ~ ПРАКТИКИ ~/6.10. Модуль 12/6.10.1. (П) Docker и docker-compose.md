# Цель

Научиться:
- создавать Dockerfile с нуля;
- собирать из него Docker-образ;
- запускать контейнер с приложением.
---
## 1. Создай файл `Dockerfile` в корне проекта

📁 Структура проекта теперь выглядит так:

```
GoShop/
├── cmd/
│   ├── main.go
│   └── subscriber.go
├── internal/
│   ├── db/
│   ├── cache/
│   ├── handlers/
│   ├── services/
│   └── models/
├── docker-compose.yml     cоздаём docker-compose
├── go.mod
├── go.sum
├── .env
├── .gitignore
└── Dockerfile             создаём Dockerfile

```

---
## 📘 2. Опиши Dockerfile

`Dockerfile`
```docker
# Этап 1: сборка бинарника
FROM golang:1.25 AS builder

# Рабочая директория внутри контейнера
WORKDIR /app

# Копируем go.mod и go.sum для кэширования зависимостей
COPY go.mod go.sum ./
RUN go mod download

# Копируем остальной код
COPY . .

# Собираем бинарник
RUN go build -o goshop ./cmd/main.go

# Этап 2: минимальный образ для запуска
FROM debian:bookworm-slim

WORKDIR /app

# Копируем бинарник из первого образа
COPY --from=builder /app/goshop .

# Указываем порт, который слушает приложение
EXPOSE 8080

# Запускаем приложение
CMD ["./goshop"]
```

---
## Разберём пошагово

|Этап|Что делает|
|---|---|
|`FROM golang:1.25 AS builder`|создаёт временный контейнер с установленным Go|
|`WORKDIR /app`|рабочая папка внутри контейнера|
|`COPY go.mod go.sum .` + `RUN go mod download`|загружает зависимости (и кэширует их)|
|`COPY . .`|копирует весь код в контейнер|
|`RUN go build`|собирает бинарник `goshop`|
|`FROM debian:bookworm-slim`|создаёт второй “чистый” образ|
|`COPY --from=builder`|переносит бинарник в финальный контейнер|
|`EXPOSE 8080`|объявляет порт для приложения|
|`CMD ["./goshop"]`|запускает программу|

## 3. Создай `docker-compose.yml`

📄 `docker-compose.yml`
```yaml
version: '3.9'

services:
  # --- PostgreSQL ---
  postgres:
    image: postgres:15
    container_name: goshop-postgres
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: goshop
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  # --- Redis ---
  redis:
    image: redis:7
    container_name: goshop-redis
    ports:
      - "6379:6379"

  # --- Zookeeper (для Kafka) ---
  zookeeper:
    image: bitnami/zookeeper:3.9
    container_name: zookeeper
    environment:
      - ALLOW_ANONYMOUS_LOGIN=yes
    ports:
      - "2181:2181"

  # --- Kafka ---
  kafka:
    image: bitnami/kafka:3.7
    container_name: kafka
    depends_on:
      - zookeeper
    environment:
      - KAFKA_BROKER_ID=1
      - KAFKA_CFG_ZOOKEEPER_CONNECT=zookeeper:2181
      - ALLOW_PLAINTEXT_LISTENER=yes
      - KAFKA_CFG_LISTENERS=PLAINTEXT://:9092
      - KAFKA_CFG_ADVERTISED_LISTENERS=PLAINTEXT://localhost:9092
    ports:
      - "9092:9092"

  # --- GoShop приложение ---
  goshop:
    build: .
    container_name: goshop-api
    ports:
      - "8080:8080"
    depends_on:
      - postgres
      - redis
      - kafka
    env_file:
      - .env

volumes:
  postgres_data:
```

---
## Разбор docker-compose.yml

|Раздел|Что делает|
|---|---|
|`services:`|список всех контейнеров проекта|
|`postgres`, `redis`, `kafka`, `goshop`|отдельные сервисы|
|`image:`|откуда брать базовый образ|
|`build: .`|собери образ из текущего Dockerfile|
|`depends_on:`|порядок запуска контейнеров|
|`env_file:`|подгрузка переменных окружения|
|`ports:`|пробрасывание портов наружу|
|`volumes:`|сохранение данных (например, БД) между перезапусками|

---
## 4. Собери и запусти всё окружение

В корне проекта выполни:
```bash
docker compose up --build
```

Docker:
1. соберёт образ `goshop`;
2. запустит контейнеры: `postgres`, `redis`, `kafka`, `zookeeper`, `goshop-api`;
3. создаст общую сеть для их взаимодействия.

---
## 5. Проверь, что всё работает

Открой новый терминал и выполни:
```bash
docker ps
```

Ты должен увидеть примерно следующее:
```
CONTAINER ID   NAME             STATUS          PORTS
a12b3c4d5e6f   goshop-api       Up 10 seconds   0.0.0.0:8080->8080/tcp
b23c4d5e6f7g   goshop-postgres  Up 10 seconds   0.0.0.0:5432->5432/tcp
c34d5e6f7g8h   goshop-redis     Up 10 seconds   0.0.0.0:6379->6379/tcp
d45e6f7g8h9i   kafka            Up 10 seconds   0.0.0.0:9092->9092/tcp
```

Теперь можно протестировать API:
```bash
curl <http://localhost:8080/products/1>
```

или создать заказ:
```bash
curl -X POST <http://localhost:8080/orders> \
  -H "Content-Type: application/json" \
  -d '{"product_id":1,"quantity":2,"total":5000}'
```

---
## 6. Управление контейнерами

|Команда|Что делает|
|---|---|
|`docker compose down`|остановить и удалить все контейнеры|
|`docker compose down -v`|удалить также тома (всё с нуля)|
|`docker compose logs`|показать логи всех контейнеров|
|`docker compose ps`|список запущенных сервисов|

---
## Возможные ошибки

|Ошибка|Причина|Решение|
|---|---|---|
|`connection refused` при подключении к БД|неправильный `DB_URL`|используй `postgres` вместо `localhost`|
|Kafka не стартует|не запущен ZooKeeper|проверь `depends_on`|
|Redis не отвечает|порт уже занят|останови локальный Redis|
|`build failed`|нет Dockerfile или ошибка пути|проверь структуру проекта|

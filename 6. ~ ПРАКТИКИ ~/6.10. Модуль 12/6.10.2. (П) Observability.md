## 2. Добавь healthcheck endpoint

📄 `cmd/main.go`

Добавь простой эндпоинт `/healthz`, который возвращает `200 OK`.
```go
package main

import (
	"fmt"
	"log"
	"net/http"

	"GoShop/internal/cache"
	"GoShop/internal/db"
	"GoShop/internal/events"
	"GoShop/internal/handlers"
	"GoShop/internal/services"
)

func main() {
	// --- Подключения ---
	dsn := "postgres://postgres:postgres@postgres:5432/goshop?sslmode=disable"

	dbConn, err := db.NewPostgres(dsn)
	if err != nil {
		log.Fatal(err)
	}

	redisCache := cache.NewProductCache("redis:6379")
	publisher := events.NewPublisher("kafka:9092", "orders")

	productRepo := db.NewProductRepo(dbConn)
	orderRepo := db.NewOrderRepo(dbConn)

	productService := services.NewProductService(productRepo, redisCache)
	orderService := services.NewOrderService(orderRepo, publisher)

	productHandler := handlers.NewProductHandler(productService)
	orderHandler := handlers.NewOrderHandler(orderService)

	// --- Маршруты ---
	http.HandleFunc("/products/", productHandler.GetProduct)
	http.HandleFunc("/orders", orderHandler.CreateOrder)

	// ✅ Healthcheck
	http.HandleFunc("/healthz", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusOK)
		w.Write([]byte("OK"))
	})

	// 🚀 Запуск сервера
	log.Println("🚀 Server started on :8080")
	if err := http.ListenAndServe(":8080", nil); err != nil {
		log.Fatal(err)
	}
}
```
- Теперь по адресу http://localhost:8080/healthz сервис вернёт `OK`, если всё в порядке.

## 3. Добавь метрики Prometheus

Установи библиотеку:
```bash
go get github.com/prometheus/client_golang/prometheus
```

В `cmd/main.go` добавь импорт и новый маршрут:
```go
import (
    "github.com/prometheus/client_golang/prometheus/promhttp"
)
```

Внутри `main()` после всех маршрутов добавь:
```go
// Метрики Prometheus
http.Handle("/metrics", promhttp.Handler())
```
- Теперь Prometheus сможет собирать статистику по адресу:
	http://localhost:8080/metrics

## 4. Создай конфиг Prometheus

📄 `monitoring/prometheus.yml`
```yaml
global:
  scrape_interval: 5s

scrape_configs:
  - job_name: 'goshop'
    static_configs:
      - targets: ['goshop-api:8080']
```

**Prometheus будет каждые 5 секунд забирать метрики из контейнера `goshop-api`.**

| <u>Строка</u>                  | <u>Что делает</u>                                                    |
| ------------------------------ | -------------------------------------------------------------------- |
| **`global:`**                      | *Глобальные настройки Prometheus*                                    |
| **`scrape_interval: 5s`**          | *Каждые **5 секунд** Prometheus будет опрашивать указанные сервисы*  |
| **`scrape_configs:`**              | *Список заданий, откуда собирать метрики*                            |
| **`job_name: 'goshop'`**           | *Имя задачи (группы метрик) — просто метка, чтобы различать сервисы* |
| **`static_configs:`**              | *Указываем конкретные адреса, куда Prometheus должен ходить*         |
| **`targets: ['goshop-api:8080']`** | *Контейнер `goshop-api` (наш сервер) и его порт с `/metrics`*        |

## 5. Обнови `docker-compose.yml`

Добавь два новых контейнера — **Prometheus** и **Grafana**.

📄 `docker-compose.yml`
```yaml
version: '3.9'

services:
  postgres:
    image: postgres:15
    container_name: goshop-postgres
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: postgres
      POSTGRES_DB: goshop
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:7
    container_name: goshop-redis
    ports:
      - "6379:6379"

  zookeeper:
    image: bitnami/zookeeper:3.9
    container_name: zookeeper
    environment:
      - ALLOW_ANONYMOUS_LOGIN=yes
    ports:
      - "2181:2181"

  kafka:
    image: bitnami/kafka:3.7
    container_name: kafka
    depends_on:
      - zookeeper
    environment:
      - KAFKA_BROKER_ID=1
      - KAFKA_CFG_ZOOKEEPER_CONNECT=zookeeper:2181
      - ALLOW_PLAINTEXT_LISTENER=yes
      - KAFKA_CFG_LISTENERS=PLAINTEXT://:9092
      - KAFKA_CFG_ADVERTISED_LISTENERS=PLAINTEXT://kafka:9092
    ports:
      - "9092:9092"

  goshop:
    build: .
    container_name: goshop-api
    ports:
      - "8080:8080"
    depends_on:
      - postgres
      - redis
      - kafka
    env_file:
      - .env

  # --- Prometheus ---
  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    volumes:
      - ./monitoring/prometheus.yml:/etc/prometheus/prometheus.yml
    ports:
      - "9090:9090"
    depends_on:
      - goshop

  # --- Grafana ---
  grafana:
    image: grafana/grafana:latest
    container_name: grafana
    ports:
      - "3000:3000"
    depends_on:
      - prometheus

volumes:
  postgres_data:

```

## 7. Проверь работу мониторинга

### 1. Healthcheck
```bash
curl <http://localhost:8080/healthz>
→ OK
```
### 2. Метрики
```bash
curl <http://localhost:8080/metrics>
```
Результат:
```
go_goroutines 10
http_requests_total 5
go_memstats_alloc_bytes 1.7e+06
...
```
### 3. Prometheus
Открой в браузере:
	http://localhost:9090
В поле поиска введи:
```
go_goroutines
```
- получишь числовое значение метрики.
### 4. Grafana
Открой:
	http://localhost:3000
Войди:
```
login: admin
password: admin
```
- Перейди в **Connections → Data sources → Add data source**
- Выбери **Prometheus**
- Укажи URL:
```
<http://prometheus:9090>
```
- Нажми **Save & Test**

Затем создай дашборд:
- Add dashboard → Add visualization → выбери Prometheus
- Введи запрос:
```
http_requests_total
```
- Нажми **Run query**
	появится график количества запросов.

|Команда|Описание|
|---|---|
|`docker compose down`|остановить все контейнеры|
|`docker compose logs -f prometheus`|показать логи Prometheus|
|`docker compose restart grafana`|перезапустить Grafana|
|`docker ps`|список запущенных сервисов|

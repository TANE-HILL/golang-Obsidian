## Что стоит разобрать подробнее

<u>Makefile</u> — это **файл автоматизации**, который позволяет запускать команды по коротким именам, например `make run`, `make build`, `make test`.

Он нужен для:
- удобного запуска рутинных команд: сборки, тестирования, запуска сервера и миграций;
- стандартизации: каждый разработчик в команде использует одни и те же команды;
- интеграции с CI/CD: pipeline может вызывать `make test` и `make build`.

## Как работает Makefile

Это обычный текстовый файл с именем `Makefile`, в котором описываются **цели (targets)** и команды, которые должны выполниться.

```
.PHONY: build run test

build:
	go build -o bin/gotracker cmd/api/main.go

run:
	go run ./cmd/api

test:
	go test ./...
```

## Что значат эти блоки

- `.PHONY:` объявляет виртуальные цели, которые не связаны с файлами. Это хорошая практика.
- `build:` — цель, запускаемая командой `make build`.
- `run:` — цель, запускаемая командой `make run`.
- `test:` — цель, запускаемая командой `make test`.
- Команды внутри цели должны начинаться с **табуляции**, а не с пробелов.

## Пример Makefile для GoTracker

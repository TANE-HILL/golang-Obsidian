# Пробуем Git на простом проекте

Цель — пройти весь путь руками: от создания проекта в GoLand до загрузки его в GitLab.

---
## Шаг 1. Создай небольшой проект

1. В GoLand нажми **File → New Project → Go**.
2. Назови папку, например, `git-practice`.
3. Убедись, что у тебя установлен `go mod init`, чтобы появился `go.mod`.

---

### Шаг 2. Напиши простой код

📄 **internal/greeting/greeting.go**
```go
package greeting

import "fmt"

func Hello(name string) {
	fmt.Printf("Привет, %s!\n", name)
}
```

📄 **main.go**
```go
package main

import "git-practice/internal/greeting"

func main() {
	greeting.Hello("мир")
}
```

Здесь мы просто создаём маленький пакет `greeting` и вызываем его из `main`.
Главное — чтобы у проекта была хоть какая-то структура, а не один файл.

---
### Шаг 3. Инициализируй Git

Открой встроенный терминал GoLand и введи:
```bash
git init
git add .
git commit -m "init: первый коммит проекта"
```

---
### Шаг 4. Создай репозиторий на GitLab

1. Перейди в [GitLab](https://gitlab.com/).
2. Нажми **New project → Create blank project**.
3. Назови репозиторий `git-practice`.
4. Скопируй ссылку, например:
```
<https://gitlab.com/username/git-practice.git>
```

---
### Шаг 5. Привяжи локальный проект к GitLab

```bash
git remote add origin <https://gitlab.com/username/git-practice.git>
git push -u origin main
```

💬 Теперь твой код доступен онлайн.
Перейди в GitLab — увидишь те же файлы `main.go` и `internal/greeting/`.

---
### Шаг 6. Сделай пару коммитов

Измени что-нибудь в коде — например, добавь новую функцию:

📄 **internal/greeting/greeting.go**
```go
func Bye(name string) {
	fmt.Printf("Пока, %s!\n", name)
}
```

📄 **main.go**
```go
func main() {
	greeting.Hello("мир")
	greeting.Bye("мир")
}
```

Сохрани изменения и зафиксируй их:
```bash
git add .
git commit -m "feat: добавлено прощание"
git push
```

---
### Шаг 7. Посмотри историю

Проверь, как Git хранит твои изменения:
```bash
git log --oneline
```

Пример вывода:
```
b4e1d2c feat: добавлено прощание
a1b2c3d init: первый коммит проекта
```

Теперь у тебя две версии проекта, и ты можешь в любой момент вернуться к первой.

# Изменения после модуля 7

## 1. **`001_create_orders.sql`**
```PostgreSQL
CREATE TABLE IF NOT EXISTS orders (  
    id INTEGER PRIMARY KEY,  
    customer TEXT NOT NULL,  
    address TEXT NOT NULL,  
    is_delivered BOOLEAN NOT NULL DEFAULT FALSE,  
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP  
);
```

## 2. **`queries.sql`**
```PostgreSQL
-- Добавление нового заказа  
INSERT INTO orders (id, customer, address)  
VALUES (1, 'Александр Авдеев', 'Сити-17');  
  
-- Получение всех заказов  
SELECT * FROM orders;  
  
-- Обновление статуса заказа  
UPDATE orders SET is_delivered = TRUE WHERE id = 1;  
  
-- Удаление заказа  
DELETE FROM orders WHERE id = 1;  
  
-- Агрегация, количество (не)доставленных заказов  
SELECT is_delivered, COUNT(*) AS order_count FROM orders  
GROUP BY is_delivered;
```

## 🧱 Как применить миграцию вручную  
  
1. Убедись, что у тебя запущен PostgreSQL  
2. В терминале введи:  
  
```bash  
psql -U postgres -d gotracker -f migrations/001_create_orders.sql
```  
3. Убедись, что таблица создана:  
```PostgreSQL  
SELECT * FROM orders;  
```

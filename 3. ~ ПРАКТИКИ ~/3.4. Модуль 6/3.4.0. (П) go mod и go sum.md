# <u>Задание</u>

#### 1. Создай модуль

1. Создай папку `geom` и инициализируй новый модуль через:
```bash
go mod init github.com/username/geom    
```
2. Убедись, что в папке появился файл `go.mod`.

#### 2. Опиши интерфейс

Создай интерфейс `Shape`, который должен описывать все геометрические фигуры.

Он должен включать методы:
- `Area() float64` — возвращает площадь;
- `Perimeter() float64` — возвращает периметр.

#### 3. Реализуй фигуры

Добавь несколько структур, каждая из которых реализует интерфейс `Shape`:
1. **Круг (Circle)**
    - Поле: `Radius float64`
    - Формулы:
        - `Площадь = π * r²`
        - `Периметр = 2 * π * r`
2. **Прямоугольник (Rectangle)**
    - Поля: `Width`, `Height`
    - Формулы:
        - `Площадь = width * height`
        - `Периметр = 2 * (width + height)`
3. **Треугольник (Triangle)**
    - Поля: `A`, `B`, `C` (три стороны)
    - Формулы:
        - Полупериметр `p = (A + B + C) / 2`
        - Площадь по формуле Герона:
            `√(p * (p - A) * (p - B) * (p - C))`
        - Периметр = `A + B + C`
4. **Квадрат (Square)**
    - Поле: `Side float64`
    - Формулы:
        - `Площадь = side²`
        - `Периметр = 4 * side`

#### 4. Добавь общий вывод информации

Добавь отдельную функцию `PrintShapeInfo(s Shape)`, которая:
- принимает любую фигуру (интерфейс `Shape`);
- выводит в консоль:
    - тип фигуры (например, “Circle”);
    - её площадь и периметр (с округлением до двух знаков).
Для округления можно использовать функцию `fmt.Printf` с форматом `%.2f`.

#### 5. Создай отдельный проект для теста

1. Выйди из папки `geom` и создай новый проект:
```bash
mkdir geomtest
cd geomtest
go mod init geomtest
```
2. Создай `main.go`, где ты:
    - Импортируешь свой модуль `github.com/username/geom`;
    - Создаёшь несколько фигур (`Circle`, `Rectangle`, `Triangle`, `Square`);
    - Для каждой вызываешь `PrintShapeInfo`.

#### 6. Настрой локальный импорт

Так как модуль пока не опубликован на GitHub, добавь в `geomtest/go.mod` строку:
```go
replace github.com/username/geom => ../geom
```
Это скажет Go использовать **локальную папку `geom`**, а не искать модуль в интернете.

#### 7. Проверь работу

1. Выполни:
```bash
go mod tidy
go run .    
```
2. Убедись, что программа корректно считает площадь и периметр каждой фигуры.
Например:    
```
=== Circle ===
Площадь: 78.54
Периметр: 31.42    

=== Rectangle ===
Площадь: 12.00
Периметр: 14.00
```

<u><font color="#4bacc6">geom</font>/geom.go:</u>
```Go
package geom  
import (  
    "fmt"  
    "math"
    )  
const Pi float64 = 3.141592653589793  
  
type Shape interface {  
    Area() float64  
    Perimeter() float64  
}  
type Circle struct {  
    Radius float64  
}  
  
func (c *Circle) Area() float64 {  
    return Pi * c.Radius * c.Radius  
}  
  
func (c *Circle) Perimeter() float64 {  
    return 2 * Pi * c.Radius  
}  
  
type Rectangle struct {  
    Width  float64  
    Height float64  
}  
  
func (r *Rectangle) Area() float64 {  
    return r.Width * r.Height  
}  
  
func (r *Rectangle) Perimeter() float64 {  
    return 2 * (r.Width + r.Height)  
}  
  
type Triangle struct {  
    A float64  
    B float64  
    C float64  
}  
  
func (t *Triangle) p() float64 {  
    return (t.A + t.B + t.C) / 2  
}  
  
func (t *Triangle) Area() float64 {  
    return math.Sqrt(t.p() * (t.p() - t.A) * (t.p() - t.B) * (t.p() - t.C))  
}  
  
func (t *Triangle) Perimeter() float64 {  
    return t.A + t.B + t.C  
}  
  
type Square struct {  
    Side float64  
}  
  
func (s *Square) Area() float64 {  
    return s.Side * s.Side  
}  
  
func (s *Square) Perimeter() float64 {  
    return 4 * s.Side  
}  
  
func PrintShapeInfo(s Shape) {  
    switch s.(type) {  
    case *Circle:  
       fmt.Println("Circle")  
    case *Rectangle:  
       fmt.Println("Rectangle")  
    case *Triangle:  
       fmt.Println("Triangle")  
    case *Square:  
       fmt.Println("Square")  
    }  
  
    fmt.Printf("Площадь: %.2f\n", s.Area())  
    fmt.Printf("Периметр: %.2f\n", s.Perimeter())  
}
```

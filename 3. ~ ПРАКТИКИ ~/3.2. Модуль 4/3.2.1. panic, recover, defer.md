# Задача 1

**Формулировка:**
Смоделируйте действие, которое сообщает о старте, делает работу и гарантированно сообщает о завершении при выходе из функции.

- Создать функцию `reportAction(action string)`.
- В начале вывести: `Старт: <action>`.
- Добавить отложенный вывод: `Завершение: <action>`.
- Между ними вывести: `В процессе: <action>`.
- В `main()` вызвать `reportAction("Импорт данных")`.

**Решение:**
```Go
package main  
import "fmt"  
func reportAction(action string) {  
    fmt.Println("Старт:", action)  
    defer fmt.Println("Завершение:", action)  
    fmt.Println("В процессе:", action)  
}  
func main() {  
    reportAction("Импорт данных")  
}
```
**Вывод:**
```Run
Старт: Импорт данных
В процессе: Импорт данных
Завершение: Импорт данных
```

# Задача 2

**Формулировка:**
Сделайте функцию, которая выполняет N шагов и выводит общий итог только при выходе из функции с помощью `defer`.

- Создать функцию `runSteps(steps int)`.
- Объявить переменную `done := 0`.
- Через `defer` в конце вывести: `Итого выполнено шагов: <done>`.
- Выполнить цикл от 1 до `steps`, на каждом шаге выводить `Шаг i` и увеличивать `done`.
- В `main()` вызвать `runSteps(4)`.

**Решение:**
```Go
package main  
import "fmt"  
func runSteps(steps int) {  
    done := 0  
    defer func() { fmt.Println("Итого выполнено шагов:", done) }()  
    for i := 1; i <= steps; i++ {  
       fmt.Println("Шаг", i)  
       done = i  
    }  
}  
func main() {  
    runSteps(6)  
}
```
**Вывод:**
```Run
Шаг 1
Шаг 2
Шаг 3
Шаг 4
Итого выполнено шагов: 4
```

# Задача 3

**Формулировка:**
Проверьте порядок срабатывания нескольких `defer`, размещённых в разных местах функции.

- Создать функцию `sequenceDemo()`.
- В начале вывести `Старт`.
- Сразу после этого добавить `defer` с сообщением `Завершение (A)`.
- Вывести `Обработка...`.
- После этой строки добавить второй `defer` с сообщением `Завершение (B)`.
- В конце функции вывести `Выход`.
- В `main()` вызвать `sequenceDemo()`.

**Решение:**
```Go
package main  
import "fmt"  
func sequenceDemo() {  
    fmt.Println("Старт")  
    defer fmt.Println("Завершение [A]")  
    fmt.Println("Обработка")  
    defer fmt.Println("Завершение [B]")  
    fmt.Println("Выход")  
}  
  
func main() {  
    sequenceDemo()  
}
```
**Вывод:**
```Run
Старт
Обработка
Выход
Завершение [B]
Завершение [A]
```

# Задача 4

**Формулировка:**
Разберитесь, влияет ли `defer` на возвращаемое значение, если оно не именовано.

- Создать функцию `calcBase() int`.
- Внутри объявить локальную переменную `base := 10`.
- Добавить `defer`, который увеличивает `base` на 5 (например, `base += 5`).
- Вернуть `base`.
- В `main()` вывести результат `calcBase()`.

**Решение:**
```Go
package main  
import "fmt"  
func calcBase() int {  
    base := 10  
    defer func() { base += 5 }()  
    return base  
}  
func main() {  
    fmt.Println(calcBase())  
}
```
**Вывод:**
```Run
10
```

# Задача 5

**Формулировка:**
Создайте функцию, которая моделирует запуск программы, и вызывает панику, если не найден важный параметр конфигурации.

- Создать функцию `initConfig(config map[string]string)`.
- Проверить наличие ключа `"host"`.
- Если ключ отсутствует — вызвать `panic("отсутствует параметр host в конфигурации")`.
- Если есть — вывести `"конфигурация загружена"`.
- В `main()` вызвать `initConfig(map[string]string{})` и затем `initConfig(map[string]string{"host": "localhost"})`.

**Решение:**
```Go
package main  
import "fmt"  
func initConfig(config map[string]string) {  
    if config["host"] == "" {  
       panic("отсутствует параметр host в конфигурации")  
    } else {  
       fmt.Println("конфигурация загружена")  
    }  
}  
func main() {  
    initConfig(map[string]string{})  
    initConfig(map[string]string{"host": "localhost"})  
}
```
**Вывод:**
```Run
panic: отсутствует параметр host в конфигурации
```

# Задача 6

**Формулировка:**
Напишите функцию, которая проверяет срез чисел.
Если в нём встречаются отрицательные значения — вызывается паника.

- Создать функцию `checkData(data []int)`.
- Пройтись по всем элементам:
    - Если число отрицательное — вызвать `panic("обнаружено отрицательное значение")`.
    - Иначе вывести `"OK:", значение`.
- В `main()` вызвать `checkData([]int{10, 5, -3, 7})`.

**Решение:**
```Go
package main  
import "fmt"  
func checkData(data []int) {  
    for _, v := range data {  
       if v < 0 {  
          panic("обнаружено отрицательное значение")  
       } else {  
          fmt.Println("OK:", v)  
       }  
    }  
}  
func main() {  
    checkData([]int{10, 5, -3, 7})  
}
```
**Вывод:**
```Run
OK: 10
OK: 5
panic: обнаружено отрицательное значение
```

```Go
}
```

# Задача 8

Создайте функцию, которая принимает возраст пользователя.
Если значение отрицательное или слишком большое — программа завершается паникой.

- Создать функцию `setAge(age int)`.
- Если `age < 0` или `age > 130` — вызвать `panic("возраст вне допустимого диапазона")`.
- Иначе вывести `"возраст установлен:", age`.

```Go
package main import "fmt"  
func setAge(age int) {

    }  
}  
func main() {  
    setAge(25)  
    setAge(200)  
}
```
**Вывод:**
```Run
возраст установлен: 25
panic: возраст вне допустимого диапазона
```

Создайте систему заказов, где заказ не может быть создан без товаров.
Если список товаров пуст — вызвать панику.

- Создать структуру `Order` с полем `Items []string`.
- Создать функцию `createOrder(o Order)`.
- Если `len(o.Items) == 0` — вызвать `panic("невозможно создать заказ без товаров")`.
- Иначе вывести `"заказ успешно создан"`.
- В `main()` вызвать `createOrder(Order{Items: []string{}})` и `createOrder(Order{Items: []string{"Телефон"}})`.

**Решение:**
```Go
package main  
import "fmt"  
type Order struct {  
    Items []string  
}  
func createOrder(o Order) {

       panic("невозможно создать заказ без товаров")

       fmt.Println("заказ успешно создан")  
    }  
}  
func main() {  
    createOrder(Order{Items: []string{}})  
    createOrder(Order{Items: []string{"Телефон"}})  
}
```
**Вывод:**
```Run
panic: невозможно создать заказ без товаров
```

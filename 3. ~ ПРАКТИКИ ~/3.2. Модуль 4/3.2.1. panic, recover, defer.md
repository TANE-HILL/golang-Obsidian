# Задача 1

**Формулировка:**
Смоделируйте действие, которое сообщает о старте, делает работу и гарантированно сообщает о завершении при выходе из функции.

- Создать функцию `reportAction(action string)`.
- В начале вывести: `Старт: <action>`.
- Добавить отложенный вывод: `Завершение: <action>`.
- Между ними вывести: `В процессе: <action>`.
- В `main()` вызвать `reportAction("Импорт данных")`.

**Решение:**
```Go
package main  
import "fmt"  
func reportAction(action string) {  
    fmt.Println("Старт:", action)  
    defer fmt.Println("Завершение:", action)  
    fmt.Println("В процессе:", action)  
}  
func main() {  
    reportAction("Импорт данных")  
}
```
**Вывод:**
```Run
Старт: Импорт данных
В процессе: Импорт данных
Завершение: Импорт данных
```

# Задача 2

**Формулировка:**
Сделайте функцию, которая выполняет N шагов и выводит общий итог только при выходе из функции с помощью `defer`.

- Создать функцию `runSteps(steps int)`.
- Объявить переменную `done := 0`.
- Через `defer` в конце вывести: `Итого выполнено шагов: <done>`.
- Выполнить цикл от 1 до `steps`, на каждом шаге выводить `Шаг i` и увеличивать `done`.
- В `main()` вызвать `runSteps(4)`.

**Решение:**
```Go
package main  
import "fmt"  
func runSteps(steps int) {  
    done := 0  
    defer func() { fmt.Println("Итого выполнено шагов:", done) }()  
    for i := 1; i <= steps; i++ {  
       fmt.Println("Шаг", i)  
       done = i  
    }  
}  
func main() {  
    runSteps(6)  
}
```
**Вывод:**
```Run
Шаг 1
Шаг 2
Шаг 3
Шаг 4
Итого выполнено шагов: 4
```

- Создать функцию `criticalAction()`, которая вызывает `panic("критическая ошибка выполнения")`.
- Создать функцию `safeRun()`, внутри которой:
    - объявить `defer` с анонимной функцией;
    - в ней вызвать `recover()` и, если вернулось значение, вывести `"Восстановлено после сбоя: <r>"`.
    - вызвать `criticalAction()`.
- В `main()` вызвать `safeRun()` и затем вывести `"Программа продолжает работу"`.

**Решение:**
```Go
package main  
import "fmt"  
func criticalAction() {  
    panic("критическая ошибка выполнения")  
}  
func safeRun() {  
    defer func() {  
       if err := recover(); err != nil {  
          fmt.Println("Восстановлено после сбоя:", err)  
       }  
    }()  
    criticalAction()  
}  
func main() {  
    safeRun()  
}
```
**Вывод:**
```Run
Восстановлено после сбоя: критическая ошибка выполнения
```

**Формулировка:**
Создайте систему инициализации модулей, где один модуль может вызвать панику, но программа должна восстановиться и продолжить работу с другими.

- Создать функцию `initModule(name string) error`, которая:
    - возвращает ошибку, если `name == "logger"`;
    - вызывает `panic("модуль cache не загрузился")`, если `name == "cache"`;
    - иначе выводит `"модуль инициализирован:", name"`.
- Создать функцию `safeInit(name string)`:
    - добавить `defer` с `recover()` и при панике выводить `"восстановлено после сбоя:", name"`;
    - вызвать `initModule(name)` и обработать возвращённую ошибку, если она есть.
- В `main()` последовательно вызвать `safeInit` для модулей:
    `db`, `cache`, `logger`, `api`.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
func initModule(name string) error {  
    if name == "logger" {  
       return errors.New("ошибка при инициализации logger")  
    } else if name == "cache" {  
       panic("модуль cache не загрузился")  
    } else {  
       fmt.Println("модуль инициализирован:", name)  
    }  
    return nil  
}

    defer func() {  
       if err := recover(); err != nil {  
          fmt.Println("восстановлено после сбоя:", name)  
       }  
    }()  
    if initModule(name) != nil {  
       fmt.Println(initModule(name))  
    }  
}  
func main() {  
    list := []string{"db", "cache", "logger", "api"}  
    for _, v := range list {  
       safeInit(v)  
    }  
}
```
**Вывод:**
```Run
модуль инициализирован: db
восстановлено после сбоя: cache
ошибка при инициализации logger
модуль инициализирован: api
```

**Формулировка:**
Реализуйте систему валидации данных, где:
- ошибка (`error`) используется для некритичных нарушений,
- паника (`panic`) — для фатальных ситуаций, а `recover` позволяет продолжить работу.

- Создать структуру `User` с полями `Name string`, `Age int`.
- Функцию `validateUser(u User) error`, которая:
    - возвращает ошибку, если имя пустое (`errors.New("имя не указано")`);
    - вызывает `panic("возраст вне диапазона")`, если `Age < 0` или `Age > 130`;
    - иначе выводит `"пользователь корректен"`.
- Функцию `safeValidate(u User)`:
    - добавить `defer` с `recover()`, выводя `"фатальная ошибка при проверке:", r"`;
    - вызвать `validateUser(u)` и обработать возможную ошибку.
- В `main()` создать несколько пользователей:
    - `{Name: "", Age: 25}`
    - `{Name: "Vasya", Age: 200}`
    - `{Name: "Masha", Age: 30}`
    - и вызвать `safeValidate` для каждого.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
type User struct {  
    Name string  
    Age  int  
}  
func validateUser(u User) error {  
    if u.Name == "" {  
       return errors.New("имя не указано")  
    } else if u.Age < 0 || u.Age > 130 {  
       panic("возраст вне диапазона")  
    } else {  
       fmt.Println("Пользователь корректен")  
    }  
    return nil  
}  
func safeValidate(u User) {  
    defer func() {  
       if r := recover(); r != nil {  
          fmt.Println("Фатальная ошибка при проверке:", r)  
       }  
    }()  
    if validateUser(u) != nil {  
       fmt.Println("Ошибка:", validateUser(u))  
    }  
}  
func main() {  
    u1 := User{Name: "", Age: 25}  
    u2 := User{Name: "Vasya", Age: 200}  
    u3 := User{Name: "Masha", Age: 30}  
    safeValidate(u1)  
    safeValidate(u2)  
    safeValidate(u3)  
}
```
**Вывод:**
```Run
Ошибка: имя не указано
Фатальная ошибка при проверке: возраст вне диапазона
Пользователь корректен
```

# Задача 18

**Формулировка:**
Смоделируйте процесс обработки данных, где:
- `defer` используется для финализации (например, “закрытие” ресурса),
- паника возникает при сбое данных,
- `recover` восстанавливает выполнение.

- Создать функцию `processData(data []int)`.
    - В начале вывести `"начало обработки"`.
    - Добавить `defer`, который всегда выводит `"обработка завершена"`.
    - Если `len(data) == 0` — вызвать `panic("нет данных для обработки")`.
    - Иначе пройтись по элементам и вывести `"элемент:", значение"`.
- Создать функцию `safeProcess(data []int)`, которая:
    - добавляет `defer` с `recover()` и выводом `"восстановлено после сбоя: <сообщение>"`;
    - вызывает `processData(data)`.
- В `main()` вызвать:
    - `safeProcess([]int{1, 2, 3})`
    - `safeProcess([]int{})`

**Решение:**
```Go
package main  
import "fmt"  
func processData(data []int) {  
    fmt.Println("Начало обработки")  
    defer fmt.Println("Обработка завершена")  
    if len(data) == 0 {  
       panic("Нет данных для обработки")  
    } else {  
       for _, value := range data {  
          fmt.Println("Элемент:", value)  
       }  
    }  
}  
func safeProcess(data []int) {  
    defer func() {  
       if r := recover(); r != nil {  
          fmt.Println("Восстановлено после сбоя:", r)  
       }  
    }()  
    processData(data)  
}  
func main() {  
    safeProcess([]int{1, 2, 3})  
    safeProcess([]int{})  
}
```
**Вывод:**
```Run
Начало обработки
Элемент: 1
Элемент: 2
Элемент: 3
Обработка завершена
Начало обработки
Обработка завершена
Восстановлено после сбоя: Нет данных для обработки
```

# Задача 19

**Формулировка:**
Создайте систему обработки операций, где каждая операция может вернуть ошибку, вызвать панику или завершиться успешно.
Программа должна всегда завершать операцию корректно.

- Создать функцию `runOperation(name string) error`, которая:
    - возвращает ошибку, если `name == "bad"`;
    - вызывает `panic("фатальный сбой")`, если `name == "crash"`;
    - иначе выводит `"операция успешно выполнена:", name"`.
- Создать функцию `safeRun(name string)`:
    - добавить `defer` с `recover()`, выводя `"восстановление после паники в:", name"`;
    - вызвать `runOperation(name)` и обработать ошибку, если она вернулась.
- В `main()` вызвать:
    - `safeRun("good")`
    - `safeRun("bad")`
    - `safeRun("crash")`
    - `safeRun("next")`

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
func runOperation(name string) error {  
    if name == "bad" {  
       return errors.New("Ошибка при выполнении bad")  
    } else if name == "crash" {  
       panic("Фатальный сбой")  
    } else {  
       fmt.Println("Операция успешно выполнена:", name)  
       return nil  
    }  
    return nil  
}  
func safeRun(name string) {  
    defer func() {  
       if err := recover(); err != nil {  
          fmt.Println("Восстановление после паники в:", name)  
       }  
    }()  
    if runOperation(name) != nil {  
       fmt.Println(runOperation(name))  
    }  
}  
func main() {  
    safeRun("good")  
    safeRun("bad")  
    safeRun("crash")  
    safeRun("next")  
}
```
**Вывод:**
```Run
Операция успешно выполнена: good
Ошибка при выполнении bad
Восстановление после паники в: crash
Операция успешно выполнена: next
```

# Задача 1

**Формулировка:**
Создайте функцию, которая возвращает ошибку, если число отрицательное.

- Создать функцию `checkNumber(n int) error`.
- Если число меньше 0 — вернуть ошибку с поясняющим сообщением.
- Если всё корректно — вернуть `nil`.
- В `main()` вызвать функцию с положительным и отрицательным числом и проверить вывод.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
func checkNumber(n int) error {  
    if n < 0 {  
       return errors.New("число не может быть отрицательным")  
    }  
    return nil  
}  
func errCheck(n int) {  
    if checkNumber(n) != nil {  
       fmt.Printf("Ошибка: %v\n", checkNumber(n))  
    } else {  
       fmt.Println("Число корректное")  
    }  
}  
func main() {  
    n := 12  
    errCheck(n)  
    n = -5  
    errCheck(n)  
}
```
**Вывод:**
```Run
Число корректное
Ошибка: число не может быть отрицательным
```

- Проверить, не равен ли делитель нулю.
- Если равен — вернуть ошибку с контекстом, указывая значения.
- Если нет — вернуть результат и `nil`.

**Решение:**
```Go
package main  
import (  
    "fmt"  
)  
func divide(a, b int) (int, error) {  
    if b == 0 {  
       return 0, fmt.Errorf("Деление на ноль! a = %d, b = %d", a, b)

       fmt.Println("Ошибка:", err)  
    } else {  
       fmt.Println(a)  
    }  
}
```

**Вывод:**

# Задача 3

**Формулировка:**
Пользователь вводит возраст в виде строки.

Нужно вернуть ошибку, если формат неверный или возраст вне диапазона `[0..120]`.

- Создать функцию `parseAge(input string) (int, error)`.
- Преобразовать введённую строку в число.
- Если преобразование не удалось — вернуть ошибку с пояснением, что возраст должен быть числом.
- Если возраст меньше 0 или больше 120 — вернуть ошибку о недопустимом диапазоне.
- Проверить разные входные данные: `"25"`, `"-5"`, `"abc"`.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt"    "strconv")  
func parseAge(input string) (int, error) {  
    age, err := strconv.Atoi(input)  
    if err != nil {  
       return 0, fmt.Errorf("Возраст должен быть числом")  
    }  
    if age < 0 || age > 120 {  
       return 0, errors.New("Возраст вне допустимого диапазона [0...120]")  
    }  
    return age, nil  
}  
func chkErr(a interface{}, err error) {  
    if err != nil {  
       fmt.Println("Ошибка:", err)  
    } else {  
       fmt.Println("Возраст:", a)  
    }  
}  
func main() {  
    a, err := parseAge("25")  
    chkErr(a, err)  
    a, err = parseAge("-5")  
    chkErr(a, err)  
    a, err = parseAge("abc")  
    chkErr(a, err)  
}
```
**Вывод:**
```Run
Возраст: 25
Ошибка: Возраст вне допустимого диапазона [0...120]
Ошибка: Возраст должен быть числом
```

# Задача 5

**Формулировка:**
Создайте функцию проверки пароля.
Пароль должен быть не короче 8 символов и содержать хотя бы одну цифру.
При нарушении правил возвращаются разные ошибки.

**Сделать:**
- Объявить ошибки `ErrTooShort` и `ErrNoDigit` и указать в описании, какая именно проверка нарушена.
- Создать функцию `validatePassword(p string) error`.
- Проверить длину пароля и наличие хотя бы одной цифры.
- Вернуть соответствующую ошибку при нарушении.
- Протестировать несколько разных паролей в `main()`.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
func validatePassword(p string) error {  
    ErrTooShort := errors.New("Пароль слишком короткий")  
    ErrNoDigit := errors.New("В пароле должна быть хотя бы одна цифра")  
    if len(p) < 8 {  
       return ErrTooShort  
    }  
    for _, c := range p {  
       if c >= '0' && c <= '9' {  
          return nil  
       }  
    }  
    return ErrNoDigit  
}  
func passErrCheck(p string) {  
    passErr := validatePassword(p)  
    if passErr != nil {  
       fmt.Printf("'%v' - %v\n", p, passErr)  
    } else {  
       fmt.Printf("'%v' - Пароль подходит\n", p)  
    }  
}  
func main() {  
    a := "short"  
    b := "password"  
    c := "goodpass1"  
    passErrCheck(a)  
    passErrCheck(b)  
    passErrCheck(c)  
}
```
**Вывод:**
```Run
'short' - Пароль слишком короткий
'password' - В пароле должна быть хотя бы одна цифра
'goodpass1' - Пароль подходит
```

**Формулировка:**
Создайте две разные пользовательские ошибки — `ValidationError` и `SystemError`, и реализуйте функцию, которая может вернуть любую из них.

Определите тип ошибки с помощью `errors.As`.

- Создать два типа:
    - `ValidationError` (для ошибок валидации данных),
    - `SystemError` (для технических ошибок, например, отказ диска).
- Написать функцию `runOperation(mode string) error`.
    - Если `mode == "validation"` — вернуть `ValidationError`.
    - Если `mode == "system"` — вернуть `SystemError`.
- В `main()` вызвать `runOperation` с разными аргументами и через `errors.As` определить тип ошибки.
- Для каждой ошибки вывести своё сообщение.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
type ValidationError struct {  
    Field   string  
    Message string  
}  
type SystemError struct {  
    SysErr string  
}  
func (e ValidationError) Error() string {  
    return fmt.Sprintf("поле %q: %v", e.Field, e.Message)  
}  
func (e SystemError) Error() string {  
    return e.SysErr  
}  
func runOperation(mode string) error {  
    if mode == "validation" {  
       return ValidationError{"email", "некорректно"}  
    }  
    if mode == "system" {  
       return SystemError{"диск недоступен"}  
    }  
    return nil  
}  
func main() {  
    var ve ValidationError  
    var se SystemError  
    v := runOperation("validation")  
    s := runOperation("system")  
    if errors.As(v, &ve) {  
       fmt.Printf("Ошибка валидации: %v\n", ve)  
    }  
    if errors.As(s, &se) {  
       fmt.Println("Системная ошибка:", se.SysErr)  
    }  
}
```
**Вывод:**
```Run
Ошибка валидации: поле "email": некорректно
Системная ошибка: диск недоступен
```

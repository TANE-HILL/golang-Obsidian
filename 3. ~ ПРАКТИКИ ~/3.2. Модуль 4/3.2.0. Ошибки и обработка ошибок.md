# Задача 1

**Формулировка:**
Создайте функцию, которая возвращает ошибку, если число отрицательное.

- Создать функцию `checkNumber(n int) error`.
- Если число меньше 0 — вернуть ошибку с поясняющим сообщением.
- Если всё корректно — вернуть `nil`.
- В `main()` вызвать функцию с положительным и отрицательным числом и проверить вывод.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
func checkNumber(n int) error {  
    if n < 0 {  
       return errors.New("число не может быть отрицательным")  
    }  
    return nil  
}  
func errCheck(n int) {  
    if checkNumber(n) != nil {  
       fmt.Printf("Ошибка: %v\n", checkNumber(n))  
    } else {  
       fmt.Println("Число корректное")  
    }  
}  
func main() {  
    n := 12  
    errCheck(n)  
    n = -5  
    errCheck(n)  
}
```
**Вывод:**
```Run
Число корректное
Ошибка: число не может быть отрицательным
```

# Задача 2

**Формулировка:**
Создайте функцию деления, которая возвращает ошибку при делении на ноль.

- Создать функцию `divide(a, b int) (int, error)`.
- Проверить, не равен ли делитель нулю.
- Если равен — вернуть ошибку с контекстом, указывая значения.
- Если нет — вернуть результат и `nil`.
- В `main()` вызвать и обработать возможную ошибку.

**Решение:**
```Go
package main  
import (  
    "fmt"  
)  
func divide(a, b int) (int, error) {  
    if b == 0 {  
       return 0, fmt.Errorf("Деление на ноль! a = %d, b = %d", a, b)  
    }  
    return a / b, nil  
}  
func main() {  
    a, err := divide(6, 2)  
    if err != nil {  
       fmt.Println("Ошибка:", err)  
    } else {  
       fmt.Println(a)  
    }  
    a, err = divide(4, 0)  
    if err != nil {  
       fmt.Println("Ошибка:", err)  
    } else {  
       fmt.Println(a)  
    }  
}
```
**Вывод:**
```Run
3
Ошибка: Деление на ноль! a = 4, b = 0
```

# Задача 3

**Формулировка:**
Пользователь вводит возраст в виде строки.

Нужно вернуть ошибку, если формат неверный или возраст вне диапазона `[0..120]`.

- Создать функцию `parseAge(input string) (int, error)`.
- Преобразовать введённую строку в число.
- Если преобразование не удалось — вернуть ошибку с пояснением, что возраст должен быть числом.
- Если возраст меньше 0 или больше 120 — вернуть ошибку о недопустимом диапазоне.
- Проверить разные входные данные: `"25"`, `"-5"`, `"abc"`.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt"    "strconv")  
func parseAge(input string) (int, error) {  
    age, err := strconv.Atoi(input)  
    if err != nil {  
       return 0, fmt.Errorf("Возраст должен быть числом")  
    }  
    if age < 0 || age > 120 {  
       return 0, errors.New("Возраст вне допустимого диапазона [0...120]")  
    }  
    return age, nil  
}  
func chkErr(a interface{}, err error) {  
    if err != nil {  
       fmt.Println("Ошибка:", err)  
    } else {  
       fmt.Println("Возраст:", a)  
    }  
}  
func main() {  
    a, err := parseAge("25")  
    chkErr(a, err)  
    a, err = parseAge("-5")  
    chkErr(a, err)  
    a, err = parseAge("abc")  
    chkErr(a, err)  
}
```
**Вывод:**
```Run
Возраст: 25
Ошибка: Возраст вне допустимого диапазона [0...120]
Ошибка: Возраст должен быть числом
```

# Задача 5

**Формулировка:**
Создайте функцию проверки пароля.
Пароль должен быть не короче 8 символов и содержать хотя бы одну цифру.
При нарушении правил возвращаются разные ошибки.

**Сделать:**
- Объявить ошибки `ErrTooShort` и `ErrNoDigit` и указать в описании, какая именно проверка нарушена.
- Создать функцию `validatePassword(p string) error`.
- Проверить длину пароля и наличие хотя бы одной цифры.
- Вернуть соответствующую ошибку при нарушении.
- Протестировать несколько разных паролей в `main()`.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
func validatePassword(p string) error {  
    ErrTooShort := errors.New("Пароль слишком короткий")  
    ErrNoDigit := errors.New("В пароле должна быть хотя бы одна цифра")  
    if len(p) < 8 {  
       return ErrTooShort  
    }  
    for _, c := range p {  
       if c >= '0' && c <= '9' {  
          return nil  
       }  
    }  
    return ErrNoDigit  
}  
func passErrCheck(p string) {  
    passErr := validatePassword(p)  
    if passErr != nil {  
       fmt.Printf("'%v' - %v\n", p, passErr)  
    } else {  
       fmt.Printf("'%v' - Пароль подходит\n", p)  
    }  
}  
func main() {  
    a := "short"  
    b := "password"  
    c := "goodpass1"  
    passErrCheck(a)  
    passErrCheck(b)  
    passErrCheck(c)  
}
```
**Вывод:**
```Run
'short' - Пароль слишком короткий
'password' - В пароле должна быть хотя бы одна цифра
'goodpass1' - Пароль подходит
```

# Задача 6

**Формулировка:**
Создайте две функции:
- `checkName(name string) error` — проверяет корректность имени пользователя и возвращает ошибку, если оно пустое;
- `createUser() error` — вызывает `checkName` и возвращает ошибку выше по стеку, добавляя контекст.

- В `checkName(name string) error` проверить, не является ли имя пустой строкой.
- Если имя пустое — вернуть ошибку `"имя не может быть пустым"`.
- В `createUser() error` вызвать `checkName("")` и, если получена ошибка,
    вернуть её с добавлением контекста `"не удалось создать пользователя: %w"`.
- В `main()` вызвать `createUser()` и вывести итоговую ошибку.

**Решение:**
```Go
package main  
import (  
    "errors"  
    "fmt")  
func checkName(name string) error {  
    if name == "" {  
       return errors.New("Имя не может быть пустым")  
    }  
    return nil  
}  
func createUser() error {  
    if checkName("") != nil {  
       return fmt.Errorf("Не удалось создать пользователя: %v\n", checkName(""))  
    }  
    return nil  
}  
func main() {  
    if err := createUser(); err != nil {  
       fmt.Println(err)  
    }  
}
```
**Вывод:**
```Run
Не удалось создать пользователя: Имя не может быть пустым
```

# Задача 7

**Формулировка:**
Создайте собственный тип ошибки, который хранит имя поля и описание ошибки.

- Создать структуру `FieldError` с полями `Field` и `Message`.
- Реализовать для неё метод `Error() string`.
- Создать функцию `validateField(value string) error`, которая возвращает ошибку, если строка пуста.
- В `main()` вызвать `validateField("")` и вывести результат.

**Решение:**
```Go
package main  
import "fmt"  
type FieldError struct {  
    Field   string  
    Message string  
}  
func (e *FieldError) Error() string {  
    return e.Field + ": " + e.Message  
}  
func validateField(value string) error {  
    if value == "" {  
       e := &FieldError{Field: "value", Message: "field is empty"}  
       return e  
    }  
    return nil  
}  
func main() {  
    err := validateField("")  
    if err != nil {  
       fmt.Println(err)  
    }  
}
```
**Вывод:**
```Run
value: field is empty
```

# Задача 8

**Формулировка:**
Создайте тип `AppError`, который хранит код ошибки и сообщение, и используйте его в функции авторизации.

- Создать структуру `AppError` с полями `Code int` и `Msg string`.
- Реализовать метод `Error() string`, возвращающий строку формата:
    `"код X: <сообщение>"`.
- Написать функцию `authorize(user, pass string) error`.
- Если пользователь не найден — вернуть `AppError{Code: 404, Msg: "пользователь не найден"}`.
- Если пароль неверный — `AppError{Code: 401, Msg: "неверный пароль"}`.
- Проверить работу и вывести ошибки в `main()`.

**Решение:**
```Go
package main  
import (  
    "fmt"  
)  
type AppError struct {  
    Code int  
    Msg  string  
}  
func (a AppError) Error() string {  
    return fmt.Sprintf("Код %v: %v", a.Code, a.Msg)  
}  
func authorize(user, pass string) error {  
    if user != "Admin" {  
       return AppError{404, "Пользователь не найден"}  
    }  
    if pass != "12345678" {  
       return AppError{401, "Неверный пароль"}  
    }  
    return nil  
}  
func authErrCheck(u, p string) {  
    err := authorize(u, p)  
    if err != nil {  
       fmt.Println(err)  
       return  
    }  
    fmt.Println("Вход выполен")  
    return  
}  
func main() {  
    u, p := "User", "1234"  
    authErrCheck(u, p)  
    u, p = "Admin", "123456"  
    authErrCheck(u, p)  
    u, p = "Admin", "12345678"  
    authErrCheck(u, p)  
}
```
**Вывод:**
```Run
Код 404: Пользователь не найден
Код 401: Неверный пароль
Вход выполен
```

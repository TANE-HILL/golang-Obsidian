# Задача 1

**Формулировка:**
Создайте несколько пользователей и выведите имена тех, кто старше 18 лет.

- Создать тип `User` с полями `Name` и `Age`.
- Добавить пользователей:
    - Vasya — 19
    - Masha — 17
    - Petr — 25
    - Olya — 30
- Сохранить их в слайс.
- Пройти циклом и вывести имена, где `Age > 18`.

**Решение:**
```Go
package main  
import "fmt"  
type users struct {  
    name string  
    age  int  
}  
func main() {  
    people := []users{}  
    people = append(people, users{"Vasya", 19}, users{"Masha", 17}, users{"Petr", 25}, users{"Olya", 30})  
    for _, person := range people {  
       if person.age >= 18 {  
          fmt.Println(person.name)  
       }  
    }  
}
```
**Вывод:**
```Run
Vasya
Petr
Olya
```

# Задача 3

**Формулировка:**
Напишите функцию, которая ищет пользователя по имени в слайсе.

```go
func FindUser(users []User, name string) *User
```

- Если пользователь найден — вернуть указатель на него.
- Если нет — вернуть `nil`.
- Проверить поиск по именам `"Petr"` и `"Anna"`.

**Решение:**
```Go
package main  
import "fmt"  
type User struct {  
    name string  
    age  int  
}  
func FindUser(users []User, name string) *User {  
    for i := range users {  
       if users[i].name == name {  
          return &users[i]  
       }  
    }  
    return nil  
}  
func checkName(user *User) {  
    if user == nil {  
       fmt.Printf("Не найден\n")  
    } else {  
       fmt.Printf("Найден: %v\n", user.name)  
    }  
}  
func main() {  
    users := []User{}  
    users = append(users, User{"Vasya", 19}, User{"Masha", 17}, User{"Petr", 25}, User{"Olya", 30})  
    fmt.Printf("Количество пользователей: %v\n", len(users))  
    a := FindUser(users, "Vasya")  
    b := FindUser(users, "Anna")  
    checkName(a)  
    checkName(b)  
}
```
**Вывод:**
```Run
Количество пользователей: 4
Найден: Vasya
Не найден
```

```Go
package main
```
```Go
import (
    "fmt"
```

```Go
)
type BankAccount struct {
    id int
    balance float64
}
func (a *BankAccount) ChangeBalance(amount float64)error{
// Немного изменил условие с "set" на "change" - так интереснее
    if a.balance + amount < 0 {
        return errors.New("ERR: negative amount")
    }
    a.balance+=amount
    return nil
}
func NewBalance(n int, bal float64, pages []*BankAccount) {
// Вывел алгоритм проверки error в отдельную функцию, для удобства
    if err := pages[n].ChangeBalance(bal); err != nil {
        fmt.Println(err)
    } else {
        fmt.Printf("OK: %.2f\n", pages[n].balance)
```

- Повысить зарплату всем, у кого `Age < 30`, на 10 %.
- Вывести новые значения зарплат.

**Решение:**
```Go
package main  
import "fmt"  
type Employee struct {  
    Name   string  
    Age    int  
    Salary int  
}  
func (e *Employee) salaryInc10() {  
    if e.Age >= 30 {  
       e.Salary = e.Salary + e.Salary/10  
    }  
}  
func main() {  
    Epmls := []Employee{  
       {"Masha", 33, 38900},  
       {"Natasha", 68, 18000},  
       {"Sasha", 21, 48000},  
       {"Vasily", 45, 289900},  
       {"Gennady", 36, 160000},  
       {"Yana", 19, 31000},  
    }  
    for i, _ := range Epmls {  
       Epmls[i].salaryInc10()  
       fmt.Printf("%v - %v\n", Epmls[i].Name, Epmls[i].Salary)  
    }  
}
```

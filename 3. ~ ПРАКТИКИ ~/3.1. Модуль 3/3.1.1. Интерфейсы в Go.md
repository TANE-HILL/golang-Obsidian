# Задача 1

**Формулировка:**
Создайте интерфейс `Printer` и реализуйте его у структуры `User`.
Пройдитесь по списку пользователей и вызовите метод `Print()`.

- Интерфейс `Printer` с методом `Print()`.
- Структура `User` с полями `Name`, `Age`.
- Метод `Print()` выводит `"Name Age"`.
- Создать `[]Printer` с тремя пользователями:
    - Vasya — 19
    - Masha — 21
    - Petr — 30
- Пройти циклом и вызвать `Print()` у каждого.

**Решение:**
```Go
package main
import "fmt"
type Printer interface {
    Print()
}
type User struct {
    Name string
    Age int
}
func (u User) Print() {
    fmt.Println(u.Name, u.Age)
}
func main() {
    p := []Printer{
        User{"Vasya", 19},
        User{"Masha", 21},
        User{"Petr", 30},
    }
    for i := range p {
        p[i].Print()
    }
}
```
**Вывод:**
```Run
Vasya 19
Masha 21
Petr 30
```

# Задача 2

**Формулировка:**
Создайте интерфейс `Pricer`, который возвращает стоимость объекта.

Подсчитайте общую сумму для разных типов.

- Интерфейс `Pricer` с методом `Price() int`.
- Структуры:
    - `Product` (`Name`, `UnitPrice`)
    - `Service` (`Name`, `Minutes`, `RatePerMinute`)
- Реализуйте `Price()` для обоих типов.
- Создайте `[]Pricer`:
    - Product: Phone — 1200
    - Product: Case — 200
    - Service: Repair — 30 минут × 10 руб.
- Посчитайте общую сумму.

**Решение:**
```Go
package main
import "fmt"
type Pricer interface {
    Price()int
}
type Product struct {
    Name string
    UnitPrice int
}
type Service struct {
    Name string
    Minutes int
    RatePerMinute int
}
func (u Product)Price()int{
    return u.UnitPrice
}
func (s Service)Price()int{
    return (s.Minutes*s.RatePerMinute)
}
func main() {
    p := []Pricer{
        Product{"Phone", 1200},
        Product{"Case", 200},
        Service{"Repair", 30, 10},
    }
    result := 0
    for i := range p {
        result += p[i].Price()
    }
    fmt.Printf("Итого: %v\n", result)
}
```
**Вывод:**
```Run
Итого: 1700
```

# Задача 5

**Формулировка:**
Подсчитайте, сколько элементов каждого типа находится в срезе.

- Создать `[]interface{}`: `"hi"`, `2`, `"go"`, `4`, `true`, `7`.
- Пройти циклом и считать:
    - сколько строк (`string`);
    - сколько чисел (`int`);
    - сколько булевых (`bool`).

**Решение:**
```Go
package main  
import "fmt"  
func main() {  
    items := []interface{}{"hi", 2, "go", 4, true, 7}  
    var s, i, b int  
    for _, v := range items {  
       switch v.(type) {  
       case string:  
          s++  
       case int:  
          i++  
       case bool:  
          b++  
       }  
    }  
    fmt.Printf("strings: %v\nints: %v\nbools: %v\n", s, i, b)  
}
```
**Вывод:**
```Run
strings: 2
ints: 3
bools: 1
```

# Задача 10

**Формулировка:**
Создайте функцию, которая принимает `interface{}` и печатает тип значения в зависимости от того, что хранится внутри.

```go
func DetectType(v interface{})
```

- Если это `int` → вывести `"Число"`
- Если `string` → `"Строка"`
- Если `bool` → `"Булево"`
- Иначе → `"Неизвестный тип"`
- Проверить на примерах: `10`, `"hi"`, `true`, `3.14`.

**Решение:**
```Go
package main
import "fmt"
func DetectType(v []interface{}){
    for i := range v {
        switch x := v[i].(type) {
        case int:
            fmt.Println("Число:", x)
        case string:
            fmt.Println("Строка:", x)
        case bool:
            fmt.Println("Булево:", x)
        default:
            fmt.Println("Неизвестный тип:", x)
        }
    }
}
func main() {
    v := []interface{}{10, "hi", true, 3.14}
    DetectType(v)
}
```
**Вывод:**
```Run
Число: 10
Строка: hi
Булево: true
Неизвестный тип: 3.14
```

# Задача 11

**Формулировка:**
Создайте функцию, которая принимает два значения `interface{}` и складывает их, если оба — числа.

```go
func Add(a, b interface{})
```

- Если оба `int` → вывести их сумму.
- Если оба `float64` → вывести их сумму.
- Иначе → `"Невозможно сложить"`.
- Пример вызовов:
    - `Add(3, 4)`
    - `Add(2.5, 3.5)`
    - `Add(3, "hi")`

**Решение:**
```Go
package main
import "fmt"
func Add(a, b interface{}){
    ai, aOk := a.(int)
    bi, bOk := b.(int)
    if aOk && bOk {
        fmt.Println(ai+bi)
        return
    }
    af, aOk := a.(float64)
    bf, bOk := b.(float64)
    if aOk && bOk {
        res := af+bf
        fmt.Printf("%.2f\n", res)
        return
    }
    fmt.Println("Невозможно сложить")
    return
}
func main() {
    Add(3, 4)
    Add(2.5, 3.5)
    Add(3, "hi")
}
```
**Вывод:**
```Run
7
6.00
Невозможно сложить
```

- Создать `[]interface{}{1, "go", true, 2, "hi", 3}`.
- Использовать `type switch` внутри цикла.
- Подсчитать количество каждого типа.

**Решение:**
```Go
package main
import "fmt"
func countOfTypes(s []interface{}) map[string]int {
    m := map[string]int{}
    for _, v := range s {
        switch v.(type) {
        case int:
            m["int"]++
        case string:
            m["string"]++
        case bool:
            m["bool"]++
        }
    }
    return m
}
func main() {
    s := []interface{}{1, "go", true, 2, "hi", 3}
    sTypes := countOfTypes(s)
    for r, v := range sTypes {
        fmt.Printf("%v: %v\n", r, v)
    }
}
```
**Вывод:**
```Run
int: 3
string: 2
bool: 1
```

# Задача 14

**Формулировка:**
Разделите значения из среза `[]interface{}` по типам: числа (`ints`), строки (`strings`), булевы (`bools`).

- Срез: `[]interface{}{"hi", 5, true, "go", 8, false}`.
- Пройти циклом, используя `type switch`.
- Наполнить три отдельных среза.
- Вывести каждый срез отдельно.

**Решение:**
```Go
package main  
import "fmt"  
func SplitTypes(items []interface{}) ([]interface{}, []interface{}, []interface{}) {  
    var sString, sInt, sBool []interface{}  
    for _, i := range items {  
       switch x := i.(type) {  
       case string:  
          sString = append(sString, x)  
       case int:  
          sInt = append(sInt, x)  
       case bool:  
          sBool = append(sBool, x)  
       default:  
          continue  
       }  
    }  
    return sString, sInt, sBool  
}  
func main() {  
    s := []interface{}{"hi", 5, true, "go", 8, false}  
    sString, sInt, sBool := SplitTypes(s)  
    fmt.Printf("String slice: %v\nInt slice: %v\nBool slice: %v\n", sString, sInt, sBool)  
}
```
**Вывод:**
```Run
String slice: [hi go]
Int slice: [5 8]
Bool slice: [true false]
```

**Формулировка:**
Создайте интерфейсы `Reader` и `Writer`, а затем объедините их в `ReadWriter`.

- `Reader` с методом `Read() string`.
- `Writer` с методом `Write(data string)`.
- `ReadWriter` = `Reader + Writer`.
- Создать структуру `Note` с полем `text string`, реализующую оба метода.
- В `main`:
    - Записать текст `"Hello"`;
    - Прочитать его и вывести.

**Решение:**
```Go
package main  
import "fmt"  
type Reader interface {  
    Read() string  
}  
type Writer interface {  
    Write(data string)  
}  
type ReadWriter interface {  
    Reader  
    Writer}  
func (f *Note) Write(data string) {  
    f.text = data  
}  
func (f *Note) Read() string {  
    return f.text  
}  
type Note struct {  
    text string  
}  
func main() {  
    var f Note  
    f.Write("Hello")  
    fmt.Println(f.Read())  
}
```
**Вывод:**
```Run
Hello
```

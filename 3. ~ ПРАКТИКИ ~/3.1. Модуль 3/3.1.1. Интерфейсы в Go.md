# Задача 1

**Формулировка:**
Создайте интерфейс `Printer` и реализуйте его у структуры `User`.
Пройдитесь по списку пользователей и вызовите метод `Print()`.

- Интерфейс `Printer` с методом `Print()`.
- Структура `User` с полями `Name`, `Age`.
- Метод `Print()` выводит `"Name Age"`.
- Создать `[]Printer` с тремя пользователями:
    - Vasya — 19
    - Masha — 21
    - Petr — 30
- Пройти циклом и вызвать `Print()` у каждого.

**Решение:**
```Go
package main
import "fmt"
type Printer interface {
    Print()
}
type User struct {
    Name string
    Age int
}
func (u User) Print() {
    fmt.Println(u.Name, u.Age)
}
func main() {
    p := []Printer{
        User{"Vasya", 19},
        User{"Masha", 21},
        User{"Petr", 30},
    }
    for i := range p {
        p[i].Print()
    }
}
```
**Вывод:**
```Run
Vasya 19
Masha 21
Petr 30
```

# Задача 2

**Формулировка:**
Создайте интерфейс `Pricer`, который возвращает стоимость объекта.

Подсчитайте общую сумму для разных типов.

- Интерфейс `Pricer` с методом `Price() int`.
- Структуры:
    - `Product` (`Name`, `UnitPrice`)
    - `Service` (`Name`, `Minutes`, `RatePerMinute`)
- Реализуйте `Price()` для обоих типов.
- Создайте `[]Pricer`:
    - Product: Phone — 1200
    - Product: Case — 200
    - Service: Repair — 30 минут × 10 руб.
- Посчитайте общую сумму.

**Решение:**
```Go
package main
import "fmt"
type Pricer interface {
    Price()int
}
type Product struct {
    Name string
    UnitPrice int
}
type Service struct {
    Name string
    Minutes int
    RatePerMinute int
}
func (u Product)Price()int{
    return u.UnitPrice
}
func (s Service)Price()int{
    return (s.Minutes*s.RatePerMinute)
}
func main() {
    p := []Pricer{
        Product{"Phone", 1200},
        Product{"Case", 200},
        Service{"Repair", 30, 10},
    }
    result := 0
    for i := range p {
        result += p[i].Price()
    }
    fmt.Printf("Итого: %v\n", result)
}
```
**Вывод:**
```Run
Итого: 1700
```

# Задача 3

**Формулировка:**
Проверьте разницу между методами на значении и указателе при реализации интерфейса.

- Интерфейс `Updater` с методом `UpdateAge()`.
- Структура `User` с полем `Age`.
- Версия 1: `func (u User) UpdateAge()` — увеличивает возраст на 1.
- Версия 2: `func (u *User) UpdateAge()` — увеличивает возраст на 1.
- Протестировать обе версии:
    - Создать `User{Age: 25}`
    - Вызвать через интерфейс метод и вывести возраст до и после.

**Решение:**
```Go
package main  
import "fmt"  
type Updater interface{ UpdateAge() }  
type User struct {  
    Age int  
}  
func (u *User) UpdateAge() {  
    u.Age++  
}  
func main() {  
    u := User{  
       Age: 10,  
    }  
    u.UpdateAge()  
    fmt.Println(u.Age)  
}
```
**~ Ответ ~**
```
При компиляции с функцией с указателем, значение изменилось.
```

# Задача 4

**Формулировка:**
Создайте срез `[]interface{}`, в который можно поместить значения разных типов.

- Создать срез `[]interface{}` из элементов:
    - `"Go"`
    - `10`
    - `true`
    - `3.14`
- Пройти по срезу циклом и вывести значение и его тип

**Решение:**
```Go
package main  
import "fmt"  
func main() {  
    items := []interface{}{"Go", 25, true, 3.14}  
  
    for i, v := range items {  
       fmt.Printf("[%d] %v (тип %T)\n", i, v, v)  
    }  
}
```
**Вывод:**
```Run
[0] Go (тип string)
[1] 25 (тип int)
[2] true (тип bool)
[3] 3.14 (тип float64)
```

# Задача 5

**Формулировка:**
Подсчитайте, сколько элементов каждого типа находится в срезе.

- Создать `[]interface{}`: `"hi"`, `2`, `"go"`, `4`, `true`, `7`.
- Пройти циклом и считать:
    - сколько строк (`string`);
    - сколько чисел (`int`);
    - сколько булевых (`bool`).

**Решение:**
```Go
package main  
import "fmt"  
func main() {  
    items := []interface{}{"hi", 2, "go", 4, true, 7}  
    var s, i, b int  
    for _, v := range items {  
       switch v.(type) {  
       case string:  
          s++  
       case int:  
          i++  
       case bool:  
          b++  
       }  
    }  
    fmt.Printf("strings: %v\nints: %v\nbools: %v\n", s, i, b)  
}
```
**Вывод:**
```Run
strings: 2
ints: 3
bools: 1
```

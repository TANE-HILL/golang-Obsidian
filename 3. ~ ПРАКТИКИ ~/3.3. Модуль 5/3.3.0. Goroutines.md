# Задача 10

**Определить, что будет выведено:**
```go
func main() {
	msg := "start"
	go func() {
		fmt.Println(msg)
	}()
	msg = "changed"
	time.Sleep(100 * time.Millisecond)
}
```

**Решение:**
```Go
package main  
import (  
    "fmt"  
    "time")  
func main() {  
    msg := "start"  
    go func() {  
       fmt.Println(msg)  
    }()  
    msg = "changed"  
    time.Sleep(100 * time.Millisecond)  
}  
/*  
Горутина захватывает ссылку на `msg`, а не копию.  
Когда переменная изменяется, горутина печатает обновлённое значение.  
*/
```
**Вывод:**
```Run
changed
```

# Задача 11

**Определить, что будет выведено:**
```go
func main() {
	msg := "start"
	go func(m string) {
		fmt.Println(m)
	}(msg)
	msg = "changed"
	time.Sleep(100 * time.Millisecond)
}
```

**Решение:**
```Go
package main  
import (  
    "fmt"  
    "time")  
func main() {  
    msg := "start"  
    go func(m string) {  
       fmt.Println(m)  
    }(msg)  
    msg = "changed"  
    time.Sleep(100 * time.Millisecond)  
}  
/*  
Здесь аргумент передаётся по значению,  
поэтому горутина печатает то, что было передано в момент запуска.  
 */
```
**Вывод:**
```Run
start
```

# Задача 12

**Определить, что будет выведено:**
```go
func main() {
	counter := 0
	for i := 0; i < 5; i++ {
		go func() {
			counter++
		}()
	}
	time.Sleep(50 * time.Millisecond)
	fmt.Println(counter)
}
```

**Решение:**
```Go
package main  
import (  
    "fmt"  
    "time")  
func main() {  
    counter := 0  
    for i := 0; i < 5; i++ {  
       go func() {  
          counter++  
       }()  
    }  
    time.Sleep(50 * time.Millisecond)  
    fmt.Println(counter)  
}  
/*  
Этот код почти всегда выводит 5.  
  
Но несколько горутин одновременно изменяют одну и ту же переменную,  
из-за чего они могут мешать друг другу и часть изменений может потеряться.  
  
В данном примере это редко заметно,  
но в более сложных программах такая ошибка  
может приводить к неправильным результатам.  
 */
```
**Вывод:**
```Run
5
```

# Задача 13

**Определить, что будет выведено:**
```go
func main() {
	go func() {
		fmt.Println("outer start")
		go fmt.Println("inner")
		fmt.Println("outer end")
	}()
	time.Sleep(10 * time.Millisecond)
}
```

**Решение:**
```Go
package main  
import (  
    "fmt"  
    "time")  
func main() {  
    go func() {  
       fmt.Println("outer start")  
       go fmt.Println("inner")  
       fmt.Println("outer end")  
    }()  
    time.Sleep(10 * time.Millisecond)  
}  
/*  
Вложенная горутина запускается независимо от внешней.  
Она может выполниться позже, даже если внешняя функция уже завершилась.  
 */
```
**Вывод:**
```Run
outer start
outer end
inner
```

# Задача 14

**Определить, что будет выведено:**
```go
func job(name string, delay time.Duration) {
	time.Sleep(delay)
	fmt.Println(name, "done")
}

func main() {
	go job("1", 200*time.Millisecond)
	go job("2", 50*time.Millisecond)
	go job("3", 100*time.Millisecond)
	time.Sleep(150 * time.Millisecond)
}
```

**Решение:**
```Go
package main  
import (  
    "fmt"  
    "time")  
func job(name string, delay time.Duration) {  
    time.Sleep(delay)  
    fmt.Println(name, "done")  
}  
func main() {  
    go job("1", 200*time.Millisecond)  
    go job("2", 50*time.Millisecond)  
    go job("3", 100*time.Millisecond)  
    time.Sleep(150 * time.Millisecond)  
}  
/*  
Порядок завершения зависит от задержки.  
Те горутины, где задержка выше,  
будут выполнены позже тех, где ниже.  
*/
```
**Вывод:**
```Run
2 done
3 done
```

# Задача 15

**Определить, что будет выведено:**
```go
func main() {
	for i := 1; i <= 3; i++ {
		go func(n int) {
			fmt.Printf("Start %d\n", n)
			time.Sleep(time.Duration(n*100) * time.Millisecond)
			fmt.Printf("End %d\n", n)
		}(i)
	}
	time.Sleep(400 * time.Millisecond)
}
```

**Решение:**
```Go
package main  
import (  
    "fmt"  
    "time")  
func main() {  
    for i := 1; i <= 3; i++ {  
       go func(n int) {  
          fmt.Printf("Start %d\n", n)  
          time.Sleep(time.Duration(n*100) * time.Millisecond)  
          fmt.Printf("End %d\n", n)  
       }(i)  
    }  
    time.Sleep(400 * time.Millisecond)  
}  
/*  
Горутина fmt.Printf("End %d\n", n) может работать независимо от функции.  
Поэтому, учитывая задержку time.Sleep(...), выведется сначала x3 Start...  
А затем End... (в рандомных порядках).  
*/
```
**Вывод:**
```Run
Start 3
Start 1
Start 2
End 1
End 2
End 3
```

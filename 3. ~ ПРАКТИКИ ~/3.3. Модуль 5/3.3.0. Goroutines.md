# Задача 1

**Формулировка:**
Создайте функцию, которая выводит сообщение `"Привет из горутины"`, и запустите её с помощью ключевого слова `go`.

В основной функции (`main`) выведите `"Привет из main"`.
- Создать функцию `printMessage()`.
- Запустить её как горутину.
- Добавить паузу перед завершением программы.

**Решение:**
```Go
package main
import (
    "fmt"
    "time"
    )
func goroutine() {
    fmt.Println("Привет из горутины!")
}
func main() {
    fmt.Println("Привет из main!")
    go goroutine()
    time.Sleep(200 * time.Millisecond)
}
```
**Вывод:**
```Run
Привет из main!
Привет из горутины!
```

# Задача 6

**Формулировка:**
Запустите горутину, которая выводит строку, и сразу завершайте основную программу.

- Проверить, выводится ли строка.
- Добавить небольшую задержку.
- Объяснить разницу в поведении.

**Решение:**
```Go
package main
import (
    "fmt"
    "time"
    )
func first() {
    time.Sleep(10 * time.Millisecond) // Задержка - 10 миллисекунд. Горутина завершится раньше func main.
    fmt.Println("Эта строка - выведется.")
}
func second() {
    time.Sleep(500 * time.Millisecond) // Задержка - 500 миллисекунд. func main завершится раньше, поэтому строка не выведется.
    fmt.Println("Эта - нет.")
}
/*
~ func main также является горутиной.
Она выполняется независимо от других горутин.
Поэтому завершится автоматически, даже если другие горутины не закончили свою работу.
~ Для предотвращения этого можно добавить задержку с помощью time.Sleep
*/
func main() {
    go first()
    go second()
    time.Sleep(100 * time.Millisecond) // Задержка - 100 миллисекунд.
}
```
**Вывод:**
```Run
Эта строка - выведется.
```

Запустите их обе как горутины **несколько раз в разном порядке** (например, чередуя “быструю” и “медленную” задачи).

- Проанализировать, в каком порядке появятся строки.


# Задача 8

**Определить, что будет выведено:**
```go
func main() {
	for i := 0; i < 3; i++ {
		go func() {
			fmt.Println(i)
		}()
	}
	time.Sleep(time.Second)
}
```

**Решение:**
```Go
/*
Цикл for i от 0 до 3 (не включительно)
Запускает горутину с анонимной функцией, печатающей i

Числа будут выводиться в рандомном порядке, поскольку передаются циклом for в функцию почти моментально, а функции, благодаря горутинам, будут выполняться параллельно.

В конце горутины main - задержка в одну секунду, благодаря чему остальные горутины успевают завершить свою работу раньше завершения func main.

					!!! ВАЖНОЕ УТОЧНЕНИЕ !!!
В этом примере в анонимную функцию НЕ передаётся значение i, функция берёт это значение из "внешней области видимости".

Такая конструкция может быть опасна при использовании в работе, так как результат будет зависеть от работы планировщика:
- если значение переменной из "внешней области видимости" изменится ДО ТОГО как горутина выполнит работу с этой переменной, то горутина будет работать уже с новым значением, соответственно, искажая необходимый результат.

В Go до версии 1.22 в этом примере вывелось бы:

3
3
3

Это объясняется тем, что в ранних версиях Go семантика переменных цикла включала в себя изменение значения одной и той же переменной. А в версиях, начиная с 1.22, каждая новая итерация цикла как-бы создаёт НОВУЮ переменную i, которая и захватывается анонимной функцией.

Но сути моего "ВАЖНОГО УТОЧНЕНИЯ" это не меняет.
*/
```
**Вывод:**
```Run
2
0
1
```

# Задача 9

**Определить, что будет выведено:**
```go
func printNum(n int) {
	fmt.Println(n)
}

func main() {
	for i := 0; i < 3; i++ {
		go printNum(i)
	}
	time.Sleep(time.Second)
}
```

**Решение:**
```Go
/*
Эта задача - более идиоматичная запись предыдущей.
Здесь значение i уже непосредственно ПЕРЕДАЁТСЯ в функцию - то есть, внутри функции создаётся копия, записывается в переменную n.
Именно поэтому вывод при такой записи будет правильным всегда: все числа от 0 до 2 выведутся - независимо от версии Go или того, что их туда "передаёт".

Не обязательно было создавать отдельную именованную функцию, можно было просто изменить анонимную из задачи выше.
Вот так:
*/
	for i := 0; i < 3; i++ {
		go func(n int) { // функция принимает n типа int
			fmt.Println(n) // работает с n
		}(i) // в функцию передаётся переменная i
	}
```
**Вывод:**
```Run
2
0
1
```

# Задача 19

**Формулировка:**
Сделайте мини-симуляцию “магазина”:

- есть список покупателей и товаров;
- каждая горутина — это покупатель,
- она “покупает” случайный товар.

- Создать срез покупателей и товаров.
- Для каждого покупателя запустить горутину, которая выводит, что он купил.
- Добавить задержку, чтобы увидеть процесс.

**Решение:**
```Go
package main  
import (  
    "fmt"  
    "math/rand"    "time")  
func main() {  
    products := []string{"Телефон", "Чехол", "Кабель", "Ноутбук", "Клавиатура", "Видеокарта"}  
    buyers := []string{"Александр", "Тимофей", "Владимир", "Алефтина", "Василиса", "Герман"}  
    for _, v := range buyers {  
       go fmt.Printf("%s покупает %s\n", v, products[rand.Intn(len(products))])  
    }  
    time.Sleep(200 * time.Millisecond)  
}
```
**Вывод:**
```Run
Герман покупает Чехол
Александр покупает Ноутбук
Василиса покупает Кабель
```

# Задача 4

**Формулировка:**
Горутина должна начать выполнение **только после сигнала** из `main`.
После получения сигнала она выводит `"Работа началась!"` и завершает выполнение.

**Функция для реализации:**
```go
func waitForSignal() string {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(waitForSignal())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func waitForSignal() string {  
    ch1 := make(chan string)  
    start := make(chan bool)  
    go func() {  
       <-start  
       close(start)  
       ch1 <- "Работа началась!"  
    }()  
    start <- true  
    return <-ch1  
}  
/*  
Сделать то, что просит условие,  
невозможно. Чтобы "подать сигнал  
в горутину из main", необходимо  
поменять сигнатуры waitForSignal  
и main. Сделать так, чтобы горутина  
создавалась в main. Тогда с помощью  
канала можно будет передать  
сигнал. Иначе - только так.
*/  
func main() {  
    fmt.Println(waitForSignal())  
}
```
**Вывод:**
```Run
Работа началась!
```

# Задача 5

**Формулировка:**
Создайте две горутины, которые последовательно обрабатывают данные:

1. первая отправляет `"data"`,
2. вторая принимает и возвращает `"processed data"`.

**Функция для реализации:**
```go
func pipeline() string {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(pipeline())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func pipeline() string {  
    ch1 := make(chan string)  
    ch2 := make(chan string)  
    go func() {  
       ch1 <- "data"  
    }()  
    go func() {  
       ch2 <- "processed " + <-ch1  
    }()  
    return <-ch2  
}  
func main() {  
    fmt.Println(pipeline())  
}
```
**Вывод:**
```Run
processed data
```

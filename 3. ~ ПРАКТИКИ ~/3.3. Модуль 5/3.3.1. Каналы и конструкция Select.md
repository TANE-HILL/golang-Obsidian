# Задача 4

**Формулировка:**
Горутина должна начать выполнение **только после сигнала** из `main`.
После получения сигнала она выводит `"Работа началась!"` и завершает выполнение.

**Функция для реализации:**
```go
func waitForSignal() string {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(waitForSignal())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func waitForSignal() string {  
    ch1 := make(chan string)  
    start := make(chan bool)  
    go func() {  
       <-start  
       close(start)  
       ch1 <- "Работа началась!"  
    }()  
    start <- true  
    return <-ch1  
}  
/*  
Сделать то, что просит условие,  
невозможно. Чтобы "подать сигнал  
в горутину из main", необходимо  
поменять сигнатуры waitForSignal  
и main. Сделать так, чтобы горутина  
создавалась в main. Тогда с помощью  
канала можно будет передать  
сигнал. Иначе - только так.
*/  
func main() {  
    fmt.Println(waitForSignal())  
}
```
**Вывод:**
```Run
Работа началась!
```

# Задача 5

**Формулировка:**
Создайте две горутины, которые последовательно обрабатывают данные:

1. первая отправляет `"data"`,
2. вторая принимает и возвращает `"processed data"`.

**Функция для реализации:**
```go
func pipeline() string {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(pipeline())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func pipeline() string {  
    ch1 := make(chan string)  
    ch2 := make(chan string)  
    go func() {  
       ch1 <- "data"  
    }()  
    go func() {  
       ch2 <- "processed " + <-ch1  
    }()  
    return <-ch2  
}  
func main() {  
    fmt.Println(pipeline())  
}
```
**Вывод:**
```Run
processed data
```

# Задача 6

**Формулировка:**
Три горутины выполняют разные задачи и отправляют сигнал `true` в канал `done`.
Программа должна дождаться всех трёх сигналов и вернуть `"Все завершены"`.

**Функция для реализации:**
```go
func waitAll() string {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(waitAll())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func waitAll() string {  
    done := make(chan bool, 3)  
    go func() {  
       fmt.Printf("все ")  
       done <- true  
    }()  
    go func() {  
       fmt.Printf("горутины ")  
       done <- true  
    }()  
    go func() {  
       fmt.Printf("успешно ")  
       done <- true  
    }()  
    for i := 1; i <= 3; i++ {  
       <-done  
    }  
    return "завершены"  
}  
func main() {  
    fmt.Printf(waitAll())  
}
```
**Вывод:**
```Run
успешно горутины все завершены
```

# Задача 1

**Формулировка:**
Создайте буферизированный канал на 3 числа.
Передайте в него значения от 1 до 3 и выведите их через `range`.

**Функция для реализации:**
```go
func readNumbers() []int {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(readNumbers())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func readNumbers() []int {  
    ch := make(chan int, 3)  
    result := []int{}  
    go func() {  
       for i := 1; i <= 3; i++ {  
          ch <- i  
       }  
       close(ch)  
    }()  
    for val := range ch {  
       result = append(result, val)  
    }  
    return result  
}  
func main() {  
    fmt.Println(readNumbers())  
}
```
**Вывод:**
```Run
[1 2 3]
```

# Задача 3

**Формулировка:**
Создайте функцию, которая получает числа из канала и возвращает их сумму после закрытия канала.

**Функция для реализации:**
```go
func sumChannel() int {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(sumChannel()) // 15
}
```

**Решение:**
```Go
package main  
import "fmt"  
func sumChannel() int {  
    ch, res := make(chan int, 5), 0  
    go func() {  
       for i := 1; i <= 5; i++ {  
          ch <- i  
       }  
       close(ch)  
    }()  
    for val := range ch {  
       res += val  
    }  
    return res  
}  
func main() {  
    fmt.Println(sumChannel()) // 15  
}
```
**Вывод:**
```Run
15
```

Создайте два отправителя, каждый из которых записывает по 3 числа в один канал.
Закройте канал, когда все отправки завершены, и выведите все значения через range.

**Функция для реализации:**
```go
func multiSender() []int {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(multiSender())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func multiSender() []int {  
    ch, done := make(chan int, 6), make(chan bool, 2)  
    res := []int{}  
    go func() {  
       for i := 4; i <= 6; i++ {  
          ch <- i  
       }  
       done <- true  
    }()  
    go func() {  
       for i := 1; i <= 3; i++ {  
          ch <- i  
       }  
       done <- true  
    }()  
    <-done  
    <-done  
    close(ch)  
    for val := range ch {  
       res = append(res, val)  
    }  
    return res  
}  
func main() {  
    fmt.Println(multiSender())  
}
```
**Вывод:**
```Run
[1 2 3 4 5 6]
```

# Задача 5

**Формулировка:**
В канал отправляются задания (строки “task 1”, “task 2” и т. д.).
Когда задания закончились — канал закрывается, а функция возвращает строку `"all tasks processed"` после чтения всех данных.

**Функция для реализации:**
```go
func processTasks() string {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(processTasks())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func processTasks() string {  
    ch := make(chan string)  
    go func() {  
       ch <- "task1"  
       ch <- "task2"  
       ch <- "task3"  
       ch <- "task4"  
       ch <- "task5"  
       close(ch)  
    }()  
    for val := range ch {  
       fmt.Println(val)  
    }  
    return "all tasks processed\n"  
}  
func main() {  
    fmt.Println(processTasks())  
}
```
**Вывод:**
```Run
task1
task2
task3
task4
task5
all tasks processed
```

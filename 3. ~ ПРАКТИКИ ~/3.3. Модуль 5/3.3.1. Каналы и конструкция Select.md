# Задача 4

**Формулировка:**
Горутина должна начать выполнение **только после сигнала** из `main`.
После получения сигнала она выводит `"Работа началась!"` и завершает выполнение.

**Функция для реализации:**
```go
func waitForSignal() string {
    // ваш код здесь
}
```

**Пример main:**
```go
func main() {
    fmt.Println(waitForSignal())
}
```

**Решение:**
```Go
package main  
import "fmt"  
func waitForSignal() string {  
    ch1 := make(chan string)  
    start := make(chan bool)  
    go func() {  
       <-start  
       close(start)  
       ch1 <- "Работа началась!"  
    }()  
    start <- true  
    return <-ch1  
}  
/*  
Сделать то, что просит условие,  
невозможно. Чтобы "подать сигнал  
в горутину из main", необходимо  
поменять сигнатуры waitForSignal  
и main. Сделать так, чтобы горутина  
создавалась в main. Тогда с помощью  
канала можно будет передать  
сигнал. Иначе - только так.
*/  
func main() {  
    fmt.Println(waitForSignal())  
}
```
**Вывод:**
```Run
Работа началась!
```

```go
    // TODO: запустите три горутины worker()
    // 🟢 Отправка задач
    // TODO: отправьте числа от 1 до 5 в jobs и закройте канал
    // 🔁 Чтение результатов
    // TODO: получите все результаты из results через range и выведите их

```

**Решение:**
```Go
package main  
import "fmt"  
func worker(id int, jobs <-chan int, results chan<- int, done chan bool) {  
    for w := range jobs {  
       fmt.Println("Worker", id, "обрабатывает задачу", w)  
       results <- w * w  
    }  
    done <- true  
}  
func main() {  
    jobs := make(chan int, 5)  
    results := make(chan int, 5)  
    done := make(chan bool)  
    go worker(1, jobs, results, done)  
    go worker(2, jobs, results, done)  
    go worker(3, jobs, results, done)  
    for i := 1; i <= 5; i++ {  
       jobs <- i  
    }  
    close(jobs)
    /*
    Ждать <- done можно только после закрытия
    канала jobs, иначе func worker зависнет
    на for-range и не дойдёт до done <- true.
    */
    <-done  
    <-done  
    <-done  
    close(results)  
    fmt.Printf("[ ")  
    for val := range results {  
       fmt.Printf("%v ", val)  
    }  
    fmt.Printf("]\n")  
}
```

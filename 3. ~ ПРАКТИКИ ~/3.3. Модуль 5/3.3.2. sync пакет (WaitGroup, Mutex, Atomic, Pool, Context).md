**Каркас программы:**
```go
func main() {
    // 🟢 Вариант 1: через done канал
    // TODO: создайте done канал, запустите 3 горутины, каждая отправляет true
    // TODO: дождитесь 3 сигналов через <-done

    // 🟢 Вариант 2: через WaitGroup
    // TODO: создайте WaitGroup, добавьте 3 задачи
    // TODO: каждая горутина печатает сообщение и вызывает Done()
    // TODO: дождитесь завершения
}
```

**Решение:**
```Go
package main  
import (
    "fmt"
    "sync"
    )
func withWG(){
    var wg sync.WaitGroup
    wg.Add(3)
    for i := 1; i <= 3; i++ {
        go func(){
            defer wg.Done()
            fmt.Println("WaitGroup, задача:", i)
        }()
    }
    wg.Wait()
}
func withDone(){
    done := make(chan bool, 3)
    for i := 1; i <= 3; i++ {
        go func(){
            fmt.Println("Done, задача:", i)
            done <- true
        }()
    }
    <-done
    <-done
    <-done
}
/*
WaitGroup проще и надёжнее, чем метод с <-done.
~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~
В случае WaitGroup используются методы из пакета,
специально предназначенные для ожидания группы
горутин. Количество ожидаемых горутин записывается
в wg.Add(_) и все они будут ожидаться в wg.Wait.
~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~
В случае "Done" - нужно вручную создавать канал,
принимающий тип bool и вручную дожидаться передачи
от каждой горутины: <-done <-done <-done... и т.д.
*/
func main() {
    withWG()
    withDone()
}
```

WaitGroup, задача: 3

# Задача 4

**Формулировка:**
Реализуй простую имитацию пула рабочих горутин, которые обрабатывают задачи (например, печать сообщений).

- Пусть есть 5 задач (строки в слайсе).
- Создай 3 горутины, каждая берёт задачу из канала и обрабатывает.
- Используй `WaitGroup`, чтобы дождаться завершения всех воркеров.

**Каркас программы:**
```go
func main() {
    tasks := []string{"one", "two", "three", "four", "five"}
    ch := make(chan string)
    var wg sync.WaitGroup
    // 🟢 Запуск воркеров
    for i := 1; i <= 3; i++ {
        wg.Add(1)
        go func(workerID int) {
            defer wg.Done()
            // TODO: получать задачи из канала и печатать
        }(i)
    }
    // 🟢 Отправка задач
    // TODO: отправить все задачи в канал и закрыть его
    // 🟢 Ожидание завершения всех воркеров
    // TODO: дождаться всех горутин
}
```

**Решение:**
```Go
package main  
import (
    "fmt"
    "sync"
    )
/*
Через цикл "for i" с помощью "go func" ОДНОВРЕМЕННО стартуют
три воркера: 1, 2, 3. Каждый из них останавливается на
"for task := range ch" и ждёт следующего значения пока канал
открыт. Когда новое значение поступает в канал, один из
воркеров берёт его в работу.
Когда канал закрывается, воркеры дорабатывают оставшиеся
значения и идут дальше (перестают ожидать новых значений).
*/
func main() {
    tasks := []string{"one", "two", "three", "four", "five"}
    ch := make(chan string)
    var wg sync.WaitGroup
    for i := 1; i <= 3; i++ {
        wg.Add(1)
        go func(workerID int) {
            defer wg.Done()
            for task := range ch {
                fmt.Printf("Worker %v: %s\n", workerID, task)
            }
        }(i)
    }
    for r := range tasks {
        ch <- tasks[r]
    }
    close(ch)
    wg.Wait()
}
```
**Вывод:**
```Run
Worker 3: one
Worker 3: four
Worker 3: five
Worker 2: three
Worker 1: two
```

# Задача 1

**Формулировка:**
Программа запускает две горутины, которые увеличивают одну и ту же переменную `counter`.

Посмотри на результат и объясни, почему он непредсказуем.

- Запустить 2 горутины, которые делают `counter++` 1000 раз.
- Вывести итоговое значение счётчика.
- Объяснить, почему результат разный при каждом запуске.

**Каркас программы:**
```go
func main() {
    var counter int
    for i := 0; i < 2; i++ {
        go func() {
            // TODO: увеличить counter 1000 раз
        }()
    }
    // TODO: подождать немного , чтобы горутины успели выполниться
    fmt.Println("Результат:", counter)
}
```

**Решение:**
```Go
package main  
import (
    "fmt"
    "time"
    )
func main() {
    var counter int
    for i := 0; i < 2; i++ {
        go func(){
          for range 1000 {
              counter++
          }  
        }()
    }
    time.Sleep(3 * time.Second)
    fmt.Println("Результат:", counter)
}
/*
В этом примере возникает гонка данных,
поскольку две горутины работают с 
одной операцией параллельно.
А операция не является не атомарной.

counter++ выполняется в три действия:
    1. Прочитать counter
    2. Прибавить 1
    3. Записать результат в counter

Из-за этого может возникнуть ситуация,
когда несколько горутин начинают
рабоать с одним значением одновременно.

Пусть это значение - 67, тогда
к концу итерации две горутины
запишут в counter число 68.
На этом моменте единица потерялась.
И таких "потерь" может быть много,
поэтому результат работы данной
программы непредсказуем. При ожидаемом
результате в "2000", мы можем получить,
например, "1653".
*/
```
**Вывод:**
```Run
Результат: 1653
```

```go
package main

import (
	"fmt"
	"sync"
	"time"
)
func main() {
	// 🟥 Версия с гонкой
	var counter int
	for i := 0; i < 2; i++ {
		go func() {
			for j := 0; j < 1000; j++ {
				counter++ // небезопасная операция
			}
		}()
	}
	time.Sleep(time.Second)
	fmt.Println("С гонкой:", counter)
	
	// 🟩 Исправленная версия с Mutex
	var safeCounter int
	var mu sync.Mutex
	var wg sync.WaitGroup
	for i := 0; i < 2; i++ {
		wg.Add(1)
		go func() {
			defer wg.Done()
			for j := 0; j < 1000; j++ {
				mu.Lock()
				safeCounter++
				mu.Unlock()
			}
		}()
	}
	wg.Wait()
	fmt.Println("Без гонки:", safeCounter)
}
```

**Решение:**
```
В первом примере будут выводиться любые значения до 2000, так как присутствует гонка данных.
Во втором случае гонки данных нет, благодаря применению Mutex, поэтому результат вывода всегда предсказуем - ровно 2000.
```

    "sync"

package main  
import (
    "fmt"
    "sync"
    )
type Database struct {
    mu sync.RWMutex
    data map[string]string
}
func (d *Database) Write(key, value string) {
    d.mu.Lock()
    defer d.mu.Unlock()
    d.data[key] = value
}
func (d *Database) Read(key string)string {
    d.mu.RLock()
    defer d.mu.RUnlock()
    return d.data[key]
}
func main() {
    d := Database{
        data: make(map[string]string),
    }

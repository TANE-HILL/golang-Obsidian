# <u>Задание</u>

Возьмите структуру `Book` с полями `Title`, `Author`, `Year`.
1. Сериализуйте её в **JSON**, **YAML**, **XML** (выведите в консоль).
2. Сделайте обратное: из трёх строк (json/yaml/xml) распарсьте в `Book` и выведите `Title`.

---
# <u>Решение</u>

#### 1. <u>Go</u> **->** <u>JSON</u> / <u>YAML</u> / <u>XML</u> :
```Go
package main  
  
import (  
    "encoding/json"  
    "encoding/xml"
    "fmt"  
    "gopkg.in/yaml.v3"
)  
  
func main() {  
    // ~ ~ ~ ~ ~ G O -> J S O N ~ ~ ~ ~ ~  
    type BookJSON struct {  
       Title  string `json:"title"`  
       Author string `json:"author"`  
       Year   int    `json:"year"`  
    }  
    bookJSON := BookJSON{"System Design", "Alex Xu", 2024}  
    dataJSON, errJSON := json.MarshalIndent(bookJSON, "", "  ")  
    if errJSON != nil {  
       panic(errJSON)  
    }  
    fmt.Printf("[ Go -> JSON ]\n%s\n\n", string(dataJSON))  
  
    // ~ ~ ~ ~ ~ G O -> Y A M L ~ ~ ~ ~ ~  
    type BookYAML struct {  
       Title  string `yaml:"title"`  
       Author string `yaml:"author"`  
       Year   int    `yaml:"year"`  
    }  
    bookYAML := BookYAML{"System Design", "Alex Xu", 2024}  
    dataYAML, errYAML := yaml.Marshal(bookYAML)  
    if errYAML != nil {  
       panic(errYAML)  
    }  
    fmt.Printf("[ Go -> YAML ]\n%s\n\n", string(dataYAML))  
  
    // ~ ~ ~ ~ ~ G O -> X M L ~ ~ ~ ~ ~  
    type BookXML struct {  
       XMLName xml.Name `xml:"book"`  
       Title   string   `xml:"title"`  
       Author  string   `xml:"author"`  
       Year    int      `xml:"year"`  
    }  
    bookXML := BookXML{Title: "System Design", Author: "Alex Xu", Year: 2024}  
    dataXML, errXML := xml.MarshalIndent(bookXML, "", "  ")  
    if errXML != nil {  
       panic(errXML)  
    }  
    fmt.Printf("[ Go -> XML ]\n%s\n\n", string(dataXML))  
}
```
#### <u>Вывод</u>:
```Run
[ Go -> JSON ]
{
  "title": "System Design",
  "author": "Alex Xu",
  "year": 2024
}

[ Go -> YAML ]
title: System Design
author: Alex Xu
year: 2024


[ Go -> XML ]
<book>
  <title>System Design</title>
  <author>Alex Xu</author>
  <year>2024</year>
</book>
```

#### 2. <u>JSON</u> / <u>YAML</u> / <u>XML</u> **->** <u>Go</u> :
```Go
package main  
  
import (  
    "encoding/json"  
    "encoding/xml"
    "fmt"  
    "gopkg.in/yaml.v3"
)  
  
func main() {  
    // ~ ~ ~ ~ ~ J S O N -> G O ~ ~ ~ ~ ~  
    type BookJSON struct {  
       Title  string `json:"title"`  
       Author string `json:"author"`  
       Year   int    `json:"year"`  
    }  
    jsonStr := `{"title":"System Design","author":"Alex Xu","year":2024}`  
    var bookJSON BookJSON  
    if errJSON := json.Unmarshal([]byte(jsonStr), &bookJSON); errJSON != nil {  
       panic(errJSON)  
    }  
    fmt.Printf("[ JSON -> Go ]\n%s - %s - %v\n\n", bookJSON.Title, bookJSON.Author, bookJSON.Year)  
  
    // ~ ~ ~ ~ ~ Y A M L -> G O ~ ~ ~ ~ ~  
    type BookYAML struct {  
       Title  string `yaml:"title"`  
       Author string `yaml:"author"`  
       Year   int    `yaml:"year"`  
    }  
    var bookYAML BookYAML  
    yamlStr := `title: System Design  
author: Alex Xu  
year: 2024  
`  
    if errYAML := yaml.Unmarshal([]byte(yamlStr), &bookYAML); errYAML != nil {  
       panic(errYAML)  
    }  
    fmt.Printf("[ YAML -> Go ]\n%s - %s - %v\n\n", bookYAML.Title, bookYAML.Author, bookYAML.Year)  
  
    // ~ ~ ~ ~ ~ X M L -> G O ~ ~ ~ ~ ~  
    type BookXML struct {  
       XMLName xml.Name `xml:"book"`  
       Title   string   `xml:"title"`  
       Author  string   `xml:"author"`  
       Year    int      `xml:"year"`  
    }  
    xmlStr := `  
<book>  
  <title>System Design</title>  <author>Alex Xu</author>  <year>2024</year></book>  
`  
    var bookXML BookXML  
  
    if errXML := xml.Unmarshal([]byte(xmlStr), &bookXML); errXML != nil {  
       panic(errXML)  
    }  
    fmt.Printf("[ XML -> Go ]\n%s - %s - %v\n\n", bookXML.Title, bookXML.Author, bookXML.Year)  
}
```
#### <u>Вывод</u>:
```Run
[ JSON -> Go ]
System Design - Alex Xu - 2024

[ YAML -> Go ]
System Design - Alex Xu - 2024

[ XML -> Go ]
System Design - Alex Xu - 2024
```

# <u>Ключевые выводы по практике</u>

#### Во всех трёх форматах принцип один:
- Для `Go -> ...` :
	- `struct` --> `Marshal` --> `[]byte`
- Для `... -> Go` :
	- `[]byte` --> `Unmarshal` --> `struct`

---
# `Go -> ...` ~ <font color="#ff0000">Marshall</font> ~ 

- `json.Marshal(...)`
- `json.MarshalIndent(...)` <font color="#7f7f7f">(для красивого вывода json)</font>
- `yaml.Marshal(...)`
- `xml.Marshal(...)`
#### <u>Синтаксис практически идентичен</u>:
- `data, err := json.Marshal(book)`
- `data, err := json.MarshalIndent(bookJSON, "", "  ")`
- `data, err := yaml.Marshal(book)`
- `data, err := xml.Marshal(book)`
#### <u>Всегда возвращает</u> `[]byte`, <u>поэтому для вывода</u>:
`data, err := json.Marshal(book)`

---
# `... -> Go` ~ <font color="#ff0000">Unmarshall</font> ~

*Во всех случаях передаём указатель на структуру*:

- `json.Unmarshal(data, &book)`
- `yaml.Unmarshal(data, &book)`
- `xml.Unmarshal(data, &book)`
#### <u>Поля должны совпадать</u>:
```Go
type Book struct {  
    Title  string `json:"title"`  
    Author string `json:"author"`  
    Year   int    `json:"year"`  
}

str := `{"title":"System Design","author":"Alex Xu","year":2024}`

var book Book
```

#### <u>Синтаксис идентичен</u>:
```Go
if err := json.Unmarshal([]byte(str), &book); err != nil {  
    panic(err)
}
```

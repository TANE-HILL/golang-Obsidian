# Оконные функции SQL

[[~ СПРАВОЧНИК ФУНКЦИЙ SQL ~#<font color=" ffff00">Оконные функции ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~</font>|Оконные функции в справочнике]].

Оконные функции позволяют выполнять вычисления по группам строк, связанным с текущей строкой, при этом не объединяя строки в одну запись. Результат вычисления добавляется в отдельный столбец.

---
# Принцип работы

В обычном SQL-запросе агрегатные функции работают с группами строк и возвращают агрегированный результат для каждой группы.

Оконные функции позволяют для **каждой строки** определить связанное с ней множество строк — **окно** — и выполнить вычисление по этому окну.

<u>Окном может быть:</u>
- вся таблица;
- отдельная **партиция** — группа строк с одинаковыми значениями одного или нескольких столбцов;
- **рамка окна** — определённый диапазон строк внутри таблицы или партиции.

Рамка может изменяться для каждой строки. Например, можно задать окно как **предыдущая + текущая строка**. В таком случае окно будет перемещаться по таблице, а результат функции — изменяться для каждой строки.

---
# Синтаксис оконной функции

```PostgreSQL
SELECT <оконная_функция>(<поле_таблицы>)
OVER (
    [PARTITION BY <столбцы_для_разделения>]
    [ORDER BY <столбцы_для_сортировки>]
    [ROWS | RANGE <определение_диапазона_строк>]
);
```

<u>Где:</u>
- `<оконная_функция>(<поле_таблицы>)` — используемая оконная функция, например `AVG(price)`;
- `OVER` — определяет окно, которое передаётся в оконную функцию;
- `PARTITION BY` — разделяет строки на отдельные партиции;
- `ORDER BY` — задаёт порядок строк внутри окна;
- `ROWS` или `RANGE` — определяет рамку окна.

Если `OVER()` оставить без параметров, окном будут все строки результата запроса.

---
# `PARTITION BY`

`PARTITION BY` разделяет строки на непересекающиеся группы по значениям одного или нескольких столбцов.

Например:
```PostgreSQL
SELECT
    Student.first_name,
    Student.last_name,
    Student_in_class.class,
    COUNT(*) OVER (
        PARTITION BY Student_in_class.class
    ) AS student_count_in_class
FROM Student_in_class
JOIN Student
    ON Student_in_class.student = Student.id;
```

Здесь:
- `PARTITION BY Student_in_class.class` разделяет строки по классам;
- `COUNT(*)` подсчитывает количество строк в каждой партиции;
- `student_count_in_class` содержит количество учащихся в классе текущей строки.

В отличие от `GROUP BY`, строки не объединяются — каждая исходная строка остаётся в результате. 

---
# `ORDER BY` внутри окна

`ORDER BY` определяет порядок строк внутри окна.

Особенно важен этот параметр для **оконных функций ранжирования**, поскольку именно порядок строк определяет их позицию внутри окна.

Пример:
```PostgreSQL
SELECT
    first_name,
    last_name,
    class,
    ROW_NUMBER() OVER (
        PARTITION BY class
        ORDER BY last_name
    ) AS row_number
FROM Student_in_class;
```

---
# Рамки окна `ROWS` и `RANGE`

`ROWS` и `RANGE` позволяют определить конкретный диапазон строк, который будет передаваться в оконную функцию.

Например, можно задать рамку как **предыдущая + текущая строка**:
```PostgreSQL
SELECT
    price,
    AVG(price) OVER (
        ORDER BY price
        ROWS BETWEEN 1 PRECEDING AND CURRENT ROW
    ) AS avg_price
FROM Rooms;
```

Для первой строки предыдущей строки нет, поэтому окно будет состоять только из текущей строки.

---
# Порядок выполнения оконных функций в `SELECT`

Оконные функции выполняются **после фильтрации и группировки**, но **до финальной сортировки результата**.

Упрощённо порядок можно представить так:
```text
FROM
→ WHERE
→ GROUP BY
→ HAVING
→ оконные функции
→ ORDER BY
```

Это важно учитывать при построении сложных запросов.

---
# Оконные функции и `GROUP BY`

<u>Ключевое отличие:</u>
**Оконные функции** вычисляют результат для каждой строки и добавляют его в отдельный столбец.

**Агрегатные функции с `GROUP BY`** объединяют строки в группы и возвращают одну строку для каждой группы.

Например, `GROUP BY`:
```PostgreSQL
SELECT
    class,
    COUNT(*) AS student_count
FROM Student_in_class
GROUP BY class;
```

Оконная функция:
```PostgreSQL
SELECT
    student,
    class,
    COUNT(*) OVER (
        PARTITION BY class
    ) AS student_count
FROM Student_in_class;
```

В первом случае получаем **одну строку на класс**, во втором — **каждого ученика с количеством учеников в его классе**.

---
# Главное

- `OVER()` превращает функцию в оконную.
- `PARTITION BY` разделяет строки на партиции.
- `ORDER BY` задаёт порядок строк внутри окна.
- `ROWS` и `RANGE` определяют рамку окна.
- Оконные функции не объединяют строки, а добавляют вычисленный результат к каждой строке.
- В отличие от `GROUP BY`, исходные строки сохраняются.

# Хранимые процедуры и функции

[[3.4.14. Хранимые процедуры в SQL|Хранимые процедуры]] и [[3.4.13. Хранимые функции в SQL|хранимые функции]] — заранее созданные и сохранённые в базе данных блоки кода, которые можно многократно вызывать по имени.

Они позволяют выносить повторяющуюся логику в [[3.0.0. Что такое БД и СУБД|базу данных]].

---
# Зачем нужны?

Хранимые процедуры и функции позволяют:
- **Повторно использовать код** — написать логику один раз и использовать её многократно.
- **Повысить производительность** — код выполняется непосредственно на сервере базы данных.
- **Повысить безопасность** — можно предоставить доступ к процедуре или функции без прямого доступа к таблицам.
- **Централизовать логику** — часть бизнес-логики хранится непосредственно в базе данных.

---
# Отличия процедур и функций

|Характеристика|Хранимые процедуры|Хранимые функции|
|---|---|---|
|Возвращаемое значение|Не обязаны возвращать значение|Возвращают значение|
|Использование в запросах|Вызываются отдельно|Могут использоваться в `SELECT`, `WHERE` и других частях запроса|
|Изменение данных|Могут изменять данные|Могут изменять данные|
|Вызов|`CALL procedure_name()`|`SELECT function_name()`|

> **Важно:** в PostgreSQL функции и процедуры имеют разные возможности и правила использования. Функции могут использоваться как часть SQL-выражений, а процедуры вызываются отдельной командой `CALL`.

---
# Когда использовать процедуры?

Хранимые процедуры подходят, когда необходимо:
- выполнить последовательность операций;
- изменить данные в нескольких таблицах;
- реализовать сложную логику;
- выполнить несколько действий как единый процесс.

Например, процедура оформления заказа может:
1. Проверить наличие товара на складе.
2. Создать запись в таблице заказов.
3. Обновить остатки товара.
4. Добавить запись в историю операций.

Вызов процедуры в PostgreSQL:
```PostgreSQL
CALL create_order(
    customer_id => 123,
    product_id => 456,
    quantity => 2
);
```

---
# Когда использовать функции?

Хранимые функции подходят, когда необходимо:
- выполнить вычисление и вернуть результат;
- создать переиспользуемую формулу;
- преобразовать данные определённым образом;
- использовать результат в других SQL-запросах.

Например, функцию расчёта скидки можно использовать непосредственно в `SELECT`:
```PostgreSQL
SELECT
    product_name,
    price,
    calculate_discount(price, customer_type) AS discount_amount
FROM Products;
```
- Функция принимает цену и тип клиента и возвращает размер скидки.

---
# Простое правило выбора

- Нужно **получить значение и использовать его в SQL-запросе** → **функция**.
- Нужно **выполнить последовательность действий или изменить данные** → **процедура**.

---

# Главное

- **Функция** возвращает значение и может использоваться внутри SQL-запросов.
- **Процедура** вызывается отдельно через `CALL`.
- Процедуры удобны для последовательности действий.
- Функции удобны для вычислений и получения результата.
- Оба объекта хранятся непосредственно в базе данных и могут использоваться многократно.

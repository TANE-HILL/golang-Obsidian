# Создание транзакций

**Транзакция** — последовательность операций с [[3.0.0. Что такое БД и СУБД|базой данных]], которые выполняются как единое целое.

Например, при переводе денег между счетами необходимо одновременно выполнить два действия:
- списать деньги со счёта отправителя;
- зачислить деньги на счёт получателя.

Если одна из операций завершится ошибкой, необходимо отменить все изменения, выполненные в рамках транзакции. Для этого используются команды `COMMIT` и `ROLLBACK`.

---
# Запуск и завершение транзакций

В PostgreSQL транзакцию можно начать с помощью `BEGIN` или `START TRANSACTION`.

```PostgreSQL
BEGIN;
```

После выполнения необходимых SQL-запросов транзакцию можно завершить двумя способами.

**`COMMIT`** — подтверждает изменения и делает их постоянными:
```PostgreSQL
COMMIT;
```

**`ROLLBACK`** — отменяет все изменения, выполненные с начала транзакции:
```PostgreSQL
ROLLBACK;
```

---
# Пример транзакции

Рассмотрим перевод `1000` единиц со счёта одного пользователя на счёт другого:
```PostgreSQL
BEGIN;

-- Списание денег со счёта отправителя
UPDATE accounts
SET user_balance = user_balance - 1000
WHERE user_id = 1;

-- Зачисление денег на счёт получателя
UPDATE accounts
SET user_balance = user_balance + 1000
WHERE user_id = 2;

COMMIT;
```
Если одна из операций завершится ошибкой, вместо `COMMIT` можно выполнить:
```PostgreSQL
ROLLBACK;
```

В этом случае все изменения, выполненные после начала транзакции, будут отменены.

---
# Точки сохранения транзакции

Иногда требуется отменить только часть выполненных операций, не откатывая всю транзакцию.

Для этого используются **точки сохранения** — `SAVEPOINT`.

Создание точки сохранения:
```PostgreSQL
SAVEPOINT my_savepoint;
```
Откат к определённой точке:
```PostgreSQL
ROLLBACK TO SAVEPOINT my_savepoint;
```

Пример:
```PostgreSQL
BEGIN;

SAVEPOINT before_updating_user_1;

UPDATE accounts
SET balance = balance + 100
WHERE user_id = 1;

-- Отменяем изменение первого пользователя
ROLLBACK TO SAVEPOINT before_updating_user_1;

-- Изменение второго пользователя сохраняется
UPDATE accounts
SET balance = balance + 200
WHERE user_id = 2;

COMMIT;
```

В результате изменение баланса первого пользователя будет отменено, а изменение баланса второго пользователя будет зафиксировано.

---
# Важные моменты

- Создание `SAVEPOINT` само по себе ничего не сохраняет окончательно. Изменения становятся постоянными только после `COMMIT`.
- `ROLLBACK TO SAVEPOINT` отменяет изменения, выполненные после указанной точки сохранения.
- Обычный `ROLLBACK` без указания `SAVEPOINT` отменяет **всю транзакцию**.
- После `COMMIT` или полного `ROLLBACK` транзакция завершается, а связанные с ней ресурсы освобождаются.

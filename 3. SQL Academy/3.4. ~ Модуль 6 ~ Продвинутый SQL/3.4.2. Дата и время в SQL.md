# Дата и время в SQL

[[~ СПРАВОЧНИК ФУНКЦИЙ SQL ~#<font color=" 00b050">Функции дат и времени</font>|Функции даты и времени в справочнике]].

В **PostgreSQL** для работы с временными данными используются типы `DATE`, `TIME`, `TIMESTAMP` и `TIMESTAMPTZ`.

Временные данные можно:
- получить из существующего столбца;
- задать строковым представлением;
- получить с помощью встроенных функций.

---
# Строковое представление временных данных

Основные форматы:

|Тип|Формат|
|---|---|
|`DATE`|`YYYY-MM-DD`|
|`TIME`|`HH:MM:SS`|
|`TIMESTAMP`|`YYYY-MM-DD HH:MM:SS`|
|`TIMESTAMPTZ`|`YYYY-MM-DD HH:MM:SS+TZ`|

Для явного преобразования строки в дату или время используется `CAST`:

```PostgreSQL
SELECT CAST('2022-06-16 16:37:23' AS TIMESTAMP) AS timestamp_1,
       CAST('2021-02-12' AS DATE) AS date_1,
       CAST('16:23:13' AS TIME) AS time_1;
```

Также можно использовать сокращённый синтаксис:

```PostgreSQL
SELECT TIMESTAMP '2022-06-16 16:37:23',
       DATE '2021-02-12',
       TIME '16:23:13';
```

---

# Функции генерации дат

Если строка имеет нестандартный формат, для преобразования даты используется функция **`TO_DATE`**.

```PostgreSQL
SELECT TO_DATE('November 13, 1998', 'Month DD, YYYY') AS date;
```

Результат:

|date|
|---|
|1998-11-13|

Для преобразования строки в дату и время также используется **`TO_TIMESTAMP`**:

```PostgreSQL
SELECT TO_TIMESTAMP('November 13, 1998 16:30:00',
                    'Month DD, YYYY HH24:MI:SS');
```

Для получения текущей даты и времени используются:

- `CURRENT_DATE` — текущая дата;
- `CURRENT_TIME` — текущее время;
- `NOW()` — текущая дата и время.

```PostgreSQL
SELECT CURRENT_DATE,
       CURRENT_TIME,
       NOW();
```

---
# Функции извлечения временных данных

Чтобы получить отдельную часть даты или времени, в PostgreSQL используется функция **`EXTRACT`**.

|Функция|Описание|
|---|---|
|`EXTRACT(YEAR FROM date)`|Год|
|`EXTRACT(MONTH FROM date)`|Месяц|
|`EXTRACT(DAY FROM date)`|День|
|`EXTRACT(HOUR FROM time)`|Час|
|`EXTRACT(MINUTE FROM time)`|Минуты|

Например:

```PostgreSQL
SELECT EXTRACT(YEAR FROM TIMESTAMP '2022-06-16 16:37:23'),
       EXTRACT(MONTH FROM TIMESTAMP '2022-06-16 16:37:23'),
       EXTRACT(DAY FROM TIMESTAMP '2022-06-16 16:37:23');
```

---
# Отличие `TIMESTAMP` от `TIMESTAMPTZ`

В PostgreSQL используются два основных типа для хранения даты и времени:

- **`TIMESTAMP`** — дата и время без часового пояса;
- **`TIMESTAMPTZ`** — дата и время с учётом часового пояса.

|Критерий|`TIMESTAMP`|`TIMESTAMPTZ`|
|---|---|---|
|Часовой пояс|Не учитывается|Учитывается|
|Хранение|Дата и время без привязки к часовому поясу|Момент времени|
|Отображение|Не зависит от часового пояса|С учётом часового пояса текущей сессии|

Например:

```PostgreSQL
SELECT TIMESTAMP '2026-09-19 12:00:00',
       TIMESTAMPTZ '2026-09-19 12:00:00+03';
```

> ⚠️ **Важно:** `TIMESTAMPTZ` не хранит сам часовой пояс. PostgreSQL хранит момент времени и отображает его с учётом часового пояса текущей сессии.

---
# Часовые пояса

В качестве точки отсчёта используется **UTC**. Часовой пояс можно задавать на разных уровнях:
- для всей базы данных;
- для конкретного пользователя;
- для текущей сессии.

Для базы данных:
```PostgreSQL
ALTER DATABASE mydb
SET timezone = 'Europe/Moscow';
```

Для пользователя:
```PostgreSQL
ALTER USER myuser
SET timezone = 'Europe/Moscow';
```

Для текущей сессии:
```PostgreSQL
SET TIME ZONE 'Europe/Moscow';
```

Также можно указать смещение:
```PostgreSQL
SET TIME ZONE '+03:00';
```

После изменения часового пояса значения `TIMESTAMPTZ` отображаются с учётом нового часового пояса.

# Примеры задач на дату и время

При работе с датами часто требуется определить возраст человека по дате рождения.

Простой расчёт разницы между текущим годом и годом рождения некорректен, поскольку не учитывает, наступил ли день рождения в текущем году.

Например:
```PostgreSQL
SELECT EXTRACT(YEAR FROM NOW())
     - EXTRACT(YEAR FROM TIMESTAMP '2003-07-03 14:10:26');
```

Такой способ может вернуть возраст на один год больше фактического.

Расчёт через количество дней также не является абсолютно точным из-за високосных годов.

Для корректного определения возраста в PostgreSQL используется функция **`AGE`**, которая возвращает интервал между двумя датами.

```PostgreSQL
SELECT AGE(NOW(), TIMESTAMP '2003-07-03 14:10:26');
```

Чтобы получить количество полных лет:
```PostgreSQL
SELECT EXTRACT(
    YEAR FROM AGE(NOW(), TIMESTAMP '2003-07-03 14:10:26')
);
```

Здесь `AGE` вычисляет точный интервал между датой рождения и текущей датой, а `EXTRACT` извлекает из него количество лет.

# Практика

<u>Задание 1:</u>  
Извлеките значение часа *(от 0 до 23)* из времени **`'14:30:45'`** с помощью соответствующей функции. Используйте псевдоним **`hour_value`** для вывода значения.
<u>Решение:</u>
```PostgreSQL
SELECT EXTRACT(HOUR FROM TIME '14:30:45') AS hour_value
```

<u>Задание 2:</u>  
Выведите имена *(поле **`member_name`**)* и возраст для каждого человека из таблицы **`FamilyMembers`**.   
Для вывода возраста используйте псевдоним **`age`**.
<u>Решение:</u>
```PostgreSQL
SELECT member_name,
    (SELECT EXTRACT(
        YEAR FROM AGE(NOW(), birthday)
    )) AS age
FROM FamilyMembers
```

# Функции преобразования типов, `CAST`

Функция **`CAST`** [[~ СПРАВОЧНИК ФУНКЦИЙ SQL ~#<font color=" ff0000"><u>CAST</u></font>|в справочнике]].

При работе со значениями разных типов данных иногда требуется явно преобразовать значение из одного типа в другой.

В PostgreSQL для преобразования типов используются функция **`CAST`** и оператор **`::`**. 

---
# Синтаксис

С помощью `CAST`:
```PostgreSQL
CAST(значение AS тип_для_конвертации);
```

С помощью оператора `::`:
```PostgreSQL
значение::тип_для_конвертации;
```

Например:
```PostgreSQL
SELECT CAST(12005.6 AS INTEGER) AS cast_example,
       12005.4::INTEGER AS operator_example;
```

Результат:

|`cast_example`|`operator_example`|
|--:|--:|
|12006|12005|

---
# Типы данных для `CAST`

В PostgreSQL `CAST` позволяет преобразовывать значения в следующие типы:

|Тип|Описание|
|---|---|
|`DATE`|Дата в формате `YYYY-MM-DD`|
|`TIMESTAMP`|Дата и время|
|`TIME`|Время в формате `HH:MM:SS`|
|`NUMERIC`|Числовое значение с фиксированной точностью|
|`VARCHAR`|Строковое значение|
|`INTEGER`|Целое число|
|`BIGINT`|Большое целое число|
|`BOOLEAN`|Логический тип|
|`TEXT`|Текстовый тип|

Например, преобразование строки в дату:
```PostgreSQL
SELECT CAST('2026-09-19' AS DATE);
```

То же самое с оператором `::`:
```PostgreSQL
SELECT '2026-09-19'::DATE;
```

---
# Преобразование числовых значений

`CAST` можно использовать для преобразования дробных чисел в целые:
```PostgreSQL
SELECT CAST(12005.6 AS INTEGER),
       12005.4::INTEGER;
```

При преобразовании в `INTEGER` дробная часть округляется до ближайшего целого.

---

# Преобразование строк

Строковое значение можно преобразовать в числовой тип:
```PostgreSQL
SELECT CAST('123' AS INTEGER),
       '456'::INTEGER;
```

Также можно преобразовать число в строку:
```PostgreSQL
SELECT CAST(123 AS TEXT),
       456::TEXT;
```

---
# Невозможность преобразования

`CAST` требует, чтобы исходное значение соответствовало формату целевого типа.
Например, строку, содержащую произвольный текст, нельзя преобразовать в дату:
```PostgreSQL
SELECT CAST('SQL Academy' AS DATE);
```

PostgreSQL вернёт **ошибку**, поскольку значение `'SQL Academy'` не может быть преобразовано в `DATE`.
> ⚠️ **Важно:** PostgreSQL не преобразует некорректное значение в `NULL` автоматически. При невозможности преобразования возникает ошибка.

# Основные оконные функции

Оконные функции можно разделить на 3 группы:
- **Агрегатные оконные функции**
- **Ранжирующие оконные функции**
- **Оконные функции смещения**
---
## Агрегатные оконные функции

Агрегатные функции выполняют вычисления над набором данных и возвращают итоговое значение.

|Функция|Описание|
|---|---|
|`SUM`|Подсчитывает общую сумму значений|
|`COUNT`|Считает количество записей|
|`AVG`|Рассчитывает среднее арифметическое|
|`MAX`|Находит максимальное значение|
|`MIN`|Находит минимальное значение|

Например, можно получить сумму, количество, среднее, максимум и минимум цены отдельно для каждого типа жилья:

```PostgreSQL
SELECT id,
       home_type,
       price,
       SUM(price) OVER (
           PARTITION BY home_type
       ) AS sum,
       COUNT(price) OVER (
           PARTITION BY home_type
       ) AS count,
       AVG(price) OVER (
           PARTITION BY home_type
       ) AS avg,
       MAX(price) OVER (
           PARTITION BY home_type
       ) AS max,
       MIN(price) OVER (
           PARTITION BY home_type
       ) AS min
FROM Rooms;
```

`PARTITION BY home_type` разделяет строки на группы по типу жилья, а оконные функции выполняются отдельно внутри каждой группы.

---
## Ранжирующие оконные функции

Ранжирующие оконные функции присваивают каждой строке определённый ранг или номер.

Для ранжирующих функций в `OVER` необходимо указать `ORDER BY`, определяющий порядок ранжирования.

Основные функции:
- **`ROW_NUMBER`** — возвращает порядковый номер строки;
- **`RANK`** — возвращает ранг строки. При одинаковых значениях одинаковые строки получают одинаковый ранг, после чего в нумерации появляются пропуски;
- **`DENSE_RANK`** — возвращает ранг строки без пропусков.

Например:
```PostgreSQL
SELECT id,
       home_type,
       price,
       ROW_NUMBER() OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS row_number,
       RANK() OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS rank,
       DENSE_RANK() OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS dense_rank
FROM Rooms;
```

Рассмотрим строки с одинаковой ценой:

|`price`|`ROW_NUMBER`|`RANK`|`DENSE_RANK`|
|--:|--:|--:|--:|
|120|7|7|7|
|120|8|7|7|
|120|9|7|7|
|135|10|10|8|

Здесь:
- `ROW_NUMBER` присваивает каждой строке уникальный номер;
- `RANK` присваивает одинаковый ранг одинаковым значениям и пропускает следующие номера;
- `DENSE_RANK` также присваивает одинаковый ранг, но не пропускает номера.

## Оконные функции смещения

Оконные функции смещения позволяют обращаться к значениям других строк относительно текущей строки, а также к первому или последнему значению в окне.

Основные функции:
- **`LAG`** — обращается к предыдущим строкам;
- **`LEAD`** — обращается к следующим строкам;
- **`FIRST_VALUE`** — возвращает первое значение в окне;
- **`LAST_VALUE`** — возвращает последнее значение в окне.

---
### Функция `LAG`

`LAG` возвращает значение из предыдущей строки.

Синтаксис:
```PostgreSQL
LAG(столбец [, количество_строк [, значение_по_умолчанию]])
```

По умолчанию выполняется смещение на одну строку.
```PostgreSQL
SELECT id,
       home_type,
       price,
       LAG(price) OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS lag,
       LAG(price, 2) OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS lag_2
FROM Rooms;
```
`LAG(price)` возвращает цену предыдущей строки, а `LAG(price, 2)` — цену строки двумя позициями выше.

---
### Функция `LEAD`

`LEAD` возвращает значение из следующей строки.
```PostgreSQL
SELECT id,
       home_type,
       price,
       LEAD(price) OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS lead
FROM Rooms;
```
`LEAD(price)` возвращает цену следующей строки относительно текущей.

---
### Функция `FIRST_VALUE`

`FIRST_VALUE` возвращает первое значение в окне.

```PostgreSQL
SELECT id,
       home_type,
       price,
       FIRST_VALUE(price) OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS first_value
FROM Rooms;
```

В данном случае первой будет строка с минимальной `price`, поскольку сортировка выполняется по возрастанию.

---
### Функция `LAST_VALUE`

`LAST_VALUE` возвращает последнее значение в текущей рамке окна.

При использовании `ORDER BY` рамка по умолчанию заканчивается текущей строкой:
```PostgreSQL
RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
```
Поэтому `LAST_VALUE` без явного указания рамки будет возвращать значение **текущей строки**, а не последней строки всей партиции.

Чтобы получить действительно последнее значение всей партиции, необходимо расширить рамку:
```PostgreSQL
ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
```

Пример:
```PostgreSQL
SELECT id,
       home_type,
       price,
       LAST_VALUE(price) OVER (
           PARTITION BY home_type
           ORDER BY price
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS last_value
FROM Rooms;
```

Здесь `last_value` будет содержать максимальную цену внутри каждого `home_type`, поскольку строки отсортированы по `price`.

---
# Все основные функции в одном запросе

```PostgreSQL
SELECT id,
       home_type,
       price,
       ROW_NUMBER() OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS row_number,
       RANK() OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS rank,
       DENSE_RANK() OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS dense_rank,
       LAG(price) OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS lag,
       LEAD(price) OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS lead,
       FIRST_VALUE(price) OVER (
           PARTITION BY home_type
           ORDER BY price
       ) AS first_value,
       LAST_VALUE(price) OVER (
           PARTITION BY home_type
           ORDER BY price
           ROWS BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING
       ) AS last_value
FROM Rooms;
```

# Практика

<u>Задание 1:</u>
Из таблицы **`Rooms`** вывести **`id`**, **`home_type`** и **`price`** у всех жилых помещений, а также в отдельной колонке **`room_rank`** вывести ранг данного жилого помещения в его категории *(**`home_type`**)* по цене, используя для этого функцию **`DENSE_RANK`** так, чтобы самое дешёвое жилое помещение имело ранг **`1`**, следующие за ним по цене — **`2`** и так далее.
<u>Решение:</u>
```PostgreSQL
SELECT id, home_type, price,
    DENSE_RANK() OVER (
        PARTITION BY home_type
        ORDER BY price) AS room_rank
FROM Rooms
```

<u>Задание 2:</u>
Дополните запрос так, чтобы найти разницу во времени между вылетами среди рейсов одной компании.   
В качестве результирующей выборки выведите идентификаторы компаний *(в поле **`company`**)*, время вылета их рейсов *(в поле **`time_out`**)* и время *(в поле **`time_diff`**)*, прошедшее с предыдущего вылета в формате **`ЧЧ-MM-СС`**. Если это был первый рейс компании, то в поле **`time_diff`** нужно вывести "**`00:00:00`**".
<u>Решение:</u>
```PostgreSQL
SELECT company,
       time_out,
       COALESCE(
           time_out - LAG(time_out) OVER (
               PARTITION BY company
               ORDER BY time_out
           ),
           INTERVAL '0'
       ) AS time_diff
FROM Trip
```

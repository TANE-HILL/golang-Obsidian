# Операторы IF, CASE, WHILE в хранимых процедурах

[[3.4.14. Хранимые процедуры в SQL|Хранимые процедуры]] и [[3.4.13. Хранимые функции в SQL|функции]] — это не просто удобные контейнеры для группы запросов. Они позволяют реализовать достаточно сложную логику, используя операторы ветвления и циклы.

В этой статье рассмотрим основные операторы управления потоком выполнения: условные операторы `IF` и `CASE`, а также цикл `WHILE`.

---
# Условный оператор IF

Оператор `IF` позволяет выполнять код в зависимости от выполнения условия.

## Синтаксис `IF`

В PostgreSQL используется `ELSIF`:
```PostgreSQL
IF условие THEN
    -- код, выполняемый при истинном условии
ELSIF другое_условие THEN
    -- код для альтернативного условия
ELSE
    -- код по умолчанию
END IF;
```

## Пример использования IF

Создадим функцию, которая определяет категорию студента по возрасту:
```PostgreSQL
CREATE OR REPLACE FUNCTION categorize_student_by_age(student_id INT)
RETURNS VARCHAR(20)
LANGUAGE plpgsql
AS $$
DECLARE
    student_age INT;
    category VARCHAR(20);
BEGIN
    -- Получаем возраст студента
    SELECT EXTRACT(YEAR FROM AGE(CURRENT_DATE, birthday))
    INTO student_age
    FROM Student
    WHERE id = student_id;

    -- Определяем категорию по возрасту
    IF student_age < 18 THEN
        category := 'Несовершеннолетний';
    ELSIF student_age BETWEEN 18 AND 25 THEN
        category := 'Молодой';
    ELSE
        category := 'Взрослый';
    END IF;

    RETURN category;
END;
$$;
```
Использование функции:
```PostgreSQL
SELECT categorize_student_by_age(1) AS age_category;
```

Результат:

|age_category|
|---|
|Молодой|

Здесь:
- `student_age` — переменная для хранения возраста студента.
- `IF` проверяет первое условие.
- `ELSIF` проверяет альтернативное условие.
- `ELSE` выполняется, если ни одно из предыдущих условий не выполнено.
- `RETURN` возвращает полученную категорию.

# Оператор выбора CASE

Оператор `CASE` предоставляет более удобный способ обработки множественных условий.

## Синтаксис `CASE`

В PostgreSQL `CASE` является выражением, поэтому используется `END`, без `CASE` после него:
```PostgreSQL
CASE
    WHEN условие 1 THEN результат 1
    WHEN условие 2 THEN результат 2
    ELSE результат_по_умолчанию
END;
```

## Пример использования CASE

Создадим функцию категоризации студентов с использованием оператора `CASE`:
```PostgreSQL
CREATE OR REPLACE FUNCTION categorize_student_with_case(student_id INT)
RETURNS VARCHAR(20)
LANGUAGE plpgsql
AS $$
DECLARE
    student_age INT;
    category VARCHAR(20);
BEGIN
    -- Получаем возраст студента
    SELECT EXTRACT(YEAR FROM AGE(CURRENT_DATE, birthday))
    INTO student_age
    FROM Student
    WHERE id = student_id;

    -- Определяем категорию с помощью CASE
    category := CASE
        WHEN student_age < 18 THEN 'Несовершеннолетний'
        WHEN student_age BETWEEN 18 AND 25 THEN 'Молодой'
        ELSE 'Взрослый'
    END;

    RETURN category;
END;
$$;
```
Использование функции:
```PostgreSQL
SELECT categorize_student_with_case(1) AS age_category;
```

Результат:

|age_category|
|---|
|Молодой|

Здесь `CASE` проверяет условия по порядку и возвращает результат первого условия, которое оказалось истинным. Если ни одно условие не выполнено, возвращается значение из `ELSE`.

# Цикл WHILE

Цикл `WHILE` позволяет выполнять код повторно, пока выполняется определённое условие.

## Синтаксис `WHILE`

В PostgreSQL цикл имеет следующий вид:
```PostgreSQL
WHILE условие LOOP
    -- код, выполняемый в цикле
END LOOP;
```

Условие проверяется перед каждой итерацией цикла. Если условие становится ложным, выполнение цикла прекращается.

## Пример использования WHILE

Рассмотрим пример хранимой процедуры для создания нескольких тестовых предметов:
```PostgreSQL
CREATE OR REPLACE PROCEDURE create_test_subjects(count_subjects INT)
LANGUAGE plpgsql
AS $$
DECLARE
    i INT := 1;
    subject_id INT := 20;
BEGIN
    WHILE i <= count_subjects LOOP
        INSERT INTO Subject (id, name)
        VALUES (
            subject_id + i,
            'Test Subject ' || i
        );

        i := i + 1;
    END LOOP;

    RAISE NOTICE 'Создано % тестовых предметов', count_subjects;
END;
$$;
```
Создаём 3 тестовых предмета:
```PostgreSQL
CALL create_test_subjects(3);
```
Проверяем результат:
```PostgreSQL
SELECT *
FROM Subject
WHERE name LIKE 'Test Subject%';
```

Результат:

|id|name|
|--:|---|
|21|Test Subject 1|
|22|Test Subject 2|
|23|Test Subject 3|

Здесь:
- `i := 1` — начальное значение счётчика.
- `WHILE i <= count_subjects LOOP` — цикл выполняется, пока `i` меньше или равно количеству создаваемых предметов.
- `subject_id + i` — формирует ID нового предмета.
- `'Test Subject ' || i` — объединяет строку с текущим значением `i`.
- `i := i + 1` — увеличивает счётчик на единицу.
- `END LOOP` — завершает тело цикла.
---
# Главное

Операторы управления потоком позволяют реализовывать условную логику и циклы внутри хранимых процедур и функций.

- `IF` — выполняет разные блоки кода в зависимости от условий.
- `CASE` — возвращает результат в зависимости от выполненного условия.
- `WHILE` — повторяет выполнение кода, пока условие истинно.

Эти конструкции позволяют реализовывать более сложную логику непосредственно внутри хранимых процедур и функций.

# Практика

<u>Задание 1:</u>
Создайте хранимую функцию **`get_user_status`**, которая принимает параметр **`input_user_id`** типа **`INT`** и возвращает статус пользователя: *"**`VIP`**"* если у него больше **`3`** резерваций, *"**`Regular`**"* если от **`1`** до **`3`** резерваций, *"**`New`**"* если резерваций нет. Используйте оператор **`IF`**.
<u>Решение:</u>
```PostgreSQL
CREATE OR REPLACE FUNCTION
    get_user_status(input_user_id INT)
RETURNS VARCHAR(20)
LANGUAGE plpgsql
AS $$
DECLARE
    count_reservations INT;
    status_user VARCHAR(20);
BEGIN
    SELECT COUNT(*)
    INTO count_reservations
    FROM Reservations
    WHERE user_id = input_user_id;
    IF count_reservations > 3 THEN
        status_user := 'VIP';
    ELSIF count_reservations BETWEEN 1 AND 3 THEN
        status_user := 'Regular';
    ELSE
        status_user := 'New';
    END IF;
    RETURN status_user;
END;
$$;
```

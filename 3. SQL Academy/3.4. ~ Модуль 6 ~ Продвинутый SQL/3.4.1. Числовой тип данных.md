# Числовой тип данных в SQL

Числовые данные в **SQL** можно вводить как [[3.1.1. Литералы в SQL|литералы]], получать из столбцов таблиц или вычислять.

Для вычислений используются арифметические операции `+`, `-`, `*`, `/` и скобки для изменения приоритета.

```PostgreSQL
SELECT 2 * ((22 - 16) / (2 + 1)) AS calc_example;
```

Результат:

|calc_example|
|---|
|4|

# Математические функции

Для математических вычислений используются встроенные функции.

|Функция|Описание|
|---|---|
|`POWER(num, power)`|Возведение числа в степень|
|`SQRT(num)`|Квадратный корень числа|
|`LOG(base, num)`|Логарифм числа по указанному основанию|
|`EXP(num)`|Вычисляет `e^num`|
|`SIN(num)`|Синус числа|
|`COS(num)`|Косинус числа|
|`TAN(num)`|Тангенс числа|

# Округление чисел

Для округления числовых данных используются функции **`CEILING`**, **`FLOOR`**, **`ROUND`** и **`TRUNC`**.

Функции **`CEILING`** и **`FLOOR`** округляют число до ближайшего целого в большую и меньшую сторону соответственно.

```PostgreSQL
SELECT CEILING(69.69) AS ceiling,
       FLOOR(69.69) AS floor;
```

Результат:

|ceiling|floor|
|--:|--:|
|70|69|

Для `CEILING` также используется сокращённая форма **`CEIL`**:

```PostgreSQL
SELECT CEIL(69.69) AS ceiling,
       FLOOR(69.69) AS floor;
```

---

# Функция **`ROUND`**

Функция **`ROUND`** округляет число до ближайшего значения.

```PostgreSQL
SELECT ROUND(69.499),
       ROUND(69.5),
       ROUND(69.501);
```

Результат:

|`ROUND(69.499)`|`ROUND(69.5)`|`ROUND(69.501)`|
|--:|--:|--:|
|69|70|70|

Второй аргумент `ROUND` задаёт количество знаков после запятой:

```PostgreSQL
SELECT ROUND(69.7171, 1),
       ROUND(69.7171, 2),
       ROUND(69.7171, 3);
```

Результат:

|`ROUND(69.7171, 1)`|`ROUND(69.7171, 2)`|`ROUND(69.7171, 3)`|
|--:|--:|--:|
|69.7|69.72|69.717|

Второй аргумент может быть отрицательным. В этом случае округление выполняется слева от десятичной точки:

```PostgreSQL
SELECT ROUND(1691.7, -1),
       ROUND(1691.7, -2),
       ROUND(1691.7, -3);
```

Результат:

|`ROUND(1691.7, -1)`|`ROUND(1691.7, -2)`|`ROUND(1691.7, -3)`|
|--:|--:|--:|
|1690|1700|2000|

# Функция **`TRUNC`**

Функция **`TRUNC`** отбрасывает ненужные цифры без округления.

```PostgreSQL
SELECT TRUNC(69.7979, 1),
       TRUNC(69.7979, 2),
       TRUNC(69.7979, 3);
```

Результат:

|`TRUNC(69.7979, 1)`|`TRUNC(69.7979, 2)`|`TRUNC(69.7979, 3)`|
|--:|--:|--:|
|69.7|69.79|69.797|

Второй аргумент может быть отрицательным:

```PostgreSQL
SELECT TRUNC(69.7979, -1);
```

> ⚠️ **Важно:** в PostgreSQL для числовых значений используется `TRUNC`. Функция `TRUNCATE` относится к другой конструкции SQL и не используется для усечения числовых значений.

# Работа со знаковыми числами

Для работы с отрицательными и положительными числами используются функции **`SIGN`** и **`ABS`**.

## Функция **`SIGN`**

Функция `SIGN` возвращает:

- `-1`, если число отрицательное;
    
- `0`, если число равно нулю;
    
- `1`, если число положительное.
    

```PostgreSQL
SELECT SIGN(-69),
       SIGN(0),
       SIGN(69);
```

Результат:

|`SIGN(-69)`|`SIGN(0)`|`SIGN(69)`|
|--:|--:|--:|
|-1|0|1|

## Функция **`ABS`**

Функция `ABS` возвращает **абсолютное значение числа**.

```PostgreSQL
SELECT ABS(-69),
       ABS(0),
       ABS(69);
```

Результат:

|`ABS(-69)`|`ABS(0)`|`ABS(69)`|
|--:|--:|--:|
|69|0|69|

# Практика

<u>Задание 1:</u>  
Выведите список цен всего доступного жилья из таблицы **`Rooms`**, округлённых до ближайшего числа, кратного 10. Например, если цена равна `9676`, после округления она должна быть равна `9680`.
Для вывода цены используйте псевдоним **`rounded_price`**.
<u>Решение:</u>
```PostgreSQL
SELECT ROUND(price, -1) AS rounded_price
FROM Rooms;
```

# Числовой тип данных в SQL

Создание числовых данных в **SQL** достаточно простое: можно ввести число как [[3.1.1. Литералы в SQL|литерал]], получить его из столбца таблицы или сгенерировать путём вычислений.

При вычислениях можно использовать стандартные арифметические операции:
`+`, `-`, `*`, `/` и другие, а также изменять приоритет вычислений с помощью скобок.

```MySQL
SELECT 2 * ((22 - 16) / (2 + 1)) AS calc_example;
```

Результат:

| calc_example |
| ------------ |
| 4            |

---
# Математические функции

Для большинства математических вычислений, таких как возведение числа в степень или получение квадратного корня, в SQL есть встроенные числовые функции.

|Функция|Описание|
|---|---|
|`POW(num, power)`|Вычисляет число в указанной степени|
|`SQRT(num)`|Вычисляет квадратный корень числа|
|`LOG(base, num)`|Вычисляет логарифм числа по указанному основанию|
|`EXP(num)`|Вычисляет `e^num`|
|`SIN(num)`|Вычисляет синус числа|
|`COS(num)`|Вычисляет косинус числа|
|`TAN(num)`|Вычисляет тангенс числа|

Список всех числовых функций, их описание и примеры можно посмотреть в справочнике SQL Academy.

# Округление чисел

При работе с числами с плавающей точкой не всегда требуется сохранять или отображать числа с полной точностью. Например, денежные транзакции можно хранить с точностью до 6 знаков после запятой, а отображать до 2 — с точностью до копеек.

Для округления числовых данных в SQL предусмотрены функции:
**`CEILING`**, **`FLOOR`**, **`ROUND`** и **`TRUNCATE`**.

Функции **`CEILING`** и **`FLOOR`** округляют число до ближайшего целого в большую и меньшую сторону соответственно.
```MySQL
SELECT CEILING(69.69) AS ceiling,
       FLOOR(69.69) AS floor;
```

Результат:

|ceiling|floor|
|---|---|
|70|69|

В некоторых реализациях SQL используются сокращённые названия функций:

- `CEIL` вместо `CEILING`;
- `TRUNC` вместо `TRUNCATE`.

```MySQL
SELECT CEIL(69.69) AS ceiling,
       FLOOR(69.69) AS floor;
```

---
# Функция **`ROUND`**

Для округления к ближайшему целому используется функция **`ROUND`**.

Если дробная часть числа больше или равна `0.5`, число округляется в большую сторону. В противном случае — в меньшую.

```MySQL
SELECT ROUND(69.499),
       ROUND(69.5),
       ROUND(69.501);
```

Результат:

|`ROUND(69.499)`|`ROUND(69.5)`|`ROUND(69.501)`|
|---|---|---|
|69|70|70|

Функция `ROUND` также позволяет округлять число до определённого количества знаков после запятой. Для этого используется второй необязательный аргумент.

```MySQL
SELECT ROUND(69.7171, 1),
       ROUND(69.7171, 2),
       ROUND(69.7171, 3);
```

Результат:

|`ROUND(69.7171, 1)`|`ROUND(69.7171, 2)`|`ROUND(69.7171, 3)`|
|---|---|---|
|69.7|69.72|69.717|

Второй аргумент `ROUND` может принимать отрицательные значения. В этом случае цифры слева от десятичной точки становятся равными нулю на указанное количество разрядов, а дробная часть отбрасывается.

```MySQL
SELECT ROUND(1691.7, -1),
       ROUND(1691.7, -2),
       ROUND(1691.7, -3);
```

Результат:

|`ROUND(1691.7, -1)`|`ROUND(1691.7, -2)`|`ROUND(1691.7, -3)`|
|---|---|---|
|1690|1700|2000|

---
# Функция **`TRUNCATE`**

Функция **`TRUNCATE`** аналогична функции `ROUND`: она также может принимать второй необязательный параметр, но вместо округления просто отбрасывает ненужные цифры.

```MySQL
SELECT TRUNCATE(69.7979, 1),
       TRUNCATE(69.7979, 2),
       TRUNCATE(69.7979, 3);
```

Результат:

|`TRUNCATE(69.7979, 1)`|`TRUNCATE(69.7979, 2)`|`TRUNCATE(69.7979, 3)`|
|---|---|---|
|69.7|69.79|69.797|

В качестве второго аргумента можно использовать отрицательное значение:

```MySQL
SELECT TRUNCATE(69.7979, -1);
```

---
# Функция **`TRUNC`**

В некоторых реализациях SQL используется функция **`TRUNC`**, аналогичная `TRUNCATE`.

Она также принимает второй необязательный параметр и отбрасывает ненужные цифры вместо округления.

```MySQL
SELECT TRUNC(69.7979, 1),
       TRUNC(69.7979, 2),
       TRUNC(69.7979, 3);
```

Результат:

|`TRUNC(69.7979, 1)`|`TRUNC(69.7979, 2)`|`TRUNC(69.7979, 3)`|
|---|---|---|
|69.7|69.79|69.797|

Также второй аргумент может быть отрицательным:

```MySQL
SELECT TRUNC(69.7979, -1);
```

# Работа со знаковыми числами

При работе с числовыми данными, которые могут содержать отрицательные значения, полезными могут быть функции **`SIGN`** и **`ABS`**. ([SQL Academy](https://sql-academy.org/ru/guide/work-with-number-data-type "Числовой тип данных — Интерактивный курс по SQL"))

## Функция **`SIGN`**

Функция `SIGN` возвращает:

- `-1`, если число отрицательное;
    
- `0`, если число равно нулю;
    
- `1`, если число положительное.
    

```MySQL
SELECT SIGN(-69),
       SIGN(0),
       SIGN(69);
```

Результат:

|`SIGN(-69)`|`SIGN(0)`|`SIGN(69)`|
|---|---|---|
|-1|0|1|

## Функция **`ABS`**

Функция `ABS` возвращает **абсолютное значение числа**.

```MySQL
SELECT ABS(-69),
       ABS(0),
       ABS(69);
```

Результат:

|`ABS(-69)`|`ABS(0)`|`ABS(69)`|
|---|---|---|
|69|0|69|

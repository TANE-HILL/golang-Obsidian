Оператор **` LIMIT `** позволяет **извлечь определённый диапазон записей** из одной или нескольких таблиц.

# Общая структура запроса с **` LIMIT `**

```PostgreSQL 17.5
SELECT поля_выборки
FROM список_таблиц
LIMIT количество_записей_для_вывода [OFFSET количество_пропущенных_записей];
```

**Если не указать ` OFFSET `, то отсчёт будет вестись с начала таблицы.**

---
## Пример использования

Возьмём таблицу **`Company`**:

|id|name|
|---|---|
|1|Don_avia|
|2|Aeroflot|
|3|Dale_avia|
|4|air_France|
|5|British_AW|

Для того чтобы вывести строки с 3 по 5, нужно использовать такой запрос:
```PostgreSQL 17.5
SELECT * FROM Company LIMIT 3 OFFSET 2;
```

В результате запроса вернётся следующая выборка:

|id|name|
|---|---|
|3|Dale_avia|
|4|air_France|
|5|British_AW|

В данном запросе происходит пропуск первых двух строк таблицы (1, 2), после чего выводятся следующие три записи (3, 4, 5).

`LIMIT` часто используется вместе с [[3.1.8. Сортировка, ORDER BY|ORDER BY]], когда необходимо получить определённое количество записей в заданном порядке. Например, `ORDER BY` позволяет сначала отсортировать выборку, а `LIMIT` — ограничить количество выводимых строк.

# Практика

<u>Задание 1:</u>
Отсортируйте список компаний *(таблица **`Company`**)* по их названию в алфавитном порядке и выведите первые **две** записи.
<u>Решение:</u>
```PostgreSQL 17.5
SELECT * FROM Company
ORDER BY name
LIMIT 2 OFFSET 0
```

<u>Задание 2:</u>
Выведите начало *(поле **`start_pair`**)* и окончание *(поле **`end_pair`**)* второго и третьего занятия из таблицы **`Timepair`**.
<u>Решение:</u>
```PostgreSQL 17.5
SELECT start_pair, end_pair FROM Timepair
LIMIT 2 OFFSET 1
```

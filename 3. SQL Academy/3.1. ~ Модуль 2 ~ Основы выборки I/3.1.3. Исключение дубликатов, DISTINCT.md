В некоторых ситуациях [[3.1.0. Базовый синтаксис SQL запроса|SQL запрос]] на выборку **может возвращать повторяющиеся строки данных**.

**Например**, давайте выведем поле `class` из таблицы `Student_in_class` из [[3.0.0. Что такое БД и СУБД|базы данных]], в которой организовано хранение информации о расписании занятий в школе.
```PostgreSQL 17.5
SELECT class FROM Student_in_class;
```
*Пример результата:*
~ class ~
- 9
- 9
- 9
- 9
- 8
- 8
- 7
- 7
- 7
- 6
- 6
- и т.д...

При выводе мы можем наблюдать **одинаковые значения**.
Чтобы при выборке избежать такого дублирования, есть оператор `DISTINCT`.

# Синтаксис `DISTINCT`

```PostgreSQL 17.5
SELECT [DISTINCT] поля_таблиц FROM наименование_таблицы;
```
- Квадратные скобки в описании синтаксиса обозначают **необязательную часть запроса**. В самом SQL-запросе их писать **не нужно**.

То есть в случае с таблицей `Student_in_class`, запрос на получение уникальных классов будет выглядеть следующим образом:
```PostgreSQL 17.5
SELECT DISTINCT class FROM Student_in_class;
```
*Пример вывода:*
~ class ~
- 9
- 8
- 7
- 6
- 5
- 4
- и т.д...

**Без повторов.**

---
# DISTINCT для нескольких колонок

При использовании оператора `DISTINCT` для **двух и более** колонок будут удаляться записи, <u>которые имеют одинаковые значения по всем полям</u>.

То есть, для таблицы:

| **first_name** | **last_name** |
| -------------- | ------------- |
| Stan           | Scott         |
| Travis         | Scott         |
| Stan           | Smith         |
| Travis         | Scott         |

запрос с оператором `DISTINCT` вернул бы все сочетания имён и фамилий, **кроме дублирующихся «Travis Scott»**.

# Практика

<u>Задание 1:</u>
Выведите только уникальные имена `first_name` студентов из таблицы `Student`.
<u>Решение:</u>
```PostgreSQL 17.5
SELECT DISTINCT first_name FROM Student;
```

<u>Задание 2:</u>
Выведите только уникальные пары значений идентификатор учителя `teacher` и идентификатор предмета `subject` из таблицы `Schedule`. Пара 2, 3 отличается от 3, 2.
<u>Решение:</u>
```PostgreSQL 17.5
SELECT DISTINCT teacher, subject FROM Schedule;
```

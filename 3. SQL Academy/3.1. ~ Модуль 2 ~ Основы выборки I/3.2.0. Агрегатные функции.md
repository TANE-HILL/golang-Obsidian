В статье о [[3.1.9. Группировка, GROUP BY|группировках]] мы обсудили, что при использовании оператора **` GROUP BY `** мы можем использовать агрегатные функции. Поговорим о них подробнее.

<u>Агрегатная функция</u> – это функция, которая **выполняет вычисление на наборе значений и возвращает одиночное значение.**

# Общая структура с агрегатной функцией

```PostgreSQL 17.5
SELECT [литералы, агрегатные_функции, поля_группировки]
FROM имя_таблицы
GROUP BY поля_группировки;
```

*Например, запрос с использованием агрегатной функции **` AVG `** может выглядеть так:*
```PostgreSQL 17.5
SELECT home_type, AVG(price) as avg_price FROM Rooms
GROUP BY home_type
```

## Описание агрегатных функций

| <u>Функция</u>              | <u>Описание</u>                  |
| --------------------------- | -------------------------------- |
| **` SUM `**(поле_таблицы)   | *Возвращает сумму значений*        |
| **` AVG `**(поле_таблицы)   | *Возвращает среднее значение*      |
| **` COUNT `**(поле_таблицы) | *Возвращает количество записей*    |
| **` MIN `**(поле_таблицы)   | *Возвращает минимальное значение*  |
| **` MAX `**(поле_таблицы)   | *Возвращает максимальное значение* |

---

**Агрегатные функции применяются для значений,
не равных ` NULL `.
Исключением является функция ` COUNT(*) `.**

---
# Примеры

1. Найдём количество каждого вида жилья и отсортируем полученный список по убыванию:
```PostgreSQL 17.5
SELECT home_type, COUNT(*) as amount FROM Rooms
GROUP BY home_type
ORDER BY amount DESC
```

2. Для каждого жилого помещения найдём самую позднюю дату выезда *(поле **` end_date `**)*:
```PostgreSQL 17.5
SELECT room_id, MAX(end_date) AS last_end_date FROM Reservations
GROUP BY room_id
```

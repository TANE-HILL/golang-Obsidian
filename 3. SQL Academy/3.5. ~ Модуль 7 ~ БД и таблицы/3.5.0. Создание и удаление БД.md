# Создание и удаление баз данных

При написании [[3.1.0. Базовый синтаксис SQL запроса|SQL-запросов]] мы активно используем таблицы. Сами таблицы хранятся в рамках конкретных [[3.0.0. Что такое БД и СУБД|баз данных]]. В этой статье рассмотрим создание, просмотр и удаление баз данных в PostgreSQL.

---
# Создание базы данных

Для создания базы данных используется оператор `CREATE DATABASE`:
```PostgreSQL
CREATE DATABASE имя_базы_данных;
```
- В PostgreSQL имя базы данных без двойных кавычек должно начинаться с буквы или символа `_`. Далее можно использовать буквы, цифры, символ `_` и символ `$`.

Максимальная длина имени — **63 байта**.

---
# Просмотр существующих баз данных

В PostgreSQL для просмотра баз данных можно обратиться к системному каталогу `pg_database`:
```PostgreSQL
SELECT datname
FROM pg_database
WHERE datistemplate = false;
```

Пример результата:

|datname|
|---|
|user_database_1|
|user_database_2|
|postgres|

Кроме пользовательских баз данных, PostgreSQL содержит служебные базы данных, например `postgres`, `template0` и `template1`.

---
# Удаление базы данных

Для удаления базы данных используется оператор `DROP DATABASE`:
```PostgreSQL
DROP DATABASE имя_базы_данных;
```

> ⚠️ **Важно:** нельзя удалить базу данных, к которой подключена текущая сессия. Удаление также не выполняется, если к базе подключены другие активные сессии.

---
# IF EXISTS

При удалении базы данных может возникнуть ошибка, если базы данных с указанным именем не существует.

Чтобы избежать такой ошибки, используется `IF EXISTS`:

```PostgreSQL
DROP DATABASE IF EXISTS имя_базы_данных;
```

Если база данных существует, она будет удалена. Если базы данных нет, PostgreSQL не выдаст ошибку.

---
# IF NOT EXISTS

В некоторых СУБД существует конструкция `CREATE DATABASE IF NOT EXISTS`, которая позволяет создать базу только в том случае, если она ещё не существует.

В PostgreSQL такой синтаксис для `CREATE DATABASE` не поддерживается.

Поэтому перед созданием базы данных можно проверить её существование:
```PostgreSQL
SELECT EXISTS (
    SELECT 1
    FROM pg_database
    WHERE datname = 'my_database'
);
```
После проверки можно выполнить:
```PostgreSQL
CREATE DATABASE my_database;
```
> ⚠️ **Важно:** проверка через `SELECT` и последующий `CREATE DATABASE` не является атомарной операцией. В многопользовательской среде между этими командами база может быть создана другой сессией.

---
# Главное
- `CREATE DATABASE` — создание базы данных.
- `SELECT ... FROM pg_database` — просмотр существующих баз данных.
- `DROP DATABASE` — удаление базы данных.
- `DROP DATABASE IF EXISTS` — удаление базы данных, если она существует.
- В PostgreSQL `CREATE DATABASE IF NOT EXISTS` не поддерживается.
- Имя базы данных без двойных кавычек должно начинаться с буквы или `_`.
- Максимальная длина имени базы данных — **63 байта**.

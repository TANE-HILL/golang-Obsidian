# Дата и время

Для работы с датой и временем в PostgreSQL используются следующие основные [[3.5.2. Типы данных для колонок таблиц|типы данных]]:

|Тип|Описание|Размер|
|---|---|--:|
|`DATE`|Хранит дату в формате `YYYY-MM-DD`|4 байта|
|`TIME`|Хранит время в формате `HH:MM:SS`|8 байт|
|`TIMESTAMP`|Хранит дату и время без часового пояса|8 байт|
|`TIMESTAMPTZ`|Хранит дату и время с часовым поясом|8 байт|
|`INTERVAL`|Хранит интервал времени|16 байт|

---
# **` DATE `**

`DATE` используется для хранения даты без времени.

```PostgreSQL
CREATE TABLE date_table (
    date_field DATE
);

INSERT INTO date_table VALUES ('2022-06-16');

SELECT * FROM date_table;
```

Формат даты:
```text
YYYY-MM-DD
```

Диапазон значений `DATE` в PostgreSQL: от `4713 BC` до `5874897 AD`.

---
# **` TIME `**

`TIME` используется для хранения времени без даты.

```PostgreSQL
CREATE TABLE time_table (
    time_field TIME
);

INSERT INTO time_table VALUES ('16:37:23');

SELECT * FROM time_table;
```

Формат времени:
```text
HH:MM:SS
```

Диапазон значений `TIME`: от `00:00:00` до `24:00:00`.

---
# **` TIMESTAMP `**

`TIMESTAMP` хранит дату и время **без информации о часовом поясе**.

```PostgreSQL
CREATE TABLE timestamp_table (
    timestamp_field TIMESTAMP
);

INSERT INTO timestamp_table
VALUES ('2022-06-16 16:37:23');

SELECT * FROM timestamp_table;
```

При изменении часового пояса значение `TIMESTAMP` не преобразуется, поскольку PostgreSQL не хранит информацию о часовом поясе вместе со значением.

---
# **` TIMESTAMPTZ `**

`TIMESTAMPTZ` — сокращённая форма `TIMESTAMP WITH TIME ZONE`. Тип используется для хранения даты и времени с учётом часового пояса.

```PostgreSQL
CREATE TABLE timestamptz_table (
    timestamptz_field TIMESTAMPTZ
);

SET timezone = 'UTC';

INSERT INTO timestamptz_table
VALUES ('2022-06-16 16:37:23');

SET timezone = 'Europe/Moscow';

SELECT * FROM timestamptz_table;
```

PostgreSQL хранит значение `TIMESTAMPTZ` в UTC и преобразует его в часовой пояс текущей сессии при выводе.

*Например, значение:*
```text
2022-06-16 16:37:23+00
```
*при часовом поясе `Europe/Moscow` будет отображено как:*
```text
2022-06-16 19:37:23+03
```

---
# **` TIMESTAMP `** и **` TIMESTAMPTZ `**

Основное различие:

|Тип|Часовой пояс|Преобразование|
|---|---|---|
|`TIMESTAMP`|Не учитывается|Нет|
|`TIMESTAMPTZ`|Учитывается|Да|

`TIMESTAMP` подходит для значений, которые не привязаны к конкретному часовому поясу.

`TIMESTAMPTZ` удобно использовать для событий, которые происходят в определённый момент времени: создание записи, оплата, отправка сообщения и т. д.

---
# **` INTERVAL `**

`INTERVAL` используется для хранения промежутков времени. Он может представлять годы, месяцы, дни, часы, минуты и секунды.

```PostgreSQL
SELECT INTERVAL '1 year 2 months 3 days 4 hours';
SELECT INTERVAL '2 weeks';
SELECT INTERVAL '90 minutes';
```

*Например:*
```text
1 year 2 mons 3 days 04:00:00
```

`INTERVAL` также можно использовать при выполнении операций с датами и временем:
```PostgreSQL
SELECT DATE '2026-09-21' + INTERVAL '7 days';
```

---
# Форматы даты и времени

PostgreSQL предпочитает стандартные форматы ISO 8601.

Основные варианты:
- дата: `YYYY-MM-DD`;
- время: `HH:MM:SS`;
- дата и время: `YYYY-MM-DD HH:MM:SS`;
- дата, время и часовой пояс: `YYYY-MM-DD HH:MM:SS+TZ`.

Например:
```PostgreSQL
CREATE TABLE date_table (
    date_field DATE,
    time_field TIME,
    timestamp_field TIMESTAMP,
    timestamptz_field TIMESTAMPTZ
);

INSERT INTO date_table VALUES (
    '2022-06-16',
    '16:37:23',
    '2022-06-16 16:37:23',
    '2022-06-16 16:37:23+03'
);

SELECT * FROM date_table;
```

PostgreSQL следует стандарту ISO 8601 и рекомендует использовать стандартные форматы даты и времени.

---
# Кратко

- `DATE` — только дата;
- `TIME` — только время;
- `TIMESTAMP` — дата и время без часового пояса;
- `TIMESTAMPTZ` — дата и время с учётом часового пояса;
- `INTERVAL` — промежуток времени.

# Практика

<u>Задание 1:</u>
Создайте таблицу **`Exams`** со следующими полями:
- **`id`** — поле типа **`INTEGER`**, являющееся первичным ключом;
- **`subject`** — обязательное поле типа **`VARCHAR(50)`** для названия предмета;
- **`exam_date`** — обязательное поле типа **`DATE`** для дня экзамена;
- **`start_time`** — обязательное поле типа **`TIME`** для времени начала;
- **`created_at`** — поле типа **`TIMESTAMP`** со значением по умолчанию, равным текущим дате и времени.
<u>Решение:</u>
```PostgreSQL
CREATE TABLE Exams (
    id INTEGER PRIMARY KEY,
    subject VARCHAR(50) NOT NULL,
    exam_date DATE NOT NULL,
    start_time TIME NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
)
```

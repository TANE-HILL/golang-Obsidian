# Числовой тип данных

Числовые данные разделяются на точные и приближенные, целые и вещественные. В PostgreSQL также используются специальные типы для автоинкрементных столбцов.

---
# Целые числа

Для хранения целых чисел в PostgreSQL используются следующие типы:

|Тип|Объем памяти|Диапазон|
|---|--:|--:|
|`SMALLINT`|2 байта|от -32 768 до 32 767|
|`INTEGER`|4 байта|от -2 147 483 648 до 2 147 483 647|
|`BIGINT`|8 байт|от -9 223 372 036 854 775 808 до 9 223 372 036 854 775 807|

`INTEGER` и `INT` являются синонимами.

Выбор типа зависит от диапазона значений, которые необходимо хранить. Например, для идентификаторов, количества товаров и других обычных целых чисел чаще всего достаточно `INTEGER`.

```PostgreSQL
CREATE TABLE Products (
    id INTEGER,
    quantity INTEGER
);
```

---
# Точные вещественные числа

Для хранения чисел с фиксированной точностью используются типы `NUMERIC` и `DECIMAL`. Они являются синонимами.

```PostgreSQL
CREATE TABLE Products (
    price NUMERIC(10, 2)
);
```

`NUMERIC(10, 2)` означает, что число может содержать максимум **`10`** цифр, из которых **`2`** находятся после десятичной точки.

Например:

```text
99999999.99
```

Тип `NUMERIC` используется, когда точность имеет критическое значение, например при хранении финансовых данных.

---
# Приближенные числа

Для хранения чисел с плавающей точкой в PostgreSQL используются:

|Тип|Объем памяти|Точность|
|---|--:|--:|
|`REAL`|4 байта|примерно 6 десятичных знаков|
|`DOUBLE PRECISION`|8 байт|примерно 15 десятичных знаков|

```PostgreSQL
CREATE TABLE Measurements (
    temperature REAL,
    distance DOUBLE PRECISION
);
```

Типы с плавающей точкой используются для приближенных вычислений. PostgreSQL также поддерживает специальные значения `Infinity`, `-Infinity` и `NaN`.

---
# Автоинкрементные типы

PostgreSQL предоставляет псевдотипы `SMALLSERIAL`, `SERIAL` и `BIGSERIAL` для создания автоинкрементных столбцов.

|Тип|Размер|Диапазон|
|---|--:|--:|
|`SMALLSERIAL`|2 байта|от 1 до 32 767|
|`SERIAL`|4 байта|от 1 до 2 147 483 647|
|`BIGSERIAL`|8 байт|от 1 до 9 223 372 036 854 775 807|

*Например:*
```PostgreSQL
CREATE TABLE Users (
    id SERIAL PRIMARY KEY,
    name VARCHAR(100)
);
```

`SERIAL` эквивалентен целочисленному столбцу с автоматически создаваемой последовательностью.

---
# **` BIT `**

Тип `BIT` используется для хранения последовательности битов заданной длины.

```PostgreSQL
CREATE TABLE Flags (
    value BIT(8)
);
```
- В `BIT(n)` значение `n` определяет количество битов.

---
# Основные числовые типы PostgreSQL

На практике чаще всего используются:
- `SMALLINT` — небольшие целые числа;
- `INTEGER` — обычные целые числа;
- `BIGINT` — большие целые числа;
- `NUMERIC` / `DECIMAL` — точные числа, например деньги;
- `REAL` — числа с плавающей точкой меньшей точности;
- `DOUBLE PRECISION` — числа с плавающей точкой большей точности;
- `SERIAL` / `BIGSERIAL` — автоинкрементные целые числа.

# Практика

<u>Задание 1:</u>
Создайте таблицу **`ExamResults`** со следующими полями:
- **`id`** — поле типа **`INTEGER`**, являющееся первичным ключом;
- **`student_id`** — обязательное поле типа **`INTEGER`**;
- **`score`** — обязательное поле типа **`SMALLINT`** для набранных баллов;
- **`completion`** — поле типа **`DECIMAL(5,2)`** для процента выполнения работы.
<u>Решение:</u>
```PostgreSQL
CREATE TABLE ExamResults (
    id INTEGER PRIMARY KEY,
    student_id INTEGER NOT NULL,
    score SMALLINT NOT NULL,
    completion DECIMAL(5,2)
)
```

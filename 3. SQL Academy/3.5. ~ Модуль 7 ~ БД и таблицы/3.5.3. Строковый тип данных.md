# Строковый тип данных

Строковый тип данных является наиболее используемым [[3.5.2. Типы данных для колонок таблиц|типом данных]]. Благодаря ему в базе данных хранятся текстовые данные.

В PostgreSQL для работы со строковыми данными используются следующие основные типы:

# **`CHARACTER`** и **`VARCHAR`**

|Тип|Описание|Диапазон|
|---|---|---|
|`CHAR(n)`|Содержит текстовые строки фиксированной длины. Если строка короче указанной длины, она дополняется пробелами.|От 1 до 10 485 760 символов|
|`VARCHAR(n)`|Содержит текстовые строки переменной длины с ограничением максимальной длины.|От 1 до 10 485 760 символов|
|`TEXT`|Содержит текстовые строки переменной длины без явного ограничения.|Практически неограниченная длина, до 1 ГБ|

## `CHAR(n)`

`CHAR(n)` используется для хранения строк фиксированной длины. Если фактическая строка короче указанной длины, PostgreSQL дополняет её пробелами.
```PostgreSQL
CREATE TABLE users (
    code CHAR(5)
);
```

*Например, значение `'AB'` будет храниться как строка длиной 5 символов с добавленными пробелами.*

## `VARCHAR(n)`

`VARCHAR(n)` используется для хранения строк переменной длины с ограничением максимальной длины.

```PostgreSQL
CREATE TABLE users (
    name VARCHAR(100)
);
```

В данном случае в столбце `name` можно хранить строки длиной до 100 символов.

## `TEXT`

`TEXT` используется для хранения строк переменной длины без необходимости задавать максимальное количество символов.

```PostgreSQL
CREATE TABLE articles (
    title VARCHAR(200),
    content TEXT
);
```

В PostgreSQL тип `TEXT` предпочтительнее использовать вместо `VARCHAR` без ограничения длины, поскольку они имеют одинаковую производительность. ([SQL Academy](https://sql-academy.org/ru/guide/string-data-type "Строковый тип данных — Интерактивный курс по SQL"))

---
# **`CHAR`**, **`VARCHAR`** и **`TEXT`**

Основное различие между типами заключается в ограничении длины:
- `CHAR(n)` — фиксированная длина;
- `VARCHAR(n)` — переменная длина с ограничением;
- `TEXT` — переменная длина без явного ограничения.

На практике `VARCHAR(n)` используют, когда необходимо явно ограничить максимальную длину значения, а `TEXT`— когда такое ограничение не требуется.

# Практика

<u>Задание 1:</u>
Создайте таблицу **`Students`** со следующими полями:
- **`id`** — поле типа **`INTEGER`**, являющееся первичным ключом;
- **`first_name`** — обязательное поле типа **`VARCHAR(50)`** для имени;
- **`last_name`** — обязательное поле типа **`VARCHAR(50)`** для фамилии;
- **`class_code`** — обязательное поле типа **`CHAR(3)`** для кода класса фиксированной длины;
- **`biography`** — поле типа **`TEXT`** для рассказа ученика о себе.
<u>Решение:</u>
```PostgreSQL
CREATE TABLE Students (
    id INTEGER PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    class_code CHAR(3) NOT NULL,
    biography TEXT
)
```

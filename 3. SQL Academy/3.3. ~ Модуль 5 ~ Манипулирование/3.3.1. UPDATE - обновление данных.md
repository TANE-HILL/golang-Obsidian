# Обновление данных, оператор **` UPDATE `**

Для редактирования существующих записей в таблицах существует SQL оператор **`UPDATE`**.

---
# Общая структура запроса с оператором **` UPDATE `**

```PostgreSQL
UPDATE имя_таблицы
SET поле_таблицы_1 = значение_поля_таблицы_1,
    поле_таблицы_N = значение_поля_таблицы_N
[WHERE условие_выборки];
```
- Оператор **`UPDATE`** изменяет значения указанных полей в существующих записях таблицы.

*Например, если необходимо изменить имя члена семьи:*
```PostgreSQL
UPDATE FamilyMembers
SET member_name = 'Andie Anthony'
WHERE member_name = 'Andie Quincey';
```
В данном случае значение `member_name` изменится только у записи, удовлетворяющей условию:
```sql
WHERE member_name = 'Andie Quincey'
```
> ⚠️ **Важно:** если не указать [[3.1.4. Условный оператор WHERE|оператор WHERE]], будут обновлены **все записи** в таблице.

---
# Изменение нескольких полей

С помощью **`SET`** можно одновременно изменить значения нескольких полей. Для этого значения перечисляются через запятую:
```PostgreSQL
UPDATE FamilyMembers
SET member_name = 'Andie Anthony',
    status = 'daughter'
WHERE member_id = 3;
```
- В результате у записи с `member_id = 3` будут изменены сразу два поля.

---
# Вычисляемые значения

При обновлении данных можно использовать **предыдущее значение самого поля** для вычисления нового значения.

*Например, чтобы увеличить цену товара в два раза:*
```PostgreSQL
UPDATE Payments
SET unit_price = unit_price * 2;
```
- Здесь новое значение `unit_price` рассчитывается на основе его предыдущего значения.

Если до выполнения запроса:
```text
unit_price = 500
```
то после выполнения:
```text
unit_price = 1000
```

---
# Присваивание значений между столбцами

Значение одного столбца можно присвоить другому столбцу:
```PostgreSQL
UPDATE Payments
SET total_price = unit_price;
```

При этом типы данных столбцов должны быть совместимыми.

---
# Практика

<u>Задание 1:</u>
Измените имя у *"Wednesday Addams"* на новое *"Tuesday Addams"*.
<u>Решение:</u>
```PostgreSQL 17.5
UPDATE FamilyMembers
SET member_name = 'Tuesday Addams'
WHERE member_name = 'Wednesday Addams'
```

<u>Задание 2:</u>
Обновите стоимость всех комнат в таблице **`Rooms`**, добавив к текущей 10 единиц.
<u>Решение:</u>
```PostgreSQL 17.5
UPDATE Rooms SET price = price + 10
```

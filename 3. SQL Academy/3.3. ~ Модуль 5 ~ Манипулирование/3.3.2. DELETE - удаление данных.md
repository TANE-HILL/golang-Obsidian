# Удаление данных, оператор **`DELETE`**

Время от времени возникает задача удаления записей из таблицы. Для этого в SQL предусмотрены операторы **`DELETE`** и **`TRUNCATE`**, из которых наиболее универсальным является первый вариант.

---
# Общая структура запроса с оператором **`DELETE`**

```PostgreSQL
DELETE FROM имя_таблицы
[WHERE условие_отбора_записей];
```

Если условие отбора записей [[3.1.4. Условный оператор WHERE|WHERE]] отсутствует, будут удалены **все записи**указанной таблицы.

Например, удалить конкретного члена семьи:
```PostgreSQL
DELETE FROM FamilyMembers
WHERE member_id = 3;
```

В результате будет удалена запись, у которой `member_id` равен `3`.

> ⚠️ **Важно:** перед выполнением `DELETE` необходимо внимательно проверять условие `WHERE`. Если его не указать, будут удалены все записи таблицы.

---
# Оператор **`TRUNCATE`**

Если необходимо удалить **все записи** из таблицы, можно использовать оператор **`TRUNCATE`**:
```PostgreSQL
TRUNCATE TABLE имя_таблицы;
```

`TRUNCATE` удаляет все строки таблицы значительно быстрее, чем последовательное удаление каждой строки с помощью `DELETE`, особенно при работе с большими таблицами.

У оператора **`TRUNCATE`** есть ряд отличий от `DELETE`:
- не срабатывают триггеры удаления;
- строки не удаляются по одной;
- в PostgreSQL можно использовать `RESTART IDENTITY` для сброса счётчиков идентификаторов;
- для выполнения операции необходимы права на изменение таблицы.

Например:
```PostgreSQL
TRUNCATE TABLE Goods;
```

# Удаление записей при многотабличных запросах

При удалении записей с использованием нескольких таблиц можно использовать **`JOIN`**.

Например, удалить все бронирования комнат, в которых отсутствует кухня:
```PostgreSQL
DELETE Reservations FROM
Reservations
JOIN Rooms ON Reservations.room_id = Rooms.id
WHERE Rooms.has_kitchen = false;
```

В этом случае `JOIN` используется для определения записей, которые необходимо удалить, а `WHERE` задаёт условие отбора.

В PostgreSQL для удаления записей из нескольких таблиц одновременно используются отдельные запросы **`DELETE`** или транзакции.

```PostgreSQL
BEGIN;

DELETE FROM Reservations
USING Rooms
WHERE Reservations.room_id = Rooms.id
AND Rooms.has_kitchen = false;

DELETE FROM Rooms
WHERE Rooms.has_kitchen = false;

COMMIT;
```

# Практика

<u>Задание 1:</u>
Удалите все записи из таблицы **`Payments`**, используя оператор **`DELETE`**.
<u>Решение:</u>
```PostgreSQL 17.5
DELETE FROM Payments
```

<u>Задание 2:</u>
Удалить запись из таблицы **`Goods`**, у которой поле **`good_name`** равно *"milk"*
<u>Решение:</u>
```PostgreSQL 17.5
DELETE FROM Goods WHERE good_name = 'milk'
```

<u>Задание 3:</u>
Измените запрос так, чтобы удалить товары *(**`Goods`**)*, 
имеющие тип деликатесов *(**`delicacies`**)*.
<u>Запрос из условия:</u>
```PostgreSQL 17.5
SELECT * FROM Goods JOIN GoodTypes ON Goods.type = GoodTypes.good_type_id WHERE GoodTypes.good_type_name = 'delicacies'
```
<u>Решение:</u>
```PostgreSQL 17.5
DELETE FROM Goods
USING GoodTypes
WHERE Goods.type = GoodTypes.good_type_id
    AND GoodTypes.good_type_name = 'delicacies'
```

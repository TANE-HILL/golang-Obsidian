# Вводная информация о SQL

<u>SQL</u> — язык структурированных запросов *(SQL, Structured Query Language)*, который используется в качестве эффективного способа сохранения данных, поиска их частей, обновления, извлечения и удаления из базы данных.

**С [[3.0.1. Реляционные базы данных|реляционными СУБД]] общаются именно на SQL**.
## **Основные операции с [[3.0.0. Что такое БД и СУБД|базами данных]]**
#### <u>Данные</u>:
`SELECT` - *Извлекать данные из базы данных;*
`INSERT` - *Вставлять записи в базу данных;*
`UPDATE` - *Обновлять записи в базе данных;*
`DELETE` - *Удалять записи из базы данных.*
#### <u>Структура</u>:
`CREATE DATABASE` - *Создавать новые базы данных;*
`CREATE TABLE` - *Создавать новые таблицы в базе данных.*
#### <u>Логика и доступ</u>:
`CREATE PROCEDURE` - *Создавать хранимые процедуры;*
`CREATE VIEW` - *Создавать представления;*
`GRANT` - *Выдавать разрешения для таблиц, процедур и представлений.*

## Диалекты SQL *(Расширения SQL)*

**Язык SQL** – универсальный язык для всех реляционных СУБД, но **многие из них вносят свои изменения в язык**, применяемый в них, тем самым отступая от стандарта. Такие языки называют <u>диалектами</u> или <u>расширениями</u> языка.

Для примера посмотрим, как в каждой из этих СУБД выбираются первые 3 строки.

`T-SQL`:
```Microsoft SQL Server
SELECT TOP 3 name
```

`PL/SQL`:
```Oracle
WHERE ROWNUM <= 3
```

`MySQL`:
```MySQL
name LIMIT 3
```

`PL/pgSQL`:
```PostgreSQL
name LIMIT 3
```

#### <u>Какой диалект учить</u>?

Если вы знаете, что вам нужно изучать SQL, вам следует изучить **стандартный SQL**. Однако, если вы уже знаете, с какой конкретной базой данных вы будете работать, вероятно, лучше всего изучить её диалект SQL и просто знать, что разные базы данных могут использовать немного отличающийся синтаксис.

Мы уже познакомились с синтаксисом оператора [[3.1.4. Условный оператор WHERE|WHERE]] и операторами сравнения, но помимо них в условных запросах мы можем использовать следующие полезные операторы:
- **` IS NULL `**
- **` BETWEEN `**
- **` IN `**

---
# **` IS NULL `**

Оператор `IS NULL` позволяет **проверить, отсутствует ли значение в поле.**

Для примера выведем всех преподавателей, у кого отсутствует отчество:
```PostgreSQL 17.5
SELECT * FROM Teacher
WHERE middle_name IS NULL;
```
*Пример вывода:*

| id  | first_name | middle_name | last_name |
| --- | ---------- | ----------- | --------- |
| 1   | YUrij      | < NULL >    | Krylov    |
| 2   | Andrej     | < NULL >    | Evseev    |
| 3   | Yana       | < NULL >    | Makarova  |

**Для использования отрицания**, то есть, <u>если мы хотим найти все записи, где поле не равно NULL</u>, мы должны использовать следующий синтаксис:
```PostgreSQL 17.5
SELECT * FROM Teacher
WHERE middle_name IS NOT NULL;
```

---
# **` BETWEEN `**

Оператор **` BETWEEN min AND max `** позволяет узнать, **расположено ли проверяемое значение столбца в интервале** между **` min `** и **` max `**, включая сами значения **` min `** и **` max `**.
Он идентичен условию:
```PostgreSQL 17.5
... WHERE field >= min AND field <= max
```

*Используется данный оператор следующим образом:*
```PostgreSQL 17.5
SELECT * FROM Payments
WHERE unit_price BETWEEN 100 AND 500;
```

В качестве результата вернутся все записи из таблицы **`Payments`**, где значение поля **`unit_price`** будет от **`100`** до **`500`**.

---
# **` IN `**

Оператор **` IN `** позволяет узнать, входит ли проверяемое значение столбца в список определённых значений.
```PostgreSQL 17.5
SELECT * FROM FamilyMembers
WHERE status IN ('father', 'mother');
```

# Практика

<u>Задание 1:</u>
Выведите имена **`first_name`** и фамилии **`last_name`** студентов из таблицы **`Student`**, у кого отсутствует отчество **`middle_name`**
<u>Решение:</u>
```PostgreSQL 17.5
SELECT first_name, last_name FROM Student WHERE middle_name IS NULL;
```

<u>Задание 2:</u>
Выведите резервации комнат (поля **`room_id`**, **`start_date`**, **`end_date`**) из таблицы **`Reservations`**, у которых итоговая стоимость аренды (поле **`total`**) находится в промежутке от **`500`** до **`1200`** включительно.
<u>Решение:</u>
```PostgreSQL 17.5
SELECT room_id, start_date, end_date FROM Reservations WHERE total BETWEEN 500 AND 1200;
```

<u>Задание 3:</u>
Выведите информацию о студентах из таблицы **`Student`**, у которых год рождения соответствует одному из перечисленных: **`2000`**, **`2002`** и **`2004`**.
<u>Решение:</u>
```PostgreSQL 17.5
SELECT * FROM Student WHERE EXTRACT(YEAR FROM birthday) IN (2000, 2002, 2004);
```

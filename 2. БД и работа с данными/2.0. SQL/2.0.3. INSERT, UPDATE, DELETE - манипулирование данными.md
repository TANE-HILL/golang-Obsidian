# Зачем это нужно

До этого мы учились [[2.0.1. Основы SQL - SELECT, FROM, GROUP BY, ORDER BY|извлекать данные]] из таблиц — получать, фильтровать и связывать информацию.

Но работа с [[2.0.0. Базы данных и их виды|базой]] на этом не заканчивается. В реальном приложении данные нужно ещё и **изменять**:
- пользователь добавляет новую задачу → база должна сохранить её;
- меняет статус → запись обновляется;
- удаляет задачу → запись исчезает.

Эти действия называются **манипуляцией данными**.

|Команда|Что делает|Пример|
|---|---|---|
|`INSERT`|Добавляет новую строку в таблицу|Добавить нового пользователя|
|`UPDATE`|Изменяет существующие данные|Обновить статус задачи|
|`DELETE`|Удаляет строку|Удалить задачу по ID|

Эти три операции — часть набора <u>CRUD</u> *(Create, Read, Update, Delete)* — базовых действий, которые выполняет любое приложение, работающее с базой данных.

---
# Почему это важно

Когда мы перейдём к PostgreSQL в следующем модуле, эти же команды будут выполняться прямо из [[1.1.0. Go Basics|Go-кода]]:
```go
db.Exec("INSERT INTO tasks (title, done) VALUES ($1, $2)", title, false)
```

**Поэтому понимание этих операций — обязательный шаг перед интеграцией с реальной базой данных.**

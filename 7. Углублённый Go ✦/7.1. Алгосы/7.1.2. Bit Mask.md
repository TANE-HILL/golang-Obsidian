# Bit Mask *(битовая маска)*

## Идея

**Bit Mask** — способ хранить **несколько независимых флагов в одном целом числе**.
Каждый флаг занимает отдельный бит:
- `0` — флаг выключен;
- `1` — флаг включён.

Для независимых флагов используют разные степени двойки, чтобы у каждого был свой бит.

Пример на [[1.1.0. Go Basics|Go]]:
```Go
const (
    Read   = 1 // 0001
    Write  = 2 // 0010
    Append = 4 // 0100
    Binary = 8 // 1000
)
```

## Объединение флагов

Оператор `|` *([[7.2.13. Битовые операции|побитовое ИЛИ]])* объединяет флаги:
```
mask := Read | Write | Binary // 1011, значение 11
```

## Проверка флага

Оператор `&` *([[7.2.13. Битовые операции|побитовое И]])* позволяет проверить, установлен ли флаг:
```
if mask&Write != 0 {
    // Флаг Write включён
}
```

`mask & flag != 0` — в маске присутствует хотя бы один бит из `flag`. Для одного флага это проверяет его наличие.

Не сравнивай результат с `1`: значение результата зависит от позиции бита (`1`, `2`, `4`, `8` и т. д.).

## Изменение флагов

```
mask |= Binary   // включить флаг
mask &^= Write   // выключить флаг
mask ^= Append   // переключить флаг: 0 -> 1, 1 -> 0
```

- `|=` — установить нужные биты.
- `&^=` — сбросить нужные биты.
- `^=` — инвертировать нужные биты.

## Когда применять

Битовые маски используют для хранения и передачи наборов опций: прав доступа, режимов работы, настроек, флагов протоколов и состояний.

**Запомнить:** степени двойки задают отдельные флаги; `|` объединяет их; `&` проверяет; `|=` включает; `&^=` выключает; `^=` переключает.

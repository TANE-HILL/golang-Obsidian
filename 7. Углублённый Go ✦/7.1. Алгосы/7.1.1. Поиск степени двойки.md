# Проверка, является ли число степенью двойки

## Идея

У положительной степени двойки в двоичном представлении ровно один бит `1`:
- `1` → `0001`
- `2` → `0010`
- `4` → `0100`
- `8` → `1000`

Если вычесть из степени двойки единицу, этот единственный бит `1` исчезнет, а все биты справа от него станут `1`.

Например:

```
  8 = 1000
  7 = 0111
  & = 0000
```

Поэтому побитовое И числа и числа на единицу меньше даст `0`. *(**`value&(value-1)`**)*.

## Реализация на Go

```
func IsPowerOfTwo(value int) bool {
    return value > 0 && value&(value-1) == 0
}
```
- `value > 0` — исключает ноль и отрицательные числа.
- `value&(value-1) == 0` — проверяет, что у числа установлен ровно один бит.

## Примеры

|Число|Результат|
|---|---|
|`1`|`true`|
|`2`|`true`|
|`8`|`true`|
|`12`|`false`|
|`16`|`true`|
|`18`|`false`|
|`0`|`false`|

**Сложность:** `O(1)` — выполняется постоянное количество операций.

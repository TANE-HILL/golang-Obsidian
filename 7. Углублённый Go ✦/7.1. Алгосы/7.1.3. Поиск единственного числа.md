# Поиск единственного числа через **`^`** *(XOR)*

## Задача

**Дан массив, в котором каждое число встречается два раза, кроме одного. Нужно найти число, которое встречается один раз.**

---
## Идея

Используем [[7.2.13. Битовые операции|побитовое исключающее ИЛИ]] *(`^`, XOR)*.

**Свойства XOR:**
- `a ^ a = 0` — одинаковые числа взаимно уничтожаются.
- `a ^ 0 = a` — XOR с нулём не меняет число.
- Порядок операций не важен: XOR можно группировать и переставлять.

Поэтому, если применить XOR ко всем элементам массива, каждая пара одинаковых чисел даст `0`, а единственное число останется.

---
## Реализация на [[1.1.0. Go Basics|Go]]

```Go
func singleNumber(array []int8) int8 {
    var number int8

    for _, element := range array {
        number ^= element
    }

    return number
}
```

---
## Пример

**Для массива:**
```Go
array := [...]int8{2, 3, 4, 2, 3, 1, 4}
```

**XOR всех элементов:**
```
2 ^ 3 ^ 4 ^ 2 ^ 3 ^ 1 ^ 4
= (2 ^ 2) ^ (3 ^ 3) ^ (4 ^ 4) ^ 1
= 0 ^ 0 ^ 0 ^ 1
= 1
```
- Результат — `1`.

---
## Сложность

- Время: `O(n)` — каждый элемент обрабатывается один раз.
- Дополнительная память: `O(1)` — используется только одна переменная.

**Ограничение:** решение работает, если все числа, кроме одного, встречаются ровно два раза. Если повторения устроены иначе, этот приём может не подойти.
	Алгоритм работает при любом чётном количестве повторений. Но не работает, если каждое число встречается четыре раза, а одно — дважды.

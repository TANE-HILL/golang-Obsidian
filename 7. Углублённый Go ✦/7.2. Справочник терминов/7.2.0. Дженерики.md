# Дженерики *(Generics)*
## Определение

**Дженерики** — механизм [[1.1.0. Go Basics|Go]], позволяющий определять функции и типы с **параметрами типов**. Один обобщённый алгоритм или структура может работать с несколькими типами, если они удовлетворяют заданным ограничениям *(constraints)*.
**Дженерики появились в Go 1.18.**

## Основные термины

| <center><u>Термин</u></center>              | <center><u>Значение</u></center>                                                  |
| ------------------------------------------- | --------------------------------------------------------------------------------- |
| **Параметр типа** *(type parameter)*        | *Имя типа, которое задаётся при использовании обобщённой функции или типа.*         |
| **Аргумент типа** *(type argument)*         | *Конкретный тип, передаваемый вместо параметра типа.*                               |
| **Ограничение** *(constraint)*              | *Требования к типам, которые разрешено использовать в качестве аргументов типа.*    |
| **Обобщённая функция** (*generic function)* | *Функция, объявленная с параметрами типов.*                                         |
| **Обобщённый тип** *(generic type)*         | *Тип, объявленный с параметрами типов.*                                             |
| **Выведение типов** *(type inference)*      | *Определение аргументов типа компилятором по контексту вызова, когда это возможно.* |
| **Множество типов** *(type set)*            | *Набор типов, описываемый ограничением.*                                            |

## Параметры типов

Параметры типов указываются в квадратных скобках после имени [[1.1.5. Функции и передача данных|функции]] или [[1.1.2. Типы данных|типа]].

```
func Identity[T any](v T) T {
    return v
}
```

Здесь `T` — **параметр типа**, а `any` — его **ограничение**.
Функция возвращает значение того же типа, который получила.

Пример вызова:
```
n := Identity[int](10)
s := Identity[string]("hello")
```

В некоторых случаях компилятор может вывести тип автоматически:
```
n := Identity(10) // T выводится как int
```

## Ограничения типов *(constraints)*

Ограничение определяет, какие типы допустимы для параметра и какие операции над значениями этого параметра разрешены.

### **`any`**

`any` — встроенный псевдоним `interface{}`. В качестве ограничения он допускает любой тип.

```
func PrintValue[T any](v T) {
    fmt.Println(v)
}
```

Само по себе `any` не разрешает выполнять над `T` произвольные операции: например, арифметика над значением неизвестного типа `T` недопустима.

### **`comparable`**

`comparable` — встроенное ограничение для типов, значения которых можно сравнивать операторами ` == ` и ` != ` в соответствии с правилами Go.

```
func Contains[T comparable](items []T, target T) bool {
    for _, item := range items {
        if item == target {
            return true
        }
    }
    return false
}
```

### **Ограничения через интерфейсы**

**Интерфейс-ограничение может задавать набор допустимых типов и методы**.
```
type Number interface {
    ~int | ~int64 | ~float64
}

func Sum[T Number](a, b T) T {
    return a + b
}
```

В этом примере `Number` задаёт типы, над значениями которых допустима операция `+`.

- `|` объединяет варианты типов.
- `~T` обозначает множество типов, у которых базовый тип — `T`, включая именованные типы с таким базовым типом.
- Перечисление типов в интерфейсе формирует множество типов, допустимых для параметра.

Интерфейсы с такими ограничениями используются как **constraints**; они не обязательно являются обычными типами, которыми можно объявить переменную для хранения значения.

## Обобщённые типы

Параметры типов можно использовать при объявлении собственных типов.
```
type Pair[A any, B any] struct {
    First  A
    Second B
}

p := Pair[int, string]{
    First:  42,
    Second: "answer",
}
```

`Pair` — обобщённый тип с двумя параметрами. `Pair[int, string]` — его применение с конкретными аргументами типов.

## Дженерики и интерфейсы

- **Интерфейс как тип значения** описывает поведение: значение удовлетворяет интерфейсу, если реализует его методы.
- **Интерфейс как ограничение** задаёт, какие типы разрешены для параметра типа и какие операции над ними доступны.
- **Дженерики** позволяют сохранить конкретный тип в пределах обобщённой функции или типа, не заменяя его заранее единым интерфейсным типом.

Дженерики и интерфейсы решают связанные, но не одинаковые задачи. Выбор зависит от того, требуется ли обобщённый алгоритм с параметром типа или работа с разными значениями через общий набор методов.

## Выведение аргументов типа

Компилятор Go может вывести аргументы типа из аргументов функции и других доступных контекстных данных. Если вывести тип нельзя или результат неоднозначен, аргументы типа указывают явно.

```
func First[T any](items []T) T {
    return items[0]
}

x := First([]string{"a", "b"}) // T выводится как string
```

Выведение типов не означает, что параметры типов можно опустить во всех ситуациях.

## Важные ограничения и замечания

- Параметр типа можно использовать только в пределах объявления обобщённой функции или типа.
- Допустимые операции над значением параметра определяются его ограничением.
- Ограничение `any` не означает, что над значением разрешены все операции.
- Обобщённые типы при использовании должны быть конкретизированы аргументами типа, если контекст языка не позволяет получить их иначе.
- Дженерики не отменяют правила типизации Go и не позволяют выполнять операции, недопустимые для всего множества типов, указанного ограничением.

# Кратко

- **Дженерики** — параметризация функций и типов типами.
- **Параметр типа** — переменная, обозначающая тип.
- **Аргумент типа** — конкретный тип для параметра.
- **Constraint** — ограничение допустимых типов и операций.
- `any` допускает любой тип; `comparable` - для сравниваемых типов ` == ` и ` != `.
- `|` задаёт альтернативы типов, `~T` включает типы с базовым типом `T`.
- Выведение типов позволяет часто вызывать обобщённые функции без явного указания аргументов типа.

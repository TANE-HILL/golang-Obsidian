# Битовые операции

Битовые операции работают с **отдельными битами целого числа**.
В [[1.1.0. Go Basics|Go]] для них используются операторы `&`, `|`, `^`, `&^`, `<<` и `>>`.

**Пусть:**
```Go
a := 6 // 0110
b := 3 // 0011
```

---
## Побитовое И (`&`)

Бит результата равен `1`, только если оба соответствующих бита равны `1`.
```
  0110  // 6
& 0011  // 3
  ----
  0010  // 2
```

```Go
result := a & b // 2
```
**Используется:** проверить или выделить отдельные биты, работать с битовыми масками.

---
## Побитовое ИЛИ (`|`)

Бит результата равен `1`, если хотя бы один из соответствующих битов равен `1`.
```
  0110  // 6
| 0011  // 3
  ----
  0111  // 7
```

```Go
result := a | b // 7
```
**Используется:** установить нужные биты.

---
## Побитовое исключающее ИЛИ (`^`)

Бит результата равен `1`, если соответствующие биты различаются.
```
  0110  // 6
^ 0011  // 3
  ----
  0101  // 5
```

```Go
result := a ^ b // 5
```
**Используется:** переключить выбранные биты; сравнить различия между битами.
- *В [[1.1.0. Go Basics|Go]] `^` также используется как унарный оператор побитового НЕ: `^a`.*

---
## Побитовое НЕ (`^` перед одним операндом)

Инвертирует каждый бит: `0` становится `1`, а `1` — `0`.
```Go
x := ^a
```
В [[1.1.0. Go Basics|Go]] целые числа имеют фиксированную разрядность, зависящую от типа. Поэтому результат `^a` зависит от разрядности и знакового представления типа. Для `int` не стоит представлять результат как инверсию только четырёх битов из примера: инвертируются все биты значения данного типа.

---
## Побитовое И-НЕ (`&^`)

Оператор `&^` в [[1.1.0. Go Basics|Go]] — AND NOT: в результате остаются биты `a`, кроме тех, которые установлены в `b`.
```
   0110  // 6
&^ 0011  // 3
   ----
   0100  // 4
```

```Go
result := a &^ b // 4
```
**Используется:** сбросить выбранные биты.

---
## Сдвиги влево и вправо (`<<`, `>>`)

Сдвигают биты на указанное количество позиций.
```
x := 3          // 0011
left := x << 1  // 0110 = 6
right := x >> 1 // 0001 = 1
```
- `x << n` — сдвиг влево на `n` бит.
- `x >> n` — сдвиг вправо на `n` бит.

Для неотрицательных чисел сдвиг влево на одну позицию соответствует умножению на 2, а сдвиг вправо — целочисленному делению на 2. Нужно учитывать переполнение и особенности знаковых типов.

---
## Краткая таблица

| Оператор | Название                  | Что делает                                           |
| -------- | ------------------------- | ---------------------------------------------------- |
| **`&`**  | **И (AND)**               | *`1`, если оба бита равны `1`*                         |
| **`**    | **`**                     | *ИЛИ (OR)*                                             |
| **`^`**  | **Исключающее ИЛИ (XOR)** | *`1`, если биты различаются; унарно — инверсия*        |
| **`&^`** | **И-НЕ (AND NOT)**        | *Оставляет биты первого числа, сбрасывая биты второго* |
| **`<<`** | **Сдвиг влево**           | *Сдвигает биты влево*                                  |
| **`>>`** | **Сдвиг вправо**          | *Сдвигает биты вправо*                                 |

**Где применяются:** битовые маски, флаги, работа с бинарными форматами и протоколами, низкоуровневый код, оптимизации и алгоритмические задачи.
